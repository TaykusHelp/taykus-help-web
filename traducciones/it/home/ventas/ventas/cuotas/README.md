# Quote

In **Vendite › vendite periodiche** gestisci le quote: incassi che si ripetono con una certa periodicità, per esempio la mensilità di un gruppo dell'accademia. Finché una quota non viene emessa, puoi cambiarne il prezzo, il giorno di scadenza o saltarla.

Prima di tutto, la quota deve essere creata come prodotto. Consulta [Come creare un prodotto di tipo Quota](../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md).

Da questa sezione puoi:

* [Vedere le quote](como-ver-las-cuotas.md) per quota, per cliente o da un gruppo dell'accademia.
* [Emettere una quota](como-emitir-una-cuota.md) perché resti in attesa di pagamento.
* [Pagare una quota](como-pagar-una-cuota.md) dal calendario delle quote.
* [Ripristinare una quota](como-restablecer-una-cuota.md) se l'hai emessa per errore.
* [Saltare una quota](como-omitir-una-cuota.md) perché quella rata non venga incassata.
* [Modificare il prezzo di una quota](como-modificar-el-precio-de-una-cuota.md).
* [Cambiare il giorno di scadenza di una quota](como-cambiar-el-dia-de-vencimiento-de-una-cuota.md).
* [Attivare l'addebito automatico su carta](como-activar-el-cobro-automatico-con-tarjeta.md).
* [Automatizzare l'emissione delle quote](como-automatizar-la-emision-de-cuotas.md).
* [Automatizzare l'annullamento per mancato pagamento](como-automatizar-la-cancelacion-por-impago.md).
* [Disiscrivere un cliente da una quota](como-dar-de-baja-a-un-cliente-de-una-cuota.md).

Se la quota cambia il tipo di cliente (per esempio, da Non socio a Socio), è un abbonamento. Consulta [Che cos'è un abbonamento e come funziona](que-es-una-membresia-y-como-funciona.md).
