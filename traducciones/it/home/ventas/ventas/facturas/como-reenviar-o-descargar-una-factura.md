# Come reinviare o scaricare una fattura

Quando emetti una fattura, viene inviata automaticamente al cliente. Se l'ha persa o non gli è arrivata, puoi inviargliela di nuovo o scaricarla da **Vendite › Fatture**.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso alle fatture

* Vai al menu laterale a sinistra e seleziona **Vendite**.
* Nel menu a tendina, scegli **Fatture**. Si apre la scheda **Fatture emesse**.
{% endstep %}

{% step %}
### Selezionare la fattura

* Trova la fattura. Puoi usare i filtri di ogni colonna, per esempio **Vendita**, **Numero** o **Data di emissione**.
*   Seleziona il cerchio a sinistra della fattura.

    <figure><img src="../../.gitbook/assets/facturas-reenviar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Reinviare o scaricare

* Clicca su **Rinvio** per inviarla di nuovo al cliente.
* Clicca su **Scaricamento** per scaricare la fattura in PDF.
{% endstep %}
{% endstepper %}
