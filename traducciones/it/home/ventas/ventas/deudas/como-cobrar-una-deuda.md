# Come incassare un debito

Da **Vendite › Debiti** puoi incassare ciò che un cliente deve ancora pagare: il debito si apre nel POS e si incassa come qualsiasi altra vendita. Puoi incassare un solo debito o più debiti insieme.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso ai debiti

* Vai al menu laterale a sinistra e seleziona **Vendite**.
* Nel menu a tendina, scegli **Debiti**. Si apre la scheda **Pagamento in sospeso**.
{% endstep %}

{% step %}
### Selezionare il debito

* Trova il debito che vuoi incassare. Puoi usare i filtri di ogni colonna, per esempio **Acquirente**.
* Seleziona la casella a sinistra del debito. Se vuoi incassarne più di uno, selezionali tutti.
*   Clicca su **POS aperto**.<br>

    <figure><img src="../../.gitbook/assets/deudas-abrir-tpv.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Incassare nel POS

* Si apre il POS con il debito caricato.
* Se hai selezionato più debiti, nello scontrino a destra compare l'opzione per caricare tutte le vendite, come quando un cliente paga la parte di un altro.
* Incassa la vendita nel modo abituale.
{% endstep %}
{% endstepper %}

Se hai dubbi sull'incasso nel POS, consulta [Come fare una vendita](https://taykus-help-center.gitbook.io/taykushelpcenter/home/tpv/tpv/ventas/como-hacer-una-venta).
