# Come annullare una vendita da linee

Se una vendita è stata registrata per errore o bisogna restituirne l'importo, puoi annullarla da **Vendite › linee**. Puoi annullare una sola riga o più righe insieme.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso a linee

* Vai al menu laterale a sinistra e seleziona **Vendite**.
* Nel menu a tendina, scegli **linee**.
{% endstep %}

{% step %}
### Selezionare la riga

* Trova la vendita che vuoi annullare. Puoi usare i filtri di ogni colonna, per esempio **Acquirente**.
* Seleziona la casella a sinistra della riga. Se vuoi annullarne più di una, selezionale tutte.
* Clicca su **Annullare**.
{% endstep %}

{% step %}
### Scegliere l'opzione di annullamento

*   Si apre un menu a tendina. Scegli **Cancellare i debiti e restituire i pagamenti**.<br>

    <figure><img src="../../.gitbook/assets/lineas-anular.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confermare

*   Si apre una finestra che chiede conferma:<br>

    <figure><img src="../../.gitbook/assets/lineas-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Clicca su **OK** per annullarla, oppure su **Chiudere** se non vuoi annullarla.
{% endstep %}
{% endstepper %}

Una volta annullata, nell'elenco vedrai due righe colorate: in rosa chiaro il rimborso (con l'importo in negativo) e in rosa più scuro la vendita annullata.

> **Importante:** se annullando bisogna restituire un pagamento in contanti o con carta, devi avere una cassa aperta. Se si tratta del rimborso di un pagamento online, non serve. Per aprire una cassa, consulta [Come aprire la cassa](../cajas/como-abrir-la-caja.md).

Puoi anche annullare una vendita dalla scheda del cliente. Consulta [Come annullare una vendita dalla scheda del cliente](../../../jugadores/jugadores/fichas-de-jugador/como-anular-una-venta-desde-la-ficha-del-jugador.md).

Se vuoi annullare una ricarica di un buono, consulta [Come annullare una ricarica di un buono](como-anular-una-recarga-de-bono.md).
