# Come creare diversi tipi di clienti

I tipi di cliente ti permettono di classificare i tuoi clienti per categorie. Se il club ha una nuova categoria di cliente, puoi aggiungerla al programma in pochi passaggi.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso a Tipi di clienti

* Clicca su **Clienti** nel menu a sinistra.
* Seleziona **Tipi di clienti**, subito sotto.

<figure><img src="../../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>

* In questo blocco compaiono tutti i tipi di cliente che hai già creato.
{% endstep %}

{% step %}
### Creare un nuovo tipo di cliente

* Clicca su <i class="fa-plus">:plus:</i>.
* Scrivi il nome della nuova categoria.

<div align="left"><figure><img src="../../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure></div>

* Salva con <i class="fa-floppy-disk">:floppy-disk:</i>.
{% endstep %}
{% endstepper %}

> **Importante:** quando crei un nuovo tipo di cliente, di solito vuoi applicargli prezzi diversi, soprattutto nelle prenotazioni. Per farlo, dovrai creare prezzi personalizzati per tipo di cliente. Per sapere come, consulta questo articolo:
