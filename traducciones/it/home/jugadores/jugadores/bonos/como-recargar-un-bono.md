# Come ricaricare un buono

Se il club lavora con i buoni, è fondamentale sapere come ricaricarli. Ci sono due modi per farlo: dal POS o dalla scheda del cliente. In questo articolo ti spieghiamo come farlo da **Clienti**.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso a Clienti

* Vai al menu laterale a sinistra e seleziona **Clienti**.
{% endstep %}

{% step %}
### Ricerca del cliente

* Usa una qualsiasi delle colonne disponibili per cercare il cliente per nome, cognome, e-mail, documento d'identità, ecc. e clicca sul suo **Id**.

<figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

* Puoi anche usare la barra di ricerca nell'angolo in alto a sinistra: scrivi il nome del cliente e premi **Invio**.

<div align="left"><figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Accesso alla sezione dei buoni

* Nel profilo del cliente, trova il blocco **Vouchers**.

<div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Ricaricare il buono

* Nell'angolo in alto a destra del blocco, seleziona **Ricaricare**.
* Questa opzione ti porta direttamente al **POS**.
{% endstep %}

{% step %}
### Selezionare il buono

* Si apre una finestra con tutti i buoni disponibili.
* Seleziona il buono che vuoi ricaricare tra quelli già configurati.

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

* Se devi fare una modifica specifica per questo cliente, puoi scegliere l'opzione **Personalizza Ricarica**, selezionando prima una qualsiasi ricarica di buono già creata.
{% endstep %}

{% step %}
### Completare la ricarica

* Fai l'incasso con il metodo di pagamento che preferisce il cliente.
* Se è una ricarica personalizzata a prezzo 0 €, seleziona **Confermare**.
{% endstep %}
{% endstepper %}
