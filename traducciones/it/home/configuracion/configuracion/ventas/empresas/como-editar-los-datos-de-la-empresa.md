# Come modificare i dati dell'azienda

Se cambiano i dati fiscali del club, puoi aggiornarli in qualsiasi momento. I nuovi dati verranno usati nelle prossime autofatture.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso alle aziende <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Clicca sull'icona <i class="fa-gear" style="color:blue;">:gear:</i> nell'angolo in alto a destra ed entra in **Impostazioni**.
* Clicca su **Vendite**.
*   Apri la scheda **Aziende**.

    <figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fs9ED1QQXJQhiuEk3Y7el%252Fimage.png%3Falt%3Dmedia%26token%3Dbabad01e-4c52-45a5-8290-6cc9696c7b71&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=828913b3&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Modificare i dati

* Clicca sull'**Id** dell'azienda.
*   Seleziona <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Cambia i dati fiscali che ti servono.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

> **Importante:** <mark style="background-color:$danger;">non modificare il campo **Invoice Number Format**.</mark>

<figure><img src="../../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Salvare

* Clicca su **Salva**.
{% endstep %}
{% endstepper %}
