# Come modificare i dati di un'azienda cliente

Se cambiano i dati di un'azienda cliente (indirizzo, CIF, contatto…), puoi aggiornarli in qualsiasi momento. I nuovi dati verranno usati nelle prossime fatture.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso alle aziende clienti <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Clicca sull'icona <i class="fa-gear" style="color:blue;">:gear:</i> nell'angolo in alto a destra ed entra in **Impostazioni**.
* Clicca su **Vendite**.
*   Apri la scheda **Aziende clienti**.<br>

    <figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Modificare i dati

* Clicca sull'**Id** dell'azienda cliente.
*   Seleziona <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Cambia i dati che ti servono.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Salvare

* Clicca su **Salva**.
{% endstep %}
{% endstepper %}
