# Come chiudere un giorno

Puoi chiudere il club per un giorno intero, in modo che non si possano fare prenotazioni su nessun campo. È utile nei festivi, per eventi interni o per qualsiasi altro motivo.

Per farlo si usa un orario chiamato **Chiuso**, con priorità più alta degli altri, a cui si aggiungono le date di chiusura.

> Se vuoi chiudere solo **un campo** in un giorno preciso, puoi farlo direttamente dal calendario. Per sapere come, consulta questo articolo:
>
> <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/calendario/como-cerrar-una-pista" class="button primary">Come chiudere un campo</a>

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso agli orari

* Clicca sull'icona <i class="fa-gear" style="color:blue;">:gear:</i> nell'angolo in alto a destra ed entra in **Impostazioni**.
*   Clicca su **prenotazioni**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure></div>
*   Clicca sul blocco **Orari**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Creare l'orario Chiuso

Se hai già un orario **Chiuso**, salta questo passaggio.

* Clicca su :heavy\_plus\_sign:.
* Si apre questa finestra:

<div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

* **Nome:** _Chiuso_.
* **Priorità:** deve essere maggiore di quella degli altri orari. Ti consigliamo _100_.
* Non compilare nient'altro e clicca su **Salva**.
{% endstep %}

{% step %}
### Aggiungere le date di chiusura

* Clicca sull'**Id** dell'orario **Chiuso**.
* Vai al blocco **Eccezioni**.

<div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>

* Clicca su <i class="fa-plus" style="color:purple;">:plus:</i>.
* Si apre questa finestra:

<div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

* **giorno:** la data in cui chiude il club.
* **Ogni anno:** selezionala solo se il club chiude in quella data tutti gli anni.
* **Tipo di eccezione:** lascialo su _Includi data_, che è il valore predefinito.
* Clicca su <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> per salvare.
{% endstep %}
{% endstepper %}

Se vuoi chiudere più giorni di seguito, non mettere date di inizio e fine a questo orario: creane uno a parte. Per sapere come, consulta questo articolo:
