# Come esportare un elenco

Puoi scaricare qualsiasi elenco per lavorarci fuori da Taykus o conservarlo. Si esporta ciò che vedi in quel momento: i record che rispettano i tuoi filtri e le colonne visibili.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Filtrare l'elenco

* Applica i filtri e lascia visibili le colonne che vuoi esportare. Consulta [Come nascondere o mostrare le colonne](como-ocultar-o-mostrar-columnas.md).
{% endstep %}

{% step %}
### Esportare

* Clicca sull'icona della freccia di download, sopra l'elenco.
*   In **Scaricamento**, scegli il formato: **Excel** o **CSV**. Il file viene scaricato sul tuo computer.

    <figure><img src="../../.gitbook/assets/listados-exportar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
