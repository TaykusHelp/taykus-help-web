# Elenchi

Quasi tutte le schermate del pannello di Taykus sono elenchi: clienti, vendite, pagamenti, debiti, modelli… Funzionano tutti allo stesso modo, quindi quello che impari in uno ti serve per gli altri.

In qualsiasi elenco puoi:

* [Filtrare tra due date](como-filtrar-entre-dos-fechas.md).
* [Spostare le colonne](como-mover-columnas.md).
* [Nascondere o mostrare le colonne](como-ocultar-o-mostrar-columnas.md).
* [Salvare un elenco come preferito](como-guardar-un-listado-como-favorito.md), con i suoi filtri e le sue colonne.
* [Esportare un elenco](como-exportar-un-listado.md).
