# Come abbassare il prezzo di un prodotto dal POS

Ridurre il prezzo di un prodotto dal POS permette di adattare una vendita puntuale senza modificare il prezzo generale dell'articolo nel sistema. Questa opzione è utile per applicare modifiche commerciali o risolvere imprevisti durante l'incasso. Ecco come farlo passo dopo passo.

{% stepper %}
{% step %}
### Accesso al POS

* Vai al menu laterale a sinistra e seleziona **POS**, oppure clicca sulla prenotazione e seleziona **Prenotazione a pagamento**. Entrambe le opzioni ti portano al POS.
{% endstep %}

{% step %}
### Ricerca del cliente

*   Se non stai pagando una prenotazione e non hai già selezionato il cliente, usa la barra di ricerca nell'angolo in alto a destra per trovarlo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Se è una vendita occasionale e non verranno registrati dati, seleziona **Cliente anonimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Selezionare il prodotto

* Se non è una prenotazione, scegli il prodotto che vuoi vendere dall'elenco disponibile.
{% endstep %}

{% step %}
### Cambiare il prezzo

* Clicca sul nome del prodotto nello scontrino.
*   La riga si evidenzia in verde e potrai inserire il nuovo prezzo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Verificare e incassare

*   Verifica che il nuovo prezzo compaia correttamente nello scontrino e procedi all'incasso con il metodo di pagamento scelto dal cliente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure></div>
* Il nuovo prezzo compare nello scontrino come uno sconto applicato sull'importo originale.
{% endstep %}
{% endstepper %}

Una volta modificato il prezzo, puoi continuare la vendita normalmente. La modifica resta registrata nello scontrino come sconto, garantendo che il movimento compaia correttamente in cassa.
