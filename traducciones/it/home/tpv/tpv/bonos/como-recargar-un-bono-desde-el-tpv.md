# Come ricaricare un buono dal POS

Ricaricare un buono di denaro dal POS permette di aggiungere saldo subito, perché il cliente possa usarlo in acquisti o prenotazioni futuri. L'operazione resta registrata automaticamente nel sistema e facilita la gestione dei pagamenti anticipati.&#x20;


{% stepper %}
{% step %}
### Accesso al POS

* Vai al menu laterale a sinistra e seleziona **POS**.
{% endstep %}

{% step %}
### Ricerca del cliente

*   Usa la barra di ricerca nell'angolo in alto a destra per trovare il cliente.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Selezione del buono

*   Clicca sull'opzione Vouchers, sotto gli accessi rapidi.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Selezione del buono desiderato

* Si apre una finestra con tutti i buoni disponibili.
* Seleziona il buono che vuoi ricaricare tra quelli configurati in precedenza.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Se devi fare una modifica specifica per questo cliente, puoi usare **Personalizza Ricarica**; per sapere come, consulta questo articolo:\
  <a href="como-hacer-una-recarga-personalizada-de-un-bono-monedero-desde-el-tpv.md" class="button primary">Come fare una ricarica personalizzata di un buono di denaro dal POS</a><br>
{% endstep %}

{% step %}

* Procedi all'incasso, con il metodo di pagamento che preferisce il cliente.
* Se la ricarica del buono resta in attesa di pagamento o di addebito bancario, il saldo non viene caricato al cliente finché non è pagata.
{% endstep %}
{% endstepper %}

Una volta fatta la ricarica, il saldo è subito disponibile. Registrare correttamente queste operazioni garantisce un controllo preciso del borsellino e dei movimenti di cassa.
