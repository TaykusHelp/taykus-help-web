# Come recuperare una vendita parcheggiata

Recuperare una vendita parcheggiata permette di riprendere una transazione in pausa senza perdere le informazioni registrate. È utile per continuare l'incasso quando un cliente torna o quando un'operazione alla cassa è stata interrotta. Ecco come recuperare una vendita parcheggiata passo dopo passo.

{% stepper %}
{% step %}
### Accesso al POS

* Vai al menu laterale a sinistra e seleziona **POS**.
{% endstep %}

{% step %}
### Aprire le vendite parcheggiate

*   Nella parte superiore della schermata, clicca su **Vendite parcheggiate**.<br>

    <figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Selezionare la vendita

* Si apre una finestra con tutte le vendite parcheggiate.
*   Scegli la vendita che vuoi riprendere.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Completare la vendita

* Continua con l'incasso usando il metodo di pagamento che preferisce il cliente.
{% endstep %}
{% endstepper %}

Una volta recuperata la vendita, puoi completare l'incasso normalmente. Usare correttamente le vendite parcheggiate aiuta a mantenere l'ordine nel POS ed evita la perdita di informazioni durante la giornata.
