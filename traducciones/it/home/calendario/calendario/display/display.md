# Display

Il display è lo schermo che puoi collocare nel club per mostrare a giocatori e visitatori le partite del giorno: orari, giocatori e numero del campo. Oltre a essere molto pratico, dà al club un'immagine più moderna e professionale.

## Come aprire il display

{% stepper %}
{% step %}
### Accesso al display

* Clicca su **Calendario** nel menu a sinistra. Si aprirà un menu a tendina con due opzioni:
  * **Display: 1 colonna**
  * **Display: 2 colonne**

<div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Scegliere il formato

* Seleziona l'opzione che preferisci in base a come vuoi che si veda lo schermo.
* Il display si aprirà in una nuova scheda del browser. È questa la scheda che dovrai mostrare sullo schermo del club.
{% endstep %}
{% endstepper %}

## Come mostrare solo le iniziali dei giocatori

Se preferisci che sullo schermo non compaia il nome completo dei partecipanti, puoi configurare il display perché mostri solo le loro iniziali.

{% stepper %}
{% step %}
### Accesso alle impostazioni delle prenotazioni

* Clicca sull'icona <i class="fa-gear">:gear:</i> nell'angolo in alto a destra.
* Clicca di nuovo su **Impostazioni**.
* Seleziona **Prenotazioni**.

<div align="left"><figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Selezionare lo sport

* Nella colonna **Gruppo risorse**, clicca sull'Id dello sport che vuoi mostrare sullo schermo.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Attivare le iniziali

* Si aprirà la configurazione generale di quello sport.
* Seleziona la casella **Mostra iniziali dei partecipanti**.

<div align="left"><figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
