# Come chiudere un campo

Chiudere un campo permette di bloccarlo per un giorno intero, così non si possono fare prenotazioni. Questa opzione è particolarmente utile nei giorni festivi, per eventi interni del club, per la manutenzione o per qualsiasi altro motivo operativo.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso al Calendario

* Vai al menu laterale a sinistra e seleziona **Calendario**.
{% endstep %}

{% step %}
### Scelta della data

* Seleziona il giorno che vuoi chiudere.

<figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

* Cliccando sul giorno, il calendario ti porterà direttamente a quella data.
{% endstep %}

{% step %}
### Chiusura del campo

* Clicca sul nome del campo.
* Si aprirà il seguente menu:

<div align="left"><figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure></div>

* Seleziona **Chiuso tutto il giorno**.
{% endstep %}
{% endstepper %}

> **Importante:** la chiusura si applica solo al campo selezionato. Se devi chiudere altri campi lo stesso giorno, ripeti la procedura con ciascuno.

Per riaprirlo, consulta [Come aprire un campo](como-abrir-una-pista.md). Se vuoi chiuderlo solo per alcune ore, consulta [Come chiudere un campo per alcune ore](como-cerrar-una-pista-unas-horas.md).
