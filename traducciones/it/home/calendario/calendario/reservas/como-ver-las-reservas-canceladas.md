# Come vedere le prenotazioni annullate

Le prenotazioni annullate non compaiono più nel calendario, ma puoi vederle nell'elenco delle prenotazioni filtrando per stato.

Ecco i passaggi da seguire:

{% stepper %}
{% step %}
### Accesso a Prenotazioni

* Vai al menu laterale a sinistra e seleziona **Calendario**.
* Nel menu a tendina, scegli **Prenotazioni**. Si apre l'elenco **Risorse prenotate**.
{% endstep %}

{% step %}
### Filtrare le annullate

* Scorri verso destra fino alla colonna **Stato**.
*   Nel filtro di quella colonna, scegli **Annullato**.

    <figure><img src="../../.gitbook/assets/reservas-canceladas.png" alt=""><figcaption></figcaption></figure>
* L'elenco mostra solo le prenotazioni annullate.
{% endstep %}
{% endstepper %}

Per sapere chi ha annullato una prenotazione, clicca sul suo **Id** e apri la scheda **Storia**. Consulta [Come vedere la cronologia di una prenotazione](como-ver-el-historico-de-una-reserva.md).

Per non dover impostare il filtro ogni volta, puoi salvare l'elenco come preferito. Consulta [Come salvare un elenco come preferito](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/listados/como-guardar-un-listado-como-favorito).
