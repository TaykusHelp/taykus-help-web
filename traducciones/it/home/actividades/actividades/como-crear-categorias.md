# Come creare le categorie

Le **categorie** permettono di organizzare i partecipanti di un'attività secondo diversi criteri, come modalità, livello o tipo di competizione.

È particolarmente utile in attività come tornei o eventi in cui i giocatori possono iscriversi a categorie diverse (per esempio: maschile, femminile, misto o diversi livelli di gioco).

In questo articolo ti spieghiamo come crearle.

{% stepper %}
{% step %}
### Accedere alla sezione Categorie

* Vai al menu a sinistra e accedi ad **Attività**.
* Seleziona l'id dell'attività che vuoi gestire.
*   Nella parte superiore, clicca sulla scheda **Categorie**.<br>

    <figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Creare una nuova categoria

* Clicca su :heavy\_plus\_sign:.
*   Si apre una finestra in cui devi compilare il seguente campo:<br>

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Nome:** indica il nome della categoria (per esempio: Maschile, Femminile, Misto o diversi livelli di gioco).
* Una volta indicato il nome, clicca su **Salva** per creare la categoria.
{% endstep %}

{% step %}
### Aggiungere altre categorie

Puoi ripetere questa procedura tutte le volte necessarie per creare tutte le categorie che faranno parte dell'attività.

Queste categorie verranno usate poi per **gestire le iscrizioni dei partecipanti** e per **configurare i prezzi di iscrizione in base al numero di categorie**.
{% endstep %}
{% endstepper %}

Una volta create le categorie, i partecipanti potranno selezionarle durante l'iscrizione e il sistema gestirà automaticamente la loro registrazione nell'attività.
