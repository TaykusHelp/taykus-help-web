# How to give permissions in Taykus Pro

In **Taykus Pro Permissions** you decide what each of the club's roles can see and do in the Taykus Pro app. The roles are the same ones you have in **Settings › Roles**.

Follow these steps:

{% stepper %}
{% step %}
### Go to Taykus Pro Permissions

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Taykus Pro Permissions**.

    <figure><img src="../../.gitbook/assets/permisos-taykus-pro-acceso.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Tick each role's permissions

* Each row is a feature of the app and each column is one of the club's roles.
*   Tick the role's box for each feature you want to give it:

    <figure><img src="../../.gitbook/assets/permisos-taykus-pro.png" alt=""><figcaption></figcaption></figure>

    * **Coaches' schedule:** **See the coaches' schedule** (each coach sees their own class schedule), **Validate class**, **Take attendance**, **Send communications** and **Add comments**.
    * **Calendar:** **See the calendar** and **Create / Edit / Cancel bookings**.
    * **Chat:** **See the chat**.
* The box on each block's row (for example, **Calendar**) ticks the whole block for that role.
* The box on the left of each feature (**All roles** column) ticks it for all roles.
* Anything a role doesn't have permission for doesn't appear in the app's menu.

> **Important:** to give a permission such as **Validate class** or **Create / Edit / Cancel bookings**, first tick its block's "see" permission. Until then, its box is greyed out.
{% endstep %}

{% step %}
### Save

* Click **Save changes**.
{% endstep %}
{% endstepper %}
