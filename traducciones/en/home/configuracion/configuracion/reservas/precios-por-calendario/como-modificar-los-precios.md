# How to change prices

Booking prices depend on the time slots set up in **Calendar prices**. To change a price, you change the product that time slot uses. Before you start, make sure you're going to edit the right calendar, facilities and time slots.

### Explainer video

{% embed url="https://youtu.be/Ra_LiCtxGUY" %}

> **Before you start:** the new price must exist as a Service product. If you haven't created it yet, see:
>
> <a href="../../ventas/productos/como-crear-un-producto-tipo-servicio.md" class="button primary" data-icon="box">How to create a Service product</a>

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar prices

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Calendar prices** block.<br>

    <figure><img src="../../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Open the price calendar

* Find the price calendar you want to change and click its **ID**.
*   Go to the **Prices** block.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>
* You'll see the list of time slots with their price:

<figure><img src="../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1: Change a time slot's product

* Widen the **Products** column by dragging its edge to the right.
*   Click the blank space shown.<br>

    <figure><img src="../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
*   Click the **X** to remove the current product.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure></div>
* Search for the product with the new price.  ![](<../../../.gitbook/assets/image (5).png>)
* Select it and press **Enter**. The time slot is updated.
{% endstep %}

{% step %}
### Option 2: Create a new time slot

You can also delete the current time slots and create new ones.

* Click :heavy\_plus\_sign:.
*   The **Add time** window opens:<br>

    <figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Resource:** the specific court or resource, if the price is only for one.
    * **Resource group:** the group, if the price is for several facilities of the same type.
    * **Start:** the time the price starts to apply.
    * **End:** the time it stops applying.
    * **Ends the next day:** tick it if the time slot ends the next day.
    * **Apply this price to overlaps:** tick it if this price should apply when two time slots overlap.
    * **Product:** the product that sets the price of bookings in this time slot.
* Click **Save**.
{% endstep %}

{% step %}
### Check the changes

Check in the list of prices that the time slot is correct. Check in particular:

* That the resource or resource group is the right one.
* That the start and end times are correct.
* That the product is the right one and its price is what you want to charge.
* That the overlaps option is only ticked if needed.
{% endstep %}
{% endstepper %}
