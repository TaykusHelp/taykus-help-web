# How to set holiday prices

You can charge a different price on public holidays, for example if there's more demand on those days. Prices for the other days don't change.

> **Important:** here you only change **prices**. Court opening and availability don't change. For that, see:
>
> [como-poner-horario-de-festivo.md](../horarios/como-poner-horario-de-festivo.md "mention")

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar prices

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Calendar prices** block.<br>

    <figure><img src="../../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the holiday price calendar

Skip this step if you already have a holiday one, or if the holiday will use existing prices (for example, the weekend ones).

* Click :heavy\_plus\_sign:.
*   This window opens:

    <div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

    * **Name:** _Holiday_.
    * **Priority:** it must be higher than the others. We recommend _100_.
    * Don't fill in anything else and click **Save**.
{% endstep %}

{% step %}
### Add the public holidays

Add the holidays to the price calendar you want them to use: the holiday one or an existing one, such as the weekend one.

* Click the price calendar's **ID**.
*   Go to the **Exceptions** block.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>
* Click <i class="fa-plus" style="color:purple;">:plus:</i>.
*   This window opens:

    <div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

    * **Day:** the date of the holiday.
    * **Every year:** tick it if the holiday falls on the same date every year.
    * **Exception type:** leave it as _Includes date_, which is the default.
* Click <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> to save.
{% endstep %}
{% endstepper %}
