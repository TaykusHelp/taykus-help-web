# How to create a booking reminder

Players already receive an email when they make, cancel or change a booking. Even so, it's easy to forget a booking or a match. To avoid this, Taykus can send a **reminder email** some time beforehand.

Follow these steps:

{% stepper %}
{% step %}
### Go to Booking reminders

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fo7gBVkwfX7ziYiTLefsN%252Fimage.png%3Falt%3Dmedia%26token%3D9f9d15bf-ab2d-44e1-b2e8-fd7276f24e60&#x26;width=300&#x26;dpr=4&#x26;quality=100&#x26;sign=3f7de3b8&#x26;sv=2" alt=""><figcaption></figcaption></figure></div>
*   Click the **Booking reminder** block.<br>

    <figure><img src="../../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the reminder

* Click :heavy\_plus\_sign:.
*   This window opens:<br>

    <figure><img src="../../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>

    * **Advance notice in minutes:** how many minutes beforehand the player is reminded.
    * **Resource group:** the sport or coaches it applies to. If you leave it empty, it applies to all.
* Click **Save**.
{% endstep %}
{% endstepper %}
