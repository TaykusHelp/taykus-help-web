# How to add a new coach

**Coaches** are created as resources, just like courts. This way the system knows when they're available and can assign them to bookings and classes without overlaps.

Coaches are usually created during the initial setup. If you need to add a new one, follow these steps.

> **Important: creating the coach isn't enough.** After creating them here, **they won't appear in the calendar** until you assign them a schedule. It's the step people forget most. As soon as you finish, see this article:
>
> <a href="../horarios/como-asignar-un-profesor-a-un-horario.md" class="button primary">How to assign a coach to a schedule</a>

Follow these steps:

{% stepper %}
{% step %}
### Go to Resource group

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Bookings**. The **Resource group** block opens directly.
{% endstep %}

{% step %}
### Go to the coaches

*   Click the **ID** of **Coaches**.<br>

{% endstep %}

#### General

* **Name:** the coach's or instructor's name. We recommend adding an identifying number so you can find them easily when assigning schedules or bookings.
* **Order:** the position they'll appear in on internal lists.
* **Related resource:** to link the coach to another resource, for example a court. When booking with the coach, the court is also booked automatically.
* **Tag:** to classify the resource in a category.
* **Image:** photo of the coach. It can be seen online if the resource is available for public booking.
* **Description:** optional text with information about the coach.
* **Booking notification email:** the email address that will receive booking notifications for this coach.

#### Restrictions

* **Online:** the coach can be booked from the website or the app.
* **Show name online:** customers will see their name when booking online.
* **Show in admin:** the coach appears in the management panel.
* **Allow overlapping bookings:** the coach can have several bookings at the same time.
* **Allow overlapping bookings in admin:** overlaps are only allowed from admin.
* **Maximum overlapping bookings:** the maximum number of bookings that can coincide at the same time.

#### Appearance

* **Colours:** how the coach will look in the calendar, so you can recognise them at a glance.
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}
