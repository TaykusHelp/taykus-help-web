# How to create or specify a cancellation reason

When a booking is cancelled there's usually a reason: rain, an injury, a change of plans… If you record these reasons, the club can see why bookings are cancelled and improve how it manages schedules, courts and communication with players.

Follow these steps:

{% stepper %}
{% step %}
### Go to Cancellation reasons

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fo7gBVkwfX7ziYiTLefsN%252Fimage.png%3Falt%3Dmedia%26token%3D9f9d15bf-ab2d-44e1-b2e8-fd7276f24e60&#x26;width=300&#x26;dpr=4&#x26;quality=100&#x26;sign=3f7de3b8&#x26;sv=2" alt=""><figcaption></figcaption></figure></div>
*   Click the **Cancellation reasons** block.<br>

    <figure><img src="../../../.gitbook/assets/image (120).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the reasons

* Click :heavy\_plus\_sign:.
*   Enter the name of the reason. For example: _rain_, _illness_, _court maintenance_, _forgot_…<br>

    <figure><img src="../../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
* Click **Save**.
* Repeat the process to create all the reasons you need.
{% endstep %}
{% endstepper %}

## Specify the reason when cancelling a booking

When you cancel a booking, this screen appears:

<div align="left"><figure><img src="../../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>

In the drop-down you can choose one of the reasons you've created. It's not required.

## See the list of cancellations with their reason

* Click **Calendar** and, in the drop-down, select **Bookings**.  ![](<../../../.gitbook/assets/image (30).png>)
* Click **Columns** and select **Cancellation reasons** to add that column to the list.  ![](<../../../.gitbook/assets/image (31).png>)
*   Filter by **Cancelled** status. You'll see the list like this:<br>

    <figure><img src="../../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>
* You can download the list and export it to Excel.
