# How to close a day

You can close the club for a whole day so that no bookings can be made on any court. It's useful on public holidays, for internal events or for any other reason.

To do this, you use a schedule called **Closed**, with a higher priority than the others, to which you add the closing dates.

> If you only want to close **one court** on a specific day, you can do it directly from the calendar. To find out how, see this article:
>
> <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/calendario/como-cerrar-una-pista" class="button primary">How to close a court</a>

Follow these steps:

{% stepper %}
{% step %}
### Go to Schedules

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Schedules** block.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Create the Closed schedule

If you already have a **Closed** schedule, skip this step.

* Click :heavy\_plus\_sign:.
* This window opens:

<div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

* **Name:** _Closed_.
* **Priority:** it must be higher than the other schedules. We recommend _100_.
* Don't fill in anything else and click **Save**.
{% endstep %}

{% step %}
### Add the closing dates

* Click the **ID** of the **Closed** schedule.
* Go to the **Exceptions** block.

<div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>

* Click <i class="fa-plus" style="color:purple;">:plus:</i>.
* This window opens:

<div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

* **Day:** the date the club is closed.
* **Every year:** tick it only if the club closes on that date every year.
* **Exception type:** leave it as _Includes date_, which is the default.
* Click <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> to save.
{% endstep %}
{% endstepper %}
