# How to set a holiday schedule

You can give public holidays a different schedule from usual: a different opening time, different booking slots or a different academy activity. The planning for the other days doesn't change.

> **Important:** here you only change the **schedule**. If holidays have a different **price**, set it up separately:
>
> <a href="../precios-por-calendario/como-poner-precios-de-festivo.md" class="button primary">How to set holiday prices</a>

Follow these steps:

{% stepper %}
{% step %}
### Go to Schedules

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Schedules** block.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (57).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Create the holiday schedule

Skip this step if you already have a holiday schedule, or if the holiday will use an existing schedule (for example, the weekend one).

* Click :heavy\_plus\_sign:.
*   This window opens:

    <div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

    * **Name:** _Holiday_.
    * **Priority:** it must be higher than the other schedules. We recommend _100_.
    * Don't fill in anything else and click **Save**.
{% endstep %}

{% step %}
### Add the public holidays

Add the holidays to the schedule you want them to use: the holiday schedule you've just created or an existing one, such as the weekend schedule.

* Click the schedule's **ID**.
*   Go to the **Exceptions** block.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>
* Click <i class="fa-plus" style="color:purple;">:plus:</i>.
*   This window opens:

    <div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

    * **Day:** the date of the holiday.
    * **Every year:** tick it if the holiday falls on the same date every year.
    * **Exception type:** leave it as _Includes date_, which is the default.
* Click <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> to save.
{% endstep %}
{% endstepper %}
