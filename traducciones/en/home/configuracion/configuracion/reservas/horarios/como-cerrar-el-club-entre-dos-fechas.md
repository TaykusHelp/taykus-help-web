# How to close the club between two dates

You can close the club for several days in a row, for example for holidays or building work, so that no court can be booked between those dates. You do it with a closing schedule of its own, with a start date and an end date.

> **Important:** bookings already made on those dates aren't cancelled automatically. You'll need to cancel them by hand. To find out how, see this article:
>
> <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/calendario/reservas/como-cancelar-una-reserva" class="button primary">How to cancel a booking</a>

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Schedules

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Schedules** block.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Create the closing schedule

> **Important:** don't use the **Closed** schedule you use for single days. If you give it start and end dates, the days you have under **Exceptions** stop working outside those dates. Always create a separate schedule for longer closures. To find out how to create a schedule, see this article:
>
> <a href="como-crear-un-horario.md" class="button primary">How to create a schedule</a>

* Click :heavy\_plus\_sign:.
* This window opens:

<div align="left"><figure><img src="../../../.gitbook/assets/cerrar-entre-fechas.png" alt=""><figcaption></figcaption></figure></div>

* **Name:** one that identifies it, for example _Closed for holidays_.
* **Priority:** it has to be higher than the other schedules. We recommend _100_.
* **Start:** the first day of the closure, at 00:00.
* **End:** the day **after** the last day of the closure, at 00:00.
* **Day of the Week:** tick every day, Monday to Sunday.
* Don't add anything under **Opening hours** and click **Save**.

> **Important:** the closure ends exactly at the **End** date and time. For example, to close from 26 October to 3 November, both included, set the start to 26/10 at 00:00 and the end to 04/11 at 00:00.
{% endstep %}
{% endstepper %}

During those dates the club will be closed on all courts. When the end date arrives, it goes back to its usual schedule by itself, without you having to do anything.
