# How to edit a schedule by hours

You can change the opening hours of an existing schedule, for example because the club's hours change, for an event or for a maintenance slot, without having to create it again.

### Explainer video

{% embed url="https://youtu.be/b5cfbRFDTIU" %}

Follow these steps:

{% stepper %}
{% step %}
### Go to Schedules

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Schedules** block.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Open the schedule

*   Click the **ID** of the schedule you want to change.

    <figure><img src="../../../.gitbook/assets/image (121).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Change the hours

*   Open the **Opening hours** tab.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (123).png" alt=""><figcaption></figcaption></figure></div>
*   Click the time you want to change.<br>

    <figure><img src="../../../.gitbook/assets/image (124).png" alt=""><figcaption></figcaption></figure>
* Change the time with the arrows or the keyboard. If in doubt, watch the video.
* Repeat the process for each resource.

> **Another option:** redo the hours from scratch. Select all the lines, delete them and create them again:
>
> <a href="como-crear-un-horario.md#anadir-horas-de-apertura-y-cierre" class="button primary" data-icon="door-open">Add opening and closing hours</a>
{% endstep %}

{% step %}
### Check the changes

In the **Opening hours** tab, check that each resource has the right hours. Check in particular:

* That the resources are the right ones.
* That the start and end times are correct.
* That the interval, minimum duration and maximum duration are what the club needs.

Then go to the calendar and check that the availability is as expected.
{% endstep %}
{% endstepper %}
