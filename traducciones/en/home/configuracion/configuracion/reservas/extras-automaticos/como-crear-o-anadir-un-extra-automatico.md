# How to create or add an automatic extra

An **automatic extra** is a supplement that is added to the booking price automatically under certain conditions. For example, charging separately for lights from a certain time or on certain dates.

> **Before you start:** the extra must exist as a Service product. If you haven't created it yet, see this article:
>
> <a href="../../ventas/productos/como-crear-un-producto-tipo-servicio.md" class="button primary">How to create a Service product</a>

Follow these steps:

{% stepper %}
{% step %}
### Go to Automatic extras

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
*   Click **Bookings**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure></div>
*   Click the **Automatic extras** block.<br>

    <figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the extra

* Click :heavy\_plus\_sign:.
*   This window opens:

    <figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

    * **Product:** search for the product you want to add as an extra.
    * **Booking type:** the booking type it applies to. If you want to apply it to several types, create an extra for each one.
    * **Resource:** the courts it's added to. If you leave it empty, it applies to all of them.
    * **Customer type:** if it's only charged to one customer type (for example, member or non-member).
    * **Customer:** if it's only charged to one person. If there are several, create an extra for each one.
    * **Start date:** the date from which it's added.
    * **End date:** the date until which it's added. It's optional.
    * **Start time:** the time from which it's added.
    * **End time:** the time until which it's added. It's optional.
    * **Yearly recurrence:** tick it if it repeats every year.
    * **Days of the week:** the days on which it's added.
* Click **Save**.
{% endstep %}
{% endstepper %}

> **Important:** just as with products, where you create one for bookings and another for matches, here you also need to create an extra for each one. First create the two products and then the two extras.
