# How to create a user

Everyone at the club who is going to use Taykus needs their own user, with their own email and password. The user's role decides what they can see and do in the program.

Follow these steps:

{% stepper %}
{% step %}
### Go to Users

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner.
*   In the drop-down, click **Users**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Create the user

* Click :heavy\_plus\_sign:.
*   This form opens:<br>

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

    * **Name:** the user's name.
    * **Logo:** optional. A photo of the user.
    * **Email:** the email they'll use to log in to Taykus.
    * **Password:** their login password.
    * **Preferred language:** the language they'll see the program in.
    * **Role:** the permissions they'll have. To find out how to create or edit a role, see this article:

      <a href="../roles/como-crear-editar-o-borra-un-rol.md" class="button primary">How to create, edit or delete a role</a>
    * **Home page:** the screen they'll see when they log in.
* Click **Save**.
{% endstep %}
{% endstepper %}
