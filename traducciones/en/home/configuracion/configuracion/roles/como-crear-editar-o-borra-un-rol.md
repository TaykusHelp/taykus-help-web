# How to create, edit or delete a role

**Roles** decide what each member of staff can see and do in Taykus. Each user has a role, and that role sets their permissions in each part of the program.

### Explainer video

{% embed url="https://youtu.be/Vk6PSU2hFQU" %}

## Where to find roles

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Roles**.

<figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>

You'll see the list of roles and can open each one to see its permissions.

## Default roles

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

* **Centre Admin:** full access to the whole program.
* **Reception:** full access to bookings, academy and communications, and partial access to settings.
* **Coach:** partial access to calendar, academy and players.
* **Taykus Support:** full access, so the support team can help you with questions or problems.

> If you don't want coaches to log in to the program as administrators, you can give them a coach-only login address, where they'll only see their classes, students and calendar. For example: `https://mariademo.taykusdemo.com/teachers/login`

## Permission levels

Each role has several permission blocks. Next to each permission you can turn these levels on or off:

![](<../../.gitbook/assets/image (10).png>)

* **View:** the user can see the information.
* **Edit:** the user can change the information. Depending on the permission, they can also create, delete or export.

## Change a role's permissions

{% stepper %}
{% step %}
### Open the role

* Go to **Settings › Roles**.
* Click the role's **ID**.
{% endstep %}

{% step %}
### Turn permissions on or off

* Review the permission blocks.
* Click the level you want to change:
  * In **green**, the permission is on.    ![](<../../.gitbook/assets/image (11).png>)
  * In **red**, it's off.    ![](<../../.gitbook/assets/image (12).png>)
* Changes are saved automatically; you don't need to press Save.
{% endstep %}
{% endstepper %}

## Create a new role

{% stepper %}
{% step %}
### Create the role

* Go to **Settings › Roles**.
* Click the option to create a new role.
* Enter the role's name and save.
{% endstep %}

{% step %}
### Set its permissions

* Open the role from its **ID**.
* Turn the permissions on or off as explained in the previous section.
{% endstep %}
{% endstepper %}

## Delete a role

{% stepper %}
{% step %}
### Check that nobody uses it

* Before deleting a role, check that no user has it assigned. Otherwise, that staff member could lose access.
{% endstep %}

{% step %}
### Delete the role

* Go to **Settings › Roles**.
* Open the role from its **ID**.
* Use the delete option.
{% endstep %}
{% endstepper %}
