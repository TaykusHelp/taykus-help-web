# Settings

In the settings menu, the **Settings** section stores the club's basic details. This is also where you import the database.

<figure><img src="../../.gitbook/assets/image (54).png" alt=""><figcaption></figcaption></figure>

Here are the steps to edit the club's details:

{% stepper %}
{% step %}
### Open the settings menu

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner.
* A drop-down opens.
* Click **Settings** again.
{% endstep %}

{% step %}
### Open the club's details

* In the settings menu, click **Settings**.
* You'll see a tab with the club's details.
* Click the **ID** to open them.
{% endstep %}

{% step %}
### Edit and save

*   Press the pencil icon <i class="fa-pen" style="color:blue;">:pen:</i> to edit.<br>

    <figure><img src="../../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>
* Make the changes you need.
* Click **Save**.
{% endstep %}
{% endstepper %}
