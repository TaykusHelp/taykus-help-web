# How to open the settings menu

The settings menu is available from any screen in Taykus. From here you set up the club's details, bookings, sales, users and the rest of the system's options.

Follow these steps:

{% stepper %}
{% step %}
### Open the drop-down

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner.
* A drop-down opens.
{% endstep %}

{% step %}
### Go to Settings

* Click **Settings** <i class="fa-gear" style="color:blue;">:gear:</i> again.

<figure><img src="../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

* The settings menu opens:

<figure><img src="../../.gitbook/assets/image (88).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
