# Lists

Almost every screen in the Taykus panel is a list: players, sales, payments, debts, templates… They all work the same way, so what you learn in one works in the others.

In any list you can:

* [Filter between two dates](como-filtrar-entre-dos-fechas.md).
* [Move columns](como-mover-columnas.md).
* [Hide or show columns](como-ocultar-o-mostrar-columnas.md).
* [Save a list as a favourite](como-guardar-un-listado-como-favorito.md), with its filters and columns.
* [Export a list](como-exportar-un-listado.md).
