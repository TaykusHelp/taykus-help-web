# How to move columns

You can change the order of a list's columns to keep the ones you use most close at hand.

Below are the steps to follow:

{% stepper %}
{% step %}
### Drag the column

* Click the header of the column you want to move and, without letting go, drag it left or right.
*   Drop it where you want it.

    <figure><img src="../../.gitbook/assets/listados-mover-columna.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Important:** if you drag the header upwards, out of the list, the column is hidden. To show it again, see [How to hide or show columns](como-ocultar-o-mostrar-columnas.md).

To keep this order, save the list as a favourite. See [How to save a list as a favourite](como-guardar-un-listado-como-favorito.md).
