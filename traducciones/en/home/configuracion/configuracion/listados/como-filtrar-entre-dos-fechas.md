# How to filter between two dates

In lists you can keep only the records from a period, for example the sales for one month. You do this with the filter on the date column.

Below are the steps to follow:

{% stepper %}
{% step %}
### Open the column filter

* In the list header, find the date column you want to filter by (for example, **Created** or **Issue date**).
* Click the three-line icon on that column.

> Each column has its own filter, and the options change depending on what it contains: text, numbers or dates.
{% endstep %}

{% step %}
### Choose In the range

*   In the drop-down, choose **In the range**. Two fields appear: the first for the start date and the second for the end date.

    <figure><img src="../../.gitbook/assets/listados-filtro-rango-campos.png" alt=""><figcaption></figcaption></figure>

    > You can also use **Less than** (before a date), **Greater than** (after a date) or **Equal** (a specific day).
{% endstep %}

{% step %}
### Start date

*   Click the first field and choose the date in the calendar. You can change the month and year at the top.

    <figure><img src="../../.gitbook/assets/listados-filtro-calendario.png" alt=""><figcaption></figcaption></figure>
* Once you choose it, the filter closes.
{% endstep %}

{% step %}
### End date

* Click the three-line icon on the same column again.
*   Click the second field and choose the end date.

    <figure><img src="../../.gitbook/assets/listados-filtro-rango.png" alt=""><figcaption></figcaption></figure>
* The list shows only the records between those two dates.
{% endstep %}
{% endstepper %}

So you don't have to set the filter every time, you can save the list as a favourite. See [How to save a list as a favourite](como-guardar-un-listado-como-favorito.md).
