# How to set up your company details

This is where the club's tax details are stored. They're used automatically on the self-billing invoice generated when the club requests a transfer, and they appear on all the accounting documents the system issues.

Only **one company or legal entity** can be registered. These details are usually set up when you start with Taykus, but you can review and change them whenever you need.

Follow these steps:

{% stepper %}
{% step %}
### Go to Companies

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**.
*   Open the **Companies** tab.<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the company details

*   Click :heavy\_plus\_sign:.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Fill in the company's tax details. The only required field is the **email**.

> **Important:** <mark style="background-color:$danger;">don't change the **Invoice Number Format** field.</mark>
{% endstep %}

{% step %}
### Save

* Click **Save**.
* From now on, these details will appear on every self-billing invoice generated when you request a transfer.
{% endstep %}
{% endstepper %}
