# How to edit the company details

If the club's tax details change, you can update them at any time. The new details will be used on the next self-billing invoices.

Follow these steps:

{% stepper %}
{% step %}
### Go to Companies <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**.
*   Open the **Companies** tab.

    <figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fs9ED1QQXJQhiuEk3Y7el%252Fimage.png%3Falt%3Dmedia%26token%3Dbabad01e-4c52-45a5-8290-6cc9696c7b71&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=828913b3&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Edit the details

* Click the company's **ID**.
*   Select <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Change the tax details you need.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

> **Important:** <mark style="background-color:$danger;">don't change the **Invoice Number Format** field.</mark>

<figure><img src="../../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}
