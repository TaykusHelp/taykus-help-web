# How to create a product type

Product types are used to group the club's products into families. This makes them easier to find and then analyse in sales reports and statistics.

Follow these steps:

{% stepper %}
{% step %}
### Go to Product types

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**.
*   Open the **Product types** tab.<br>

    <figure><img src="../../.gitbook/assets/image (93).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a product type

* Click :heavy\_plus\_sign:.
*   A window opens. Enter the name of the new family or subfamily.

    <div align="left"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>
* Click **Save**.
{% endstep %}
{% endstepper %}

## Change a product type <a href="#modificar-un-tipo-de-producto" id="modificar-un-tipo-de-producto"></a>

* Click the **ID** of the product type you want to change.
* Click the edit icon <i class="fa-pen" style="color:green;">:pen:</i>.
* Make the changes.
* Click **Save**.
