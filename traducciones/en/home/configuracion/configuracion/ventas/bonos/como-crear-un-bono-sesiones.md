# How to create a sessions voucher

A **sessions voucher** is a bundle of uses (for example, 10 classes). Each time the player uses it, the system deducts one session until they run out.

It's usually used for **classes, bookings or services counted by number of uses**.

Follow these steps:

{% stepper %}
{% step %}
### Go to Vouchers

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**.
*   Open the **Vouchers** tab.<br>

    <figure><img src="../../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the voucher

* Click :heavy\_plus\_sign:.
* The voucher form opens:

{% step %}
### General details

* **Logo:** image to recognise the voucher in the system and in online sales.
* **Name:** the name players and club staff will see. For example: _10 classes voucher_ or _5 sessions voucher_.
* **Gross price:** final price of the voucher, including taxes.
* **Net price:** price without taxes. It's calculated automatically from the tax type.
* **Tax type:** the tax applied to the voucher sale.
* **Details:** optional text to explain the voucher's conditions.
{% endstep %}

{% step %}
### Where it's sold

* **Online sale:** tick it so the voucher can be bought on the club's website.
* **Trending:** highlights the voucher in online sales as a recommended option.
* **Popular:** marks the voucher as a popular option.
* **POS sale:** tick it so you can sell it from the POS.
* **POS quick access:** the voucher appears in the POS quick-access items.
{% endstep %}

{% step %}
### Type and quantity

* **Voucher type:** select **Sessions Voucher**.
* **Description:** optional internal text.
* **Quantity type:** select **Units**, because the voucher is used up by number of sessions.
* **Amount to fill:** the number of sessions in the voucher (for example, 5, 10 or 20). Each use deducts one.
{% endstep %}

{% step %}
### Validity

* **Days until expiry:** days until the voucher expires, counting from when it's bought or activated.
* **Days of valid use:** days during which the voucher can be used once activated.
* **Validity start date:** the date from which the voucher can be used.
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}

> **Important:** these fields are required to save the voucher: **Name**, **Gross price**, **Tax type**, **Voucher type**, **Quantity type** and **Amount to fill**.

Once saved, the voucher can be sold or assigned to players from the POS or from their profile, and it's deducted as they use it.
