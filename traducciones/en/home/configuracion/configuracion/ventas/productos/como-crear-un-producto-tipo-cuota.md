# How to create a Fee product

**Fee** products are charged regularly, such as a monthly fee, a quarterly fee or an annual subscription. Their form sets how often and how they're charged, so the system can manage recurring payments.

Follow these steps:

{% stepper %}
{% step %}
### Go to Products

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**. The **Products** tab opens directly.
{% endstep %}

{% step %}
### Create the product

* Click :heavy\_plus\_sign:.
* The product form opens:

<figure><img src="../../../.gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Fill in the details

* **Name:** a descriptive name for the fee.
* **Logo:** optional. Helps you recognise the product in the POS.
* **Category:** set to **Item** by default. Change it to **Fee**.
* **Product type:** choose one of the product types you've already created.
* **Gross price:** retail price.
* **Tax type:** 21% is shown by default. You can create others if you need to.
* **Brand:** optional. To record the brand or name of the fee.
* **Loyalty points:** amount loaded onto the customer's wallet voucher for each unit bought, in the smallest unit of your currency (for euros, cents). For example, if you enter 2, the customer gets 2 cents for each unit they buy.
* **Online sale:** tick it if it can be bought online.
* **POS sale:** tick it so you can charge for it at the till.
* **Frequency:** choose how often the fee is charged in the drop-down.
* **Prorate first:** tick it so that, when someone joins part-way through a period, the first charge is proportional.
* **Bank billing:** tick it if the fee is paid by direct debit.
* **Registration:** to add a registration or enrolment fee.

> The drop-downs only show five options. If you can't see the one you want, start typing its name.
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}
