# How to create a Service product

**Service** products have a duration, such as a padel booking, a class or a session. Their form sets how long they last, how much they cost and how they're sold, and the system uses them to work out booking availability and prices.

Follow these steps:

{% stepper %}
{% step %}
### Go to Products

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**. The **Products** tab opens directly.
{% endstep %}

{% step %}
### Create the product

* Click :heavy\_plus\_sign:.
* The product form opens:

<div align="left"><figure><img src="../../../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Fill in the details

* **Name:** a descriptive name for the service.
* **Logo:** optional. Helps you recognise the product in the POS.
* **Category:** set to **Item** by default. Change it to **Service**.
* **Product type:** choose one of the product types you've already created.
* **Gross price:** retail price.
* **Minutes:** the duration that price covers. For example, a 90-minute match for €30.
* **Tax type:** 21% is shown by default. You can create others if you need to.
* **Loyalty points:** amount loaded onto the customer's wallet voucher for each unit bought, in the smallest unit of your currency (for euros, cents). For example, if you enter 2, the customer gets 2 cents for each unit they buy.
* **Can be an extra:** tick it so you can add this service as a supplement.
* **Online sale:** tick it if it can be bought online.
* **POS sale:** tick it so you can charge for it at the till.

> The drop-downs only show five options. If you can't see the one you want, start typing its name.
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}

> **Important:** if a court has different prices depending on the time or use, create a service for each case: peak time, off-peak time, peak-time matches, off-peak matches, private lessons or lights if they're charged separately. That way each service has its own duration and price, and the system applies the right rate.
