# How to create an Item product

**Item** products are physical products, such as sports equipment, clothing or accessories. They can have stock control, so the system knows how many units are left and warns you when there are only a few.

Follow these steps:

{% stepper %}
{% step %}
### Go to Products

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**. The **Products** tab opens directly.
{% endstep %}

{% step %}
### Create the product

* Click :heavy\_plus\_sign:.
* The product form opens:

<figure><img src="../../../.gitbook/assets/image (51).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Fill in the details

* **Name:** a descriptive name for the item.
* **Logo:** optional. Helps you recognise the product in the POS.
* **Category:** set to **Item** by default. Leave it like that.
* **Product type:** choose one of the product types you've already created.
* **Brand:** optional. The item's brand.
* **Gross price:** retail price.
* **Tax type:** 21% is shown by default. You can create others if you need to.
* **Loyalty points:** amount loaded onto the customer's wallet voucher for each unit bought, in the smallest unit of your currency (for euros, cents). For example, if you enter 2, the customer gets 2 cents for each unit they buy.
* **Can be an extra:** tick it so you can add this item as a supplement.
* **Has stock:** tick it to keep stock control for the item.
* **Optimal stock:** the minimum number of units you want to have.
* **Low stock notification email:** if you enter an email address, you'll get a warning when stock drops below the optimal level.
* **Online sale:** tick it if it can be bought online.
* **POS sale:** tick it so you can charge for it at the till.

> The drop-downs only show five options. If you can't see the one you want, start typing its name.
{% endstep %}

{% step %}
### Save

* Click **Save**.
* The item appears in the product list and in the POS.
{% endstep %}
{% endstepper %}
