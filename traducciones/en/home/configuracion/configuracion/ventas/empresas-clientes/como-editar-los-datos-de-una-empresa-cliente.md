# How to edit a customer company's details

If a customer company's details change (address, tax ID, contact…), you can update them at any time. The new details will be used on future invoices.

Follow these steps:

{% stepper %}
{% step %}
### Go to Customer companies <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**.
*   Open the **Customer companies** tab.<br>

    <figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Edit the details

* Click the customer company's **ID**.
*   Select <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Change the details you need.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}
