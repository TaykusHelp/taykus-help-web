# Set custom booking prices by playing time

You can set a different price for a booking depending on its duration, without having to create a new product for each duration.

Follow these steps:

{% stepper %}
{% step %}
### Go to Products

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Sales**. The **Products** tab opens directly.
{% endstep %}

{% step %}
### Open the product

* Find the product you want to apply the special price to in the list.

> **Important:** choose the right product. For bookings there's usually one service per time slot (peak, off-peak…), so make sure you open the exact service and time slot you want to apply the price to.

*   Click its **ID**. The product's **General** tab opens.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure></div>
*   Open the **Special prices** tab.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Create the special price

* Click :heavy\_plus\_sign:.
*   A window opens where you only need to fill in these fields:<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure></div>

    * **Minutes:** the duration the new price applies to. For example, 60, 120 or 180.
    * **Gross price:** the new price, in numbers. If you want it to be free, enter 0.
* Click **Save**.
{% endstep %}
{% endstepper %}

> If you want a different price for each duration, create a special price for each one: one for 60 minutes, another for 120, another for 180… And if it should apply to several time slots or products, repeat the process for each one.
