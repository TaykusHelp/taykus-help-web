# How to specify which users are coaches

For a user to work as a coach (with training sessions, schedules and availability in the calendar), you need to link them to their coach resource.

Follow these steps:

{% stepper %}
{% step %}
### Go to Academies

* Click the <i class="fa-gear" style="color:blue;">:gear:</i> icon in the top right corner and go to **Settings**.
* Click **Academies**.
{% endstep %}

{% step %}
### Link the user to their resource

* You'll see all users in a table with two columns: **Name** and **Resource**.
*   Click the user's **Resource** column and choose their resource in the drop-down.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (63).png" alt=""><figcaption></figcaption></figure></div>

> **Important:** the drop-down shows both courts and coaches. Link each coach to **their own coach resource**.
{% endstep %}
{% endstepper %}
