# How to edit a template

You can change any email template, both the ones the club has created and Taykus's automatic ones (welcome, invoices, debt notifications…). The changes apply to emails sent from then on.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Email Templates

* Go to the left-hand menu and select **Communications**.
*   In the drop-down, choose **Email Templates**.

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Open the template

* Click the **Id** of the template you want to change. Automatic ones have the Id **0000**.
* The template opens, ready to edit.
{% endstep %}

{% step %}
### Change the template

*   Change whatever you need: the **Subject**, the **Topic** or the text in the **Message body**.

    <figure><img src="../.gitbook/assets/plantilla-editar.png" alt=""><figcaption></figcaption></figure>
* To add a customer detail, choose it in **Select replacement to insert**.

> **Important:** words in double square brackets, such as `[[CustomerName]]`, are replaced with each customer's details when the email is sent. If you delete them, that detail will no longer appear.
{% endstep %}

{% step %}
### Save

* Click **Save**.
{% endstep %}
{% endstepper %}

To create a new template, see [How to create a template](como-crear-una-plantilla.md).
