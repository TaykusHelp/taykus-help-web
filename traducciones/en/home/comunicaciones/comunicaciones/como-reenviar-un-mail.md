# How to resend an email

Taykus lets you send again any email the system has already sent to a customer (booking confirmations, tickets, fees…). This is useful, for example, when the customer says they didn't receive it or deleted it.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to the sent emails

* Go to the left-hand menu and select **Communications**.
*   In the drop-down, choose **Emails**. You'll see the list of emails sent by the system.<br>

    <figure><img src="../.gitbook/assets/reenviar-acceso-emails.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the email

* Find the email you want to resend. You can use the filter on each column, for example **Customer** or **Subject**.
* Tick the box to the left of the email. If you want to resend several at once, tick them all.
*   Click **Resend**, at the top of the list.<br>

    <figure><img src="../.gitbook/assets/reenviar-seleccionar-correo.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirm the resend

*   A window opens asking you to confirm:

    <figure><img src="../.gitbook/assets/reenviar-confirmar.png" alt=""><figcaption></figcaption></figure>
* Click **OK** to resend it, or **Close** if you don't want to resend it.
{% endstep %}

{% step %}
### Check the resend

* The email shows up again in the list with the status **Inserted** and **Attempts** at 0 while it's waiting to go out.
* Once it goes out again, its **Delivery status** changes to **Sent**.
{% endstep %}
{% endstepper %}

> **Important:** you can't change the email address from this screen. If the customer's address was wrong, first correct it in their profile and then resend the email: it will go to the new address.

To learn more about email statuses, see [Where to see the delivery status of emails](donde-ver-el-estado-de-envio-de-los-correos.md).
