# How to cancel a booking

Sometimes you need to cancel a booking because of the weather, court maintenance or because the players can't come. When you cancel it, you can choose whether the debt is also removed or kept.

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar <a href="#acceso-a-calendario" id="acceso-a-calendario"></a>

* Go to the left-hand menu and select **Calendar**.

<figure><img src="../../.gitbook/assets/image (71).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the booking

* Click the booking you want to cancel.
* A menu with several options opens.
* Hover over the cancel icon.

<figure><img src="../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Type of cancellation

* Two options appear:
  * **Cancel booking and debts:** removes the booking and the debt.
  * **Cancel booking but keep debts:** removes the booking but keeps the outstanding court payment. This is useful when a player cancels too late and you want to free up the court without losing the debt.
* Click the option you need.
* A confirmation message appears depending on the option you chose.
{% endstep %}

{% step %}
### Confirmation

<div align="left"><figure><img src="../../.gitbook/assets/image (75).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../../.gitbook/assets/image (76).png" alt=""><figcaption></figcaption></figure></div>

* If you have it set up, you can enter the **cancellation reason**. It's optional, but it helps you keep track of the most common reasons.
* Click **OK** to confirm. The booking is cancelled.
{% endstep %}
{% endstepper %}
