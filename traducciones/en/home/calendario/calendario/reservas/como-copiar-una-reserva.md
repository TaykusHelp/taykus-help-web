# How to copy a booking

Copying a booking lets you repeat it on another day, court or time without having to create it from scratch.

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar

*   Go to the left-hand menu and select **Calendar**.<br>

    <figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Copy the booking

* Click the booking you want to copy.
*   In the menu that opens, select **Copy**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Paste the copy

* The window closes.
* Click the day, court and time where you want to create the copy.
{% endstep %}
{% endstepper %}

> **Important:** before confirming, check the date, court and players of the new booking to avoid mistakes in the calendar.
