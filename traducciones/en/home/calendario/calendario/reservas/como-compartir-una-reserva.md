# How to share a booking

You can share any booking with the players, for example by WhatsApp, so they have all the information and the direct link to hand.

Follow these steps:

{% stepper %}
{% step %}
### Open the sharing options

* Click the booking.
* Go to the menu on the right.
*   You'll see two ways to share it, depending on what you need.

    <figure><img src="../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1: Share (ready-to-send message)

When you click **Share**, the system creates a formatted message that includes:

* Club name
* Match level
* Date and duration
* Location
* Available places
* Direct sign-up link

<div align="left"><figure><img src="../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure></div>

It's the best option for sending by WhatsApp, because it shows all the information clearly.
{% endstep %}

{% step %}
### Option 2: Copy link

When you click **Copy link**, the system copies only the direct link to the booking.

It's useful if:

* You want to write your own message.
* You're going to include it in a campaign or newsletter.
* You only need the link.
{% endstep %}
{% endstepper %}
