# How to see cancelled bookings

Cancelled bookings no longer appear in the calendar, but you can see them in the bookings list by filtering by their status.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Bookings

* Go to the left-hand menu and select **Calendar**.
* In the drop-down, choose **Bookings**. The **Booked Resources** list opens.
{% endstep %}

{% step %}
### Filter by cancelled

* Scroll right to the **Status** column.
*   In that column's filter, choose **Cancelled**.

    <figure><img src="../../.gitbook/assets/reservas-canceladas.png" alt=""><figcaption></figcaption></figure>
* The list shows only the cancelled bookings.
{% endstep %}
{% endstepper %}

To find out who cancelled a booking, click its **Id** and go to the **History** tab. See [How to see a booking's history](como-ver-el-historico-de-una-reserva.md).

So you don't have to set the filter every time, you can save the list as a favourite. See [How to save a list as a favourite](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/listados/como-guardar-un-listado-como-favorito).
