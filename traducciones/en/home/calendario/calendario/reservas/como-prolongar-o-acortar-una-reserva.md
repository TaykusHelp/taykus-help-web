# How to extend or shorten a booking

You can change the duration of a booking directly in the calendar, to lengthen or shorten the playing time or to block a court for more or less time.

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar

*   Go to the left-hand menu and select **Calendar**.<br>

    <figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Change the duration

* Click the booking and move to the top edge (to change the start time) or the bottom edge (to change the end time).
*   A double arrow appears, as in the image. Hold the mouse button down and drag up or down to the new duration.<br>

    <figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirm the change

*   When you let go, a confirmation window opens:

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>

    * **Update price:** recommended. Adjusts the amount to the new duration or time slot.
    * **Notify participants:** sends an email to the players to let them know about the change.
* Press **OK** to save the changes.
{% endstep %}
{% endstepper %}

> **Important:** check the new start and end times before confirming to avoid overlapping with other bookings.
