# How to share a match

Sharing a match is the quickest way to get more players to join so it fills up sooner.

Follow these steps:

{% stepper %}
{% step %}
### Open the sharing options

* Click the match.
* Go to the menu on the right.
*   You'll see two ways to share it, depending on what you need.

    <figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1: Share (ready-to-send message)

When you click **Share**, the system creates a formatted message that includes:

* Club name
* Match level
* Date and duration
* Location
* Available places
* Direct sign-up link

It's the best option for sending by WhatsApp, because it shows all the match information clearly.

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 2: Copy link

When you click **Copy link**, the system copies only the direct link to the match.

It's useful if:

* You want to write your own message.
* You're going to include it in a campaign or newsletter.
* You only need the link.
{% endstep %}
{% endstepper %}
