# How to change the time or duration of multiple bookings

You can change the start time or duration of many bookings at once, for example because the club's opening hours or court availability have changed. The change can apply to the whole multiple booking or only to a period.

Follow these steps:

{% stepper %}
{% step %}
### Open the multiple booking

* Go to the left-hand menu and select **Calendar**.
*   Click **Multiple Bookings**.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Find the multiple booking you want to change and click its **ID**.
* You'll see the list of all the bookings that are part of it.

<figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the bookings

* **To change all the bookings:** click **ID** in the header to select them all.
* **To change only one date or period:** first filter by the **Start** column:
  * Click the three horizontal lines in the column.
  *   Choose **Greater than** to change the bookings from a certain date.

      <figure><img src="../../../.gitbook/assets/image (114).png" alt=""><figcaption></figcaption></figure>
  * Or choose **In range** to change the bookings between two dates.
  * Then select the filtered bookings.
{% endstep %}

{% step %}
### Change the time or duration

* With the bookings selected, click **Actions**.
*   Select **Change time/duration**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (115).png" alt=""><figcaption></figcaption></figure></div>
*   In the window that opens, change:<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (116).png" alt=""><figcaption></figcaption></figure></div>

    * The **start time**.
    * The booking **duration**.
* Tick **Update price** to adjust the amount to the new time or duration.
* If you want to let the players know, tick **Notify participants**.
* Click **OK**.
{% endstep %}
{% endstepper %}

The system checks availability before applying the changes. If any booking can't be changed because the court isn't free at the new time or for the new duration, a window with the errors appears:

<div align="left"><figure><img src="../../../.gitbook/assets/image (117).png" alt=""><figcaption></figcaption></figure></div>

In that case you can:

* Save the valid changes.
* Discard the bookings with errors.

Once confirmed, the time or duration is updated in the selected bookings.
