# How to cancel future bookings in a multiple booking

If a multiple booking has already started, you can cancel just the bookings still to be played and keep the ones that have already taken place. This is useful when a player stops coming, a regular schedule changes or the club needs to free up upcoming dates without touching the history.

### Explainer video

{% embed url="https://youtu.be/ehAQhAR0FKU" %}

Follow these steps:

{% stepper %}
{% step %}
### Go to the Multiple Bookings list

* Go to the left-hand menu and select **Calendar**.
*   In the drop-down, click **Multiple Bookings**.<br>

    <figure><img src="../../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Filter the future bookings

* Find the multiple booking in the list and click its **ID**.
* You'll see all the bookings that are part of it.
* Go to the **start date** column.
*   Select **Greater than** and enter the date from which you want to cancel.<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the bookings

* Check that the filter has been applied correctly.
*   Click **ID** in the header to select all the filtered bookings.

    <figure><img src="../../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Type of cancellation

* With the bookings selected, click the **Cancel** button.
*   Two options appear:

    <div align="left"><figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>

    * **Cancel booking and debts:** removes the booking and the debt.
    * **Cancel booking but keep debts:** removes the booking but keeps the outstanding court payment. This is useful when a player cancels too late and you want to free up the court without losing the debt.
* Click the option you need.
* A confirmation message appears depending on the option you chose.\
  ![](<../../../.gitbook/assets/image (9).png>)![](<../../../.gitbook/assets/image (10).png>)
{% endstep %}

{% step %}
### Confirmation

* Confirm to cancel the selected bookings.

> **Important:** before confirming, check that the filter only includes future bookings. That way you won't cancel (or refund) bookings you don't want to touch.
{% endstep %}

{% step %}
### Result

*   The bookings change from **Booked** to **Cancelled**.<br>

    <figure><img src="../../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Important:** the bookings **are not deleted from the system**: they just change to **Cancelled** and still appear in the lists. To avoid confusion, we recommend renaming the multiple booking to **CANCELLED**.
