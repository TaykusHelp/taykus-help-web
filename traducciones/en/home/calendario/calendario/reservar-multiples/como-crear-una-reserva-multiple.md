# How to create a multiple booking

A **multiple booking** creates several bookings at once. It's very useful when a player wants a regular court for a period (for example, every Tuesday) or when the club needs to block several courts for tournaments, classes or events.

In a single multiple booking you can choose several **resources**, **dates**, **days** and **times**.

### Explainer video

{% embed url="https://youtu.be/Wf7-vtLXeM0" %}

Follow these steps:

{% stepper %}
{% step %}
### Go to the Multiple tab

* Go to the left-hand menu and select **Calendar**.
* Click the **day**, **court** and **time** where you want the booking to start.
*   Choose the **booking type**.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
* Open the **Multiple** tab.

<div align="left"><figure><img src="../../.gitbook/assets/image (57).png" alt="" width="274"><figcaption></figcaption></figure></div>

In this tab you set the resources, duration and times of the multiple booking.

<figure><img src="../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the resources

* Press the :heavy\_plus\_sign: button\
  ![](<../../.gitbook/assets/image (1).png>)
* A window opens where you choose the courts or facilities you want to book.

<figure><img src="../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

* Tick the resources and press **OK**.
{% endstep %}

{% step %}
### Enter dates and description

* **Start date:** the day the multiple booking starts.
* **End date:** the last day the booking repeats.
* **Description:** a name so you can recognise the multiple booking.

<figure><img src="../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select days and times

* Choose the booking **time**.
* Press the **+** button to add that time slot.
*   Tick the **days of the week** on which it will repeat.<br>

    <figure><img src="../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure>
* Repeat the process if you need other days or times.

> **Important:** after choosing the time, you must press the **+** button. If you don't add the time slot with this button, the system won't let you save the multiple booking, even if you tick the days.
{% endstep %}

{% step %}
### Check availability

*   Before saving, press the button to check availability.<br>

    <figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
* This shows you whether the resources are free on the chosen dates and times.
* Any that aren't available are marked in red.\
  ![](<../../.gitbook/assets/image (3).png>)
{% endstep %}

{% step %}
### Save the multiple booking

* Once you've checked availability, save the multiple booking.
* The system creates all the bookings according to the resources, days and times you set.
* If any can't be created because there's no availability, check the resources marked in red and change your selection.
{% endstep %}
{% endstepper %}

Once saved, you'll see all the bookings in the calendar and can view and manage them whenever you need.
