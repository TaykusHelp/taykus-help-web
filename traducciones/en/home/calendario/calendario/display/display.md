# Display

The display is a screen you can put up at the club to show players and visitors the day's matches: times, players and court number. As well as being very practical, it gives the club a more modern and professional image.

## How to open the display

{% stepper %}
{% step %}
### Open the display

* Click **Calendar** in the left-hand menu. A drop-down opens with two options:
  * **Display: 1 column**
  * **Display: 2 columns**

<div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Choose the format

* Select the option you prefer depending on how you want the screen to look.
* The display opens in a new tab. That's the tab you need to show on the club's screen.
{% endstep %}
{% endstepper %}

## How to show only the players' initials

If you'd rather not show participants' full names on the screen, you can set up the display to show only their initials.

{% stepper %}
{% step %}
### Go to booking settings

* Click the <i class="fa-gear">:gear:</i> icon in the top right corner.
* Click **Settings** again.
* Select **Bookings**.

<div align="left"><figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Select the sport

* In the **Resource group** column, click the ID of the sport you want to show on the screen.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Turn on initials

* The general settings for that sport open.
* Tick the **Show participants' initials** box.

<div align="left"><figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
