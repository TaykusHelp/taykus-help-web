# How to close a court

Closing a court blocks it for a whole day so that no bookings can be made on it. This is especially useful on public holidays, for internal club events, maintenance or any other operational reason.

Follow these steps:

{% stepper %}
{% step %}
### Go to Calendar

* Go to the left-hand menu and select **Calendar**.
{% endstep %}

{% step %}
### Select the date

* Select the day you want to close.

<figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

* When you click the day, the calendar takes you straight to that date.
{% endstep %}

{% step %}
### Close the court

* Click the name of the court.
* The following menu opens:

<div align="left"><figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure></div>

* Select **Close whole day**.
{% endstep %}
{% endstepper %}

> **Important:** the closure only applies to the selected court. If you need to close more courts on the same day, repeat the process for each of them.
