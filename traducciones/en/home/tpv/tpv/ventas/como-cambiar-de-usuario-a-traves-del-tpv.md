# How to switch user from the POS

**Switching user** in the POS lets staff quickly swap over when several people use the same terminal. This makes sure each transaction is recorded under the right user, making it easier to control sales and track activity at the till without logging out or interrupting the workflow.

In this article we show you how to use this option step by step.

{% stepper %}
{% step %}
### Go to the POS

* Go to the left-hand menu and select **POS.**
{% endstep %}

{% step %}
### Switch user

*   Click the **Switch user** button.

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the user

*   A window opens with all the available users.<br>

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
* Click the user you want.
* Another window opens for you to enter the password.

<div align="left"><figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure></div>

* Click OK to switch user.
{% endstep %}
{% endstepper %}

Using the **Switch user** feature correctly helps keep an orderly record of activity in the POS and ensures each transaction is linked to the right person. Making it a daily habit improves cash register control and avoids confusion between shifts.
