# How to resume a parked sale

Resuming a parked sale lets you pick up a paused transaction without losing the information already entered. This is useful for continuing the payment when a customer comes back or when a transaction at the till has been interrupted. Here's how to resume a parked sale step by step.

{% stepper %}
{% step %}
### Go to the POS

* Go to the left-hand menu and select **POS**.
{% endstep %}

{% step %}
### Open parked sales

*   At the top of the screen, click **Parked sales**.<br>

    <figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the sale

* A window opens with all the parked sales.
*   Choose the sale you want to resume.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Complete the sale

* Continue with the payment using the customer's preferred payment method.
{% endstep %}
{% endstepper %}

Once the sale has been resumed, you can complete the payment as normal. Using parked sales correctly helps keep the POS organised and avoids losing information during the day.
