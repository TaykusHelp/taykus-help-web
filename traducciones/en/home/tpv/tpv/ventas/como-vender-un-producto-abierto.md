# How to sell an open product

Having a POS tool that lets you sell products that aren't registered in the system is very useful, especially for occasional products that won't be available regularly.&#x20;

Here's how to make a sale with an open product:

{% stepper %}
{% step %}
### Go to the POS

* Go to the left-hand menu and select **POS**, or click the booking and select **Pay booking**. Both options take you to the POS.
{% endstep %}

{% step %}
### Find the player or customer

*   If you're not paying for a booking and haven't already selected the player, use the search box in the top right corner to find them.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   If it's a one-off sale and no details will be recorded, select **Anonymous customer**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Select the product

* If it isn't a booking, choose the product you want to sell from the list.
{% endstep %}

{% step %}
### Add an open product

*   Click **Open Price.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
*   The following window pops up for you to fill in.<br>

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    * **Description:** Enter the name you want to give this product or sale.
    * **Price:** Set the price you want to give this product or sale.
    * **Product type:** select a category in the drop-down if you want to classify this open product. This field is optional.
    * **Taxes:** select the tax rate to apply to this open product.
* Click **OK** to add this charge to the ticket.
{% endstep %}

{% step %}
### Check and take payment

* Make sure the open product has been added correctly to the ticket.
* Take the payment using the customer's preferred payment method.<br>
{% endstep %}
{% endstepper %}

Once the open product has been added, you can continue the sale and take the payment as normal. This feature lets you record custom amounts without changing the product catalogue, keeping control of the ticket and the cash register.
