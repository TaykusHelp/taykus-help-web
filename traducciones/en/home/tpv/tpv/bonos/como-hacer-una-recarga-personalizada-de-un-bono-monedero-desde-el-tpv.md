# How to make a customised wallet voucher top-up from the POS

Customised wallet voucher top-ups let you add a specific amount to suit the customer's needs, without relying on preset values. This gives you more flexibility in managing balances and is automatically recorded in the system.&#x20;

Here's how to make a customised top-up step by step.

{% stepper %}
{% step %}
### Go to the POS

* Go to the left-hand menu and select **POS**.
{% endstep %}

{% step %}
### Find the player or customer

*   Use the search box in the top right corner to find the player you want.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Select Vouchers

*   Click the Vouchers option, below the quick-access items.

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Customise the top-up

* A window opens with all the available vouchers.
* Select **any of the vouchers** you've already set up.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Click Customise top-up.
*   A drop-down opens with the details of the selected voucher, which you can change.

    <figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>
* **Customise Top-up:**
  * **Price:** the new amount to charge for the top-up.
  * **Voucher type:** select the right voucher type in the drop-down.
  * **Quantity type:** choose the type of balance you're going to top up in the drop-down.
  * **Amount to top up:** enter the amount you want to add (for example, €100 or 10 units).
  * **Description:** optional comment to note the reason for the customised top-up.
* **Customise Restrictions:**
  * This section isn't required, but you can customise the voucher's restrictions.
* Click OK to save the customisation.
{% endstep %}

{% step %}
### Complete the top-up

* Take the payment using the customer's preferred payment method.
* If the voucher top-up is left pending payment or direct debit, the balance isn't added to the customer's voucher until it has been paid.
{% endstep %}
{% endstepper %}

Once the top-up is confirmed, the customised balance is available on the voucher straight away. Recording these operations correctly ensures precise control of transactions and of the customer's history.
