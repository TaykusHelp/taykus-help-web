# How to top up a voucher from the POS

Topping up a wallet voucher from the POS lets you add balance immediately so the customer can use it for future purchases or bookings. The process is automatically recorded in the system and makes prepayments easier to manage.&#x20;

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to the POS

* Go to the left-hand menu and select **POS**.
{% endstep %}

{% step %}
### Find the player or customer

*   Use the search box in the top right corner to find the player you want.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Select Vouchers

*   Click the Vouchers option, below the quick-access items.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the voucher you want

* A window opens with all the available vouchers.
* Select the voucher you want to top up from the ones you've already set up.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* If you need to make a specific change for this customer, you can **Customise the top-up**; to find out how, see this article:\
  <a href="como-hacer-una-recarga-personalizada-de-un-bono-monedero-desde-el-tpv.md" class="button primary">How to make a customised wallet voucher top-up from the POS</a><br>
{% endstep %}

{% step %}
### Complete the top-up

* Take the payment using the customer's preferred payment method.
* If the voucher top-up is left pending payment or direct debit, the balance isn't added to the customer's voucher until it has been paid.
{% endstep %}
{% endstepper %}

Once the top-up has been made, the balance is available to use straight away. Recording these operations correctly ensures precise control of the wallet and of the cash register transactions.
