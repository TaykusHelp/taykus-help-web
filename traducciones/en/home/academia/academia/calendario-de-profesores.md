# Coaches' calendar

The coaches' calendar shows each coach's monthly schedule. From here you can see all their classes, bookings and assigned times at a glance. The system also calculates the total hours worked and the monthly average, which makes it easier to control workloads and plan the team better.

To see this information, follow these steps:

{% stepper %}
{% step %}
### Go to Academy

* Go to the left-hand menu and click Academy.
{% endstep %}

{% step %}
### Go to Coaches' Calendar

*   In the drop-down, select **Coaches' Calendar.**<br>

    <figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select coaches

*   Click the box in the middle that says **Select Resources.**<br>

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
* Select the name of the coach or coaches you want to see. You can select more than one.
{% endstep %}

{% step %}
### Select the calendar view

*   The default view is **weekly**.

    <figure><img src="../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
*   But there's also a **monthly** view:

    <figure><img src="../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>
*   And an **agenda** view:

    <figure><img src="../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### View metrics in the Coaches' Calendar

The calendar shows different metrics depending on **the selected view** (Daily, Weekly or Monthly) and **the number of coaches** you choose in the filter.

When you select one or more coaches, the system automatically calculates:

* **Occupancy percentage**
* **Total number of hours assigned**
* **Total participants**
* **Average hours per resource (coach)**

The information always adapts to the view:

* **Daily view** → metrics for the selected day.
* **Weekly view** → metrics for that week.
* **Monthly view** → summary of the whole month.

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

If you select **a single coach**, the metrics are shown only for them. If you select **several**, the system calculates them together for the filtered group.\
<br>
{% endstep %}
{% endstepper %}
