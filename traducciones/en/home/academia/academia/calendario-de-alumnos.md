# Students' calendar

In this article we explain step by step how to set up permissions so that each coach only sees their own calendar with their assigned students. This feature is designed to give a clearer, more secure and more personalised experience in our sports management program. By limiting visibility to the relevant groups and times only, you avoid information overload, protect data privacy and greatly improve the internal organisation of your coaching team.

To do this, follow these steps:

{% stepper %}
{% step %}
### Create the resource

* To find out how to create a resource, follow this link:\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/reservas/grupo-de-recursos/como-crear-un-recurso" class="button primary" data-icon="tennis-ball">How to create a resource</a>
{% endstep %}

{% step %}
### Create the user

* To find out how to create a user, follow this link:\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/usuarios/como-crear-un-usuario" class="button primary" data-icon="user-plus">How to create a user</a>
{% endstep %}

{% step %}
### Specify which users are coaches

* To find out how to mark a user as a coach, follow this link:\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/academia/como-especificar-que-usuarios-son-entrenadores" class="button primary" data-icon="medal">How to specify which users are coaches</a>
{% endstep %}
{% endstepper %}

Once all these steps have been completed, give the coach the following login URL, with which they can only see their own classes and take attendance for their students:

<mark style="background-color:yellow;">**Clubname**</mark>_.taykus.com/teachers/login_

<sub>_**\* Enter the club's name**_</sub>

This is what the coach sees from their user account, where they can mark students' attendance and see days, times, court, etc.<br>
