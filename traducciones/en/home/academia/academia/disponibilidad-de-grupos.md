# Group availability

The **Group availability** section lets you find the available academy groups using different search criteria, such as dates, days of the week, resources or level.

This tool is useful when the club needs to quickly find an active group, check its availability or add a student to a specific group without manually going through the whole academy calendar.

From this screen you can apply filters, see the groups that match your search and use the actions available for each of them.

{% stepper %}
{% step %}
### Go to Group availability

* Open the left-hand menu.
* Go to **Academy**.
* Click **Group availability**.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FLhYAxVU5CxyabXNEgArt%252Fimage.png%3Falt%3Dmedia%26token%3D2a2bcb2c-1283-4c7d-b471-a326cf7f503f\&width=768\&dpr=3\&quality=100\&sign=45d66402\&sv=2)

Once inside, you'll see the search screen and the list of available groups.
{% endstep %}

{% step %}
### Search criteria

At the top of the screen you'll find the filters for narrowing down your search.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FUshFUAGquodInGbtv5Ki%252Fimage.png%3Falt%3Dmedia%26token%3Dcf213e40-7cb3-4675-a6ed-40315f96ec2b\&width=768\&dpr=3\&quality=100\&sign=55ec3a09\&sv=2)

**Dates**

You can enter a date range using the fields:

* **From**
* **To**

These fields let you search for groups available within a specific period.

**Days of the week**

You can also select one or more days of the week:

* Mon
* Tue
* Wed
* Thu
* Fri
* Sat
* Sun

This way, you can find groups with availability on specific days.

**Resources**

The **Resources** field lets you filter by the court, facility or resource linked to the group.

**Level**

The **Level** field lets you search for groups by their assigned level, making it easier to find suitable groups for a particular student.
{% endstep %}

{% step %}
### Search for available groups

Once you've applied the filters you need, click **Search**.

The system shows the groups that match your criteria in the list below.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FUL6zF6Duexel6ebun107%252Fimage.png%3Falt%3Dmedia%26token%3Db48d1e8c-b4c4-4f48-88b8-f6b888ac87b0\&width=768\&dpr=3\&quality=100\&sign=87f0898c\&sv=2)

The list shows information such as:

* **ID**
* **Group name**
* **Season**
* **Start date**
* **End date**
* **Details**

This lets you quickly see which groups are available and during which period they are active.
{% endstep %}

{% step %}
### Add a student to a group

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FDWLYuM20q5jZ6kvXmHov%252Fimage.png%3Falt%3Dmedia%26token%3D6540d8f4-a11d-483c-8c25-c19bb029d931\&width=768\&dpr=3\&quality=100\&sign=44ac800f\&sv=2)



* Find the group you want to add the student to.
* Select the group in the list.
* Click **Add Student to Group**.
* A pop-up window opens with the name of the selected group.
* In the **Search Student** field, search for and select the student you want to add.
* If needed, enter an **End Date** to set how long the student will be in the group.
* Select the days the student will attend the group.
* Click **OK** to confirm.

If you don't want to go ahead, you can close the window by clicking **Close** or the **X** in the top right corner.

> **Important:** before confirming, check that the group shown in the window is the right one and that the selected days match the student's attendance. This way you won't add them to the wrong group or days.
{% endstep %}
{% endstepper %}

The **Group availability** section lets you quickly find the academy groups that meet specific search criteria.

Using the date, day, resource and level filters, the club can see the available groups and add students more quickly and in an organised way. Before taking any action, it's always a good idea to check the selected group to make sure it matches the availability you want.
