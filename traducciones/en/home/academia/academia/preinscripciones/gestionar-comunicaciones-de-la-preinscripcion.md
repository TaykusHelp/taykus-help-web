# Manage pre-registration communications

The **Communications** section lets you review and change the message templates the system sends automatically to students during pre-registration for the school or academy.

These communications tell the user the status of their request, for example when they register successfully or when their pre-registration is cancelled.

The club can edit these messages to match its own style or add extra information for students.

{% stepper %}
{% step %}
### Go to the Communications section

* Go to the left-hand menu and click **Academy**.
* In the drop-down, select **Pre-registrations**.
* Select the ID of the **pre-registration** you want to manage.
*   At the top, click the **Communications** tab.<br>

    <figure><img src="../../.gitbook/assets/image (31).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Review the available templates

This section shows the automatic message templates the system sends to students during pre-registration.

*   **Pre-registration confirmation:** message the student receives when they register successfully.

    <figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
*   **Pre-registration cancellation:** message sent when a request is cancelled.

    <figure><img src="../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>



These communications are sent automatically according to the status of the request.
{% endstep %}

{% step %}
### Edit a message template

If you want to change any of these messages:

* Select the template you want to edit.
* Make the changes you need to the message.
* Click **Save** to apply the changes.
{% endstep %}
{% endstepper %}

By customising the communications, the club can adapt the automatic messages sent to students and keep them informed during pre-registration.
