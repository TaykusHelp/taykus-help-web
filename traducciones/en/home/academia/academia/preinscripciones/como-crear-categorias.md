# How to create categories

**Categories** let you organise students within an academy pre-registration according to different criteria, such as level, group or format.

This is useful for structuring registration requests and makes it easier later to assign students to the academy's different groups or levels.

In this article we explain how to create them.

{% stepper %}
{% step %}
### Go to the Categories section

* Go to the left-hand menu and click **Academy**.
* In the drop-down, select **Pre-registrations**.
* Select the ID of the **pre-registration** you want to manage.
*   At the top, click the **Categories** tab.

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a new category

* In this section, click **+**.
*   A window opens where you need to fill in the following field:<br>

    <figure><img src="../../.gitbook/assets/Captura de pantalla 2026-03-13 124035.png" alt=""><figcaption></figcaption></figure>



    * **Name:** Enter the name of the category or level (for example: Beginner, Intermediate, Advanced or any other level in the academy).
* Once you've entered the name, click **Save** to create the category.
{% endstep %}

{% step %}
### Add more categories

You can repeat this process as many times as you need to create all the categories or levels available in the pre-registration.

These categories let you **classify students according to the level or group they want to join**, making it easier to organise the academy later.
{% endstep %}
{% endstepper %}

Once the categories have been created, students can select them when they pre-register, so the club can organise and manage requests in a more structured way.
