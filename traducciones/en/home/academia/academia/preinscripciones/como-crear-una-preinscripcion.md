# How to create a pre-registration

Pre-registrations let you collect interest from new students before assigning them to a group or coach, so you can manage demand in an organised way. This module helps the club plan places, times and levels in advance, avoiding overcrowding and keeping the information structured from the start. With this first step, it's easier to review requests and confirm registrations quickly and in a controlled way.

In this article we show you how to set them up.

{% stepper %}
{% step %}
### Go to Pre-registrations

* Go to the left-hand menu and click Academy.
*   In the drop-down, select **Pre-registrations.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a pre-registration

* Click :heavy\_plus\_sign:
*   A window pops up that you need to fill in as follows:

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

    * **Name:** The title of the pre-registration for the academy group.
    * **Poster:** click "browse" to select an image to show on the website.
    * **Description:** Space to add extra information.
    * **Sport:** a drop-down opens where you select the sport.
    * **Product:** Select a previously created product **in the ITEM category.** This is the price that will be assigned to this course.
      * _To create Item products, see the following article:_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary" data-icon="box">How to create an Item product</a>
    * **Comments:** space to add an internal note.
    * **Participants:** Sets the number of people who can fill in the form.
    * **Start:** Start date of the course/school/academy.
    * **End:** End date of the course/school/academy.
    * **Registration from:** Date registration opens.
    * **Registration until:** Date registration closes.
    * **Maximum Number of Participants:** Sets the maximum number of people who can take part.
    * **Online:** This box only makes the course visible on the website. Nothing else. It doesn't open registration or change how it's managed.
    * **Online registration:** Lets users access the pre-registration from the website. Without this ticked, the course is only shown and doesn't accept registrations.
* Click Save to keep your changes.
{% endstep %}

{% step %}
### Pre-registration settings

Once the pre-registration has been created and saved, new sections become available so you can finish setting it up and manage the students' requests.

The following tabs appear at the top:<br>

<figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

* **Activity:** Lets you review or change the general information of the pre-registration.
* **Participants:** Here you can see and manage the registration requests made by students.\
  _&#x54;o find out how to manage it, click the following link:_\
  <a href="gestionar-participantes-en-preinscripciones.md" class="button primary" data-icon="users">Manage pre-registration participants</a>
* **Categories:** Lets you organise pre-registrations into categories or levels within the academy.\
  _&#x54;o find out how to create them, click the following link:_\
  <a href="como-crear-categorias.md" class="button primary" data-icon="list">How to create categories</a>
* **Customise Registration:** Lets you set up the fields that users will fill in on the registration form.\
  _&#x54;o find out how to customise it, click the following link:_\
  <a href="personalizar-formulario-de-inscripcion.md" class="button primary" data-icon="file-pen">Customise the registration form</a>
* **Communications:** Where you set up the messages or notifications related to the pre-registration.\
  _&#x54;o find out how to set it up, click the following button:_\
  <a href="gestionar-comunicaciones-de-la-preinscripcion.md" class="button primary" data-icon="envelope-open-text">Manage pre-registration communications</a>
* **Fees:** Lets you set the fees or payments linked to the activity.
* **Sales:** Shows the information about payments or sales generated by registrations.
{% endstep %}
{% endstepper %}

Once these sections are set up, the pre-registration is ready to receive requests from students through the website or to be managed directly from the club's system.
