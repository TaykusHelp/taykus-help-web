# Pre-registrations

{% tabs %}
{% tab title="Activity" %}
## How to create a pre-registration

Pre-registrations let you collect interest from new students before assigning them to a group or coach, so you can manage demand in an organised way. This module helps the club plan places, times and levels in advance, avoiding overcrowding and keeping the information structured from the start. With this first step, it's easier to review requests and confirm registrations quickly and in a controlled way.

In this article we show you how to set them up.

{% stepper %}
{% step %}
### Go to Pre-registrations

* Go to the left-hand menu and click Academy.
*   In the drop-down, select **Pre-registrations.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a pre-registration

* Click :heavy\_plus\_sign:
*   A window pops up that you need to fill in as follows:

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

    * **Name:** The title of the pre-registration for the academy group.
    * **Poster:** click "browse" to select an image to show on the website.
    * **Description:** Space to add extra information.
    * **Sport:** a drop-down opens where you select the sport.
    * **Product:** Select a previously created product **in the ITEM category.** This is the price that will be assigned to this course.
      * _To create Item products, see the following article:_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary" data-icon="box">How to create an Item product</a>
    * **Comments:** space to add an internal note.
    * **Participants:** Sets the number of people who can fill in the form.
    * **Start:** Start date of the course/school/academy.
    * **End:** End date of the course/school/academy.
    * **Registration from:** Date registration opens.
    * **Registration until:** Date registration closes.
    * **Maximum Number of Participants:** Sets the maximum number of people who can take part.
    * **Online:** This box only makes the course visible on the website. Nothing else. It doesn't open registration or change how it's managed.
    * **Online registration:** Lets users access the pre-registration from the website. Without this ticked, the course is only shown and doesn't accept registrations.
* Click Save to keep your changes.
{% endstep %}

{% step %}
### Pre-registration settings

Once the pre-registration has been created and saved, new sections become available so you can finish setting it up and manage the students' requests.

The following tabs appear at the top:<br>

<figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

* **Activity:** Lets you review or change the general information of the pre-registration.
* **Participants:** Here you can see and manage the registration requests made by students.\
  _&#x54;o find out how to manage it, click the following link:_\
  <a href="gestionar-participantes-en-preinscripciones.md" class="button primary" data-icon="users">Manage pre-registration participants</a>
* **Categories:** Lets you organise pre-registrations into categories or levels within the academy.\
  _&#x54;o find out how to create them, click the following link:_\
  <a href="como-crear-categorias.md" class="button primary" data-icon="list">How to create categories</a>
* **Customise Registration:** Lets you set up the fields that users will fill in on the registration form.\
  _&#x54;o find out how to customise it, click the following link:_\
  <a href="personalizar-formulario-de-inscripcion.md" class="button primary" data-icon="file-pen">Customise the registration form</a>
* **Communications:** Where you set up the messages or notifications related to the pre-registration.\
  _&#x54;o find out how to set it up, click the following button:_\
  <a href="gestionar-comunicaciones-de-la-preinscripcion.md" class="button primary" data-icon="envelope-open-text">Manage pre-registration communications</a>
* **Fees:** Lets you set the fees or payments linked to the activity.
* **Sales:** Shows the information about payments or sales generated by registrations.
{% endstep %}
{% endstepper %}

Once these sections are set up, the pre-registration is ready to receive requests from students through the website or to be managed directly from the club's system.
{% endtab %}

{% tab title="Participants" %}
## Manage the participants of a pre-registration

The **Participants** section lets you see and manage everyone registered in a pre-registration. From here you can review the information for each registration, add manual notes or export the full list of participants.

This gives the club clear control over attendees and access to the information collected during registration.

{% stepper %}
{% step %}
### Go to the Participants section

* Go to the left-hand menu and open **Academy**.
* Click **Pre-registrations**.
* Click the ID of the pre-registration you want to manage.
* At the top, click the **Participants** tab.

![](../../.gitbook/assets/image)
{% endstep %}

{% step %}
### View and manage participants

In this section you can see the full list of people registered.

From here you can:

* Review each participant's information.
* Check the details collected on the registration form.
* Add **manual comments or notes** if you need to record extra information.

This keeps all the information about participants organised in one place.
{% endstep %}

{% step %}
### Export the list of participants

If you need to work with the information outside the system, you can export the list of participants.

*   Click ID to select all the participants.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
*   Select export and choose the download format.<br>

    <figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
* The download then starts and you'll find the file in your downloads folder.
{% endstep %}
{% endstepper %}

This way, the club can easily view and manage all the registrations made in the academy pre-registration. The Participants section brings together the information collected during registration and also lets you export it to review or process it elsewhere when needed.
{% endtab %}

{% tab title="Categories" %}
## How to create categories

**Categories** let you organise students within an academy pre-registration according to different criteria, such as level, group or format.

This is useful for structuring registration requests and makes it easier later to assign students to the academy's different groups or levels.

In this article we explain how to create them.

{% stepper %}
{% step %}
### Go to the Categories section

* Go to the left-hand menu and click **Academy**.
* In the drop-down, select **Pre-registrations**.
* Select the ID of the **pre-registration** you want to manage.
*   At the top, click the **Categories** tab.

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a new category

* In this section, click **+**.
*   A window opens where you need to fill in the following field:<br>

    <figure><img src="../../.gitbook/assets/Captura de pantalla 2026-03-13 124035.png" alt=""><figcaption></figcaption></figure>



    * **Name:** Enter the name of the category or level (for example: Beginner, Intermediate, Advanced or any other level in the academy).
* Once you've entered the name, click **Save** to create the category.
{% endstep %}

{% step %}
### Add more categories

You can repeat this process as many times as you need to create all the categories or levels available in the pre-registration.

These categories let you **classify students according to the level or group they want to join**, making it easier to organise the academy later.
{% endstep %}
{% endstepper %}

Once the categories have been created, students can select them when they pre-register, so the club can organise and manage requests in a more structured way.
{% endtab %}

{% tab title="Customise Registration" %}
## Customise the registration form

The **Customise Registration** section lets you set up the fields students need to fill in when they **pre-register for the school or academy**.

This lets the club collect extra information about students before assigning them to a group or level.

{% stepper %}
{% step %}
### Go to the Customise Registration section

* Go to the left-hand menu and click **Academy**.
* In the drop-down, select **Pre-registrations**.
* Select the **pre-registration** you want to manage.
* At the top, click the **Customise Registration** tab.

![](<../../.gitbook/assets/image (3)>)
{% endstep %}

{% step %}
### Add fields to the form

At the top you'll find different **predefined fields** you can use in the form.

To add one of these fields:

* Select the field you want to use.
* **Drag it to the bottom part of the form.**
* Drop it in the **Left Column** or **Right Column**, depending on how you want to lay out the form.

This lets you arrange the form in **one or two columns**, making it easier for users to read.

![](<../../.gitbook/assets/image (4)>)
{% endstep %}

{% step %}
### Make a field required

Once the field has been added to the form, a **checkbox appears next to it**.

* If you tick this box, the field becomes **required**, so the user must fill it in to complete the registration.
* If the box isn't ticked, the field is **optional**.

![](<../../.gitbook/assets/image (5)>)
{% endstep %}

{% step %}
### Create new custom fields

As well as the predefined fields, you can also create new fields.

To do this:

* Click **Add New**.
* The **Add Dynamic Field** window opens.

Fill in the following fields:

**Label:** Name of the field the user will see on the form.\
**Field type:** Sets the type of answer the user can enter.

The options available include:

![](<../../.gitbook/assets/image (6)>)

* Text
* Yes/No
* List
* Number
* Text area
* Date
* Email
* File upload
* Multiple choice

You can also optionally set:

* **Options:** Values available when the field is a list or selection.
* **Default value:** Value that appears already selected on the form.

Once the field is set up, click **Save** to add it to the form.

Once the form fields are set up, users will need to fill in this information when they register. All the data collected is linked to each participant and can be checked later from the **Participants** section.
{% endstep %}
{% endstepper %}

By customising the pre-registration form, the club can collect extra information from students and organise requests better before assigning them to the academy's groups.
{% endtab %}

## Communications

The **Communications** section lets you review and change the message templates the system sends automatically to students during pre-registration for the school or academy.

These communications tell the user the status of their request, for example when they register successfully or when their pre-registration is cancelled.

The club can edit these messages to match its own style or add extra information for students.

{% stepper %}
{% step %}
### Go to the Communications section

* Go to the left-hand menu and click **Academy**.
* In the drop-down, select **Pre-registrations**.
* Select the ID of the **pre-registration** you want to manage.
*   At the top, click the **Communications** tab.<br>

    <figure><img src="../../.gitbook/assets/image (31).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Review the available templates

This section shows the automatic message templates the system sends to students during pre-registration.

*   **Pre-registration confirmation:** message the student receives when they register successfully.

    <figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
*   **Pre-registration cancellation:** message sent when a request is cancelled.

    <figure><img src="../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>



These communications are sent automatically according to the status of the request.
{% endstep %}

{% step %}
### Edit a message template

If you want to change any of these messages:

* Select the template you want to edit.
* Make the changes you need to the message.
* Click **Save** to apply the changes.
{% endstep %}
{% endstepper %}

By customising the communications, the club can adapt the automatic messages sent to students and keep them informed during pre-registration.
{% endtab %}
