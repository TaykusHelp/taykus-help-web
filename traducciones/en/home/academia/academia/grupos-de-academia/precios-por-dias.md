# Prices per day

**Prices per day** let each player choose how many days a week they want to attend within the same course. If the group trains Monday to Friday, the student can sign up for just one day, two, three… or all five. It's flexible for the player and practical for the club, because the price is adjusted to each person's actual attendance.

It's important to follow an order when creating the group. If you're going to use **prices per day**, add them first, before creating the training sessions and before adding players. This avoids errors, makes sure each student sees the right price for the days they choose and keeps the whole course setup consistent from the start.

To create prices per day, follow these steps:

{% stepper %}
{% step %}
### Go to the Academy module

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Go to the academy group's prices per day

* If you haven't created the group yet, follow this link to find out how:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">How to create an Academy group</a>
* If the group already exists, click its ID to open it.
*   Go to the **Prices per day** section.<br>

    <figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create prices per day

* Click :heavy\_plus\_sign:.
*   The following panel opens, which you need to fill in as follows:

    <figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

    * **Number of days:** Enter the number of days you're setting a price for.
    * **Product:** Sets the price for this number of days. The product must be in the **Fee** category.
      * _To create Fee products, see the following article:_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota" class="button primary" data-icon="box">How to create a Fee product</a>
    * Click Save.
{% endstep %}
{% endstepper %}

You need to create one product for each option you want to offer. If students can come one, two, three or four days, you'll need to create a 1-day product, a 2-day product, a 3-day product and a 4-day product, each with its own price. That way students can choose exactly how many days they want to attend.
