# How to create an Academy group

In this article we explain step by step how to create academy groups in our sports management program. With a simple, efficient process, you can organise participants in the best way, following specific criteria that improve the users' experience and make activities easier to manage.

When creating an academy group, it's important to follow the steps in order.

{% stepper %}
{% step %}
### Go to the Academy module:

* Go to the left-hand menu and select Academy.
* The section where you manage all the academy groups you create opens.
{% endstep %}

{% step %}
### Create the new Academy group

* Click :heavy\_plus\_sign: to create a new group.
*   A form opens that you need to fill in as follows:<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>



    *   **GENERAL DETAILS:**

        * **Name:** The name of the group. We recommend following a clear structure such as:\
          `Group name – Category (age or level) – Days – Times`.
        * **Logo:** If the academy has a logo, you can add it here.
        * **Season:** The period the course lasts.
        * **End:** End date of the course/school/academy.
        * **Details:** Space to add an extra description.
        * **Product:** Select a previously created product **in the FEE category.** This is the price that will be assigned to this course.
          * _To create Fee products, see the following article:_ \
            <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota" class="button primary" data-icon="box">How to create a Fee product</a>
        * **Maximum Participants:** Sets the maximum number of people who can join.
        * **Minimum Level:** Set the minimum level required for this group.
        * **Maximum Level:** Set the maximum level allowed for this group.

        _<mark style="background-color:yellow;">(With these details your academy group is created)</mark>_
    * Click Save to keep your changes.


{% endstep %}
{% endstepper %}
