# How to add students

Adding students is the step where each player is officially enrolled in an academy course. Here you decide who is part of the group, and the system links them to their training sessions and the type of registration that applies to them. It's the process that turns the course setup into a real group, with its participants registered and ready to start.

If you're going to use **prices per day**, you must create them **before** adding the students. Only then will the system correctly assign which days each student can choose and which price applies. Once that's done, you can set up the students and get the group ready.

* _To create prices per day, see the following article:_\
  <a href="precios-por-dias.md" class="button primary" data-icon="medal">Prices per day</a>

For students to be assigned correctly to the group, the training sessions must be created beforehand. If you follow this order, the system can link them correctly to their sessions and the course is organised from the start.

* _To create the training sessions, see the following article:_\
  <a href="como-crear-los-entrenamientos.md" class="button primary" data-icon="medal">How to create the training sessions</a>

To add students, follow these steps:

{% stepper %}
{% step %}
### Go to the Academy module

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Go to the academy group's students

* If you haven't created the group yet, follow this link to find out how:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">How to create an academy group</a>
* If the group already exists, click its ID to open it.
*   Go to the **Students** section.

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Add students

* Click :heavy\_plus\_sign:
*   The following panel opens, which you need to fill in as follows:<br>

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

    * **Customer:** Search for the name of the student or students you want to add. If they attend on the same days, you can add more than one at a time.
    * **Start:** Select the date the student or students start the course.
    * **End:** Select the date the student(s) finish the course. You can change this date later if the student leaves before the course ends.
    * **Notes&#x20;**_**(Optional)**_**:** Space to write any details or keep a record of something.
    * **Days:** Tick the day or days the student will attend the course. This automatically adds each student's attendance days to the booking.
* Click Save to add the students to the academy group.
{% endstep %}
{% endstepper %}
