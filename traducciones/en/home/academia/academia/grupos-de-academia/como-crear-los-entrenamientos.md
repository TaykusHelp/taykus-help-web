# How to create the training sessions

**Training sessions** are the course's weekly sessions: the day, time and court where each group trains and, if you want, the coach. When you create them, you can **link the bookings to the academy group**, so that all attendance and places are linked to the course instead of being separate bookings.

If you're going to use **prices per day**, you must create them **before** adding the training sessions. Only then will the system correctly assign which days each student can choose and which price applies. Once that's done, you can set up the training sessions and get the group ready.

* _To create prices per day, see the following article:_\
  <a href="precios-por-dias.md" class="button primary" data-icon="medal">Prices per day</a>

To create the training sessions, follow these simple steps:

{% stepper %}
{% step %}
### Go to the Academy module

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Go to the academy group's training sessions

* If you haven't created the group yet, follow this link to find out how:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">How to create an academy group</a>
* If the group already exists, click its ID to open it.
*   Go to the **Training sessions** section.

    <figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the training sessions

*   Click Calendar.

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
* The club's calendar opens, but inside the Academy module.
* Make a **multiple booking** as usual, but it's important to do it **from the Academy module**. Only then will the booking be linked to the group and, when students are added, the system will automatically assign them to their training sessions. Everything stays organised within the same course.
  * _To make a multiple booking, see the following article:_\
    <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/reservar-multiples/como-crear-una-reserva-multiple" class="button primary" data-icon="clock">How to create a multiple booking</a>
* Once the multiple booking has been created, the training sessions are automatically assigned to that group. From then on, the whole course works with that setup.
{% endstep %}
{% endstepper %}
