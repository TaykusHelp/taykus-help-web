# Online registration

Online registration lets students sign up for an academy course quickly and securely. It avoids paperwork, reduces errors and updates the available places in real time. The club gains organisation and the student gains convenience. It simplifies the whole sign-up process into a single step.

To turn it on, just follow these simple steps:

{% stepper %}
{% step %}
### Go to the Academy module:

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Edit or create an Academy group

* If you haven't created the group yet, follow this link to find out how:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">How to create an academy group</a>
* If the group already exists, click its ID to open it.
*   Once inside, click <i class="fa-pen" style="color:purple;">:pen:</i> to edit it.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Turn on online registration

* Scroll down to the **Registration** section.
*   To turn on registration, fill in this section as follows:<br>

    <figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

    * **Show Online:** This box only makes the course visible on the website. Nothing else. It doesn't open registration or change how it's managed.&#x20;
    * **Days in advance to show online:** How many days beforehand you want the course to appear online. They only control the **date it becomes visible.**
    * **Allow online registration:** Lets students sign up for the course from the website. Without this ticked, the course is only shown and doesn't accept registrations.
    * **Registration start date:** Date from which students can register for the course.
    * **Registration end date:** Last date on which students can register.
{% endstep %}

{% step %}
### Save

* Click Save to keep your changes.
{% endstep %}
{% endstepper %}
