# Open class

Offering an open class is a way to fill gaps in a group when a student is missing. The club fills the class, and users can quickly sign up from the website. It helps you avoid losing court hours and income, and keeps groups active.

Just follow these simple steps:

{% stepper %}
{% step %}
### Go to the Academy module

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Edit or create a group

* If you haven't created the group yet, follow this link to find out how:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">How to create an academy group</a>
* If the group already exists, click its ID to open it.
*   Once inside, click <i class="fa-pen" style="color:purple;">:pen:</i> to edit it.<br>

    <figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Turn on open class

* Scroll down to the **Open class** section.
*   To offer single classes online, fill in this section as follows:<br>

    <figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

    * **Open class product:** Sets the price of an open class booking. The product must be in the **Service** category.
      * _To create Service products, see the following article:_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-servicio" class="button primary" data-icon="box">How to create a Service product</a>
    * **Allow online registration for open class:** Lets players sign up for the offered class from the website.
    * **Days in advance for open class online registration:** How many days beforehand the offered class appears online and accepts registrations.
{% endstep %}

{% step %}
### Save

* Click Save to keep your changes.


{% endstep %}
{% endstepper %}
