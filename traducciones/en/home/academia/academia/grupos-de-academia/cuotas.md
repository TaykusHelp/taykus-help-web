# Fees

The **Fees** section gives you a clear, organised view of everything related to payments in your academy group. From here you can see which fees have been issued, who has paid, who still owes and whether any amounts have been changed. It's the quickest way to check the group's financial status without getting lost in manual checks.

To open it and work with it, follow these steps:

{% stepper %}
{% step %}
### Go to the Academy module

* Go to the left-hand menu and select Academy.
{% endstep %}

{% step %}
### Go to the academy group's fees

* Click the ID of the group you want.
*   Go to the **Fees** section.<br>

    <figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
* This section shows all the fee types enabled for this group.
  * If only one is available, it appears in a single list; if the _Prices per day_ option is turned on, they are split as in the image.
{% endstep %}
{% endstepper %}
