# How to create a stock request

In this article we explain step by step how to use the Warehouse module. With a simple, efficient system you can keep accurate control of the stock available, manage incoming and outgoing products and keep the information up to date in real time. This not only improves your internal organisation, it also makes decisions easier and helps you avoid running out of stock or overstocking.

Here's how to do it:

{% stepper %}
{% step %}
### Go to Warehouse

* Go to the left-hand column and select **Warehouse**.
* The section with all the stock requests opens.
{% endstep %}

{% step %}
### Create a new stock request

* Click :heavy\_plus\_sign: to create a new one.
*   A short form opens that you need to fill in with the following details:

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Description:** The name of the order/request. We recommend including the date.
    * **Comments:** Space to add any extra description.
    * **Validated:&#x20;**<mark style="background-color:$warning;">**IMPORTANT.**</mark> The order must have this box ticked so that you can add stock in the next step.
* Click Save to keep the request.
{% endstep %}

{% step %}
### Add products

* When you save, the program takes you to the request.
* If it doesn't, click the ID of the request you want to add products to.
*   Once you are on the next screen, click Add products.

    * _<mark style="background-color:$warning;">(You can only add products that you have previously marked as “Has Stock”; see the article SETTINGS: Sales / Products – Stock Control)</mark>_

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>


* This takes you to a window with the products you have marked as having stock.
* Select the products you want to add to the request.
* Click Select, in the top left corner, to save your selection.
* Once the products have been added, the screen refreshes and shows the current stock of each item.
*   Find the Requested Quantity column and enter the number of items you want to request for each product.<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Once you've done this, you can export the list to Excel if needed and send it to your supplier by clicking :arrow\_down:.
{% endstep %}

{% step %}
### Add stock

* In the Warehouse module, where all the stock requests are listed, click the ID of the stock request you created.
*   Go to the **Stock in** block.

    <figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
*   Go to the **Add Delivered Quantity** column.<br>

    <figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
* Enter the number of items received and press Enter.
{% endstep %}
{% endstepper %}

Once you have entered the delivered quantities, the system automatically updates the inventory of each product and shows the new stock available in real time.\
You can check or change the request at any time from the Warehouse module if needed.
