# How to add stock manually

In this article we show you how to add stock manually. There are two\
ways to add inventory to your products.

The first option is to go to the list of stock requests, open the\
Stock in block and add the new quantities for each item. This method\
is ideal for updating several products at once, quickly and easily.

To find out how, read the following article:\
[como-crear-una-peticion-de-stock.md](como-crear-una-peticion-de-stock.md "mention")

However, if you only need to add stock to a single item, the best\
option is the second one, designed specifically for individual stock\
entries.

To do this, just follow these simple steps:

{% stepper %}
{% step %}
### Go to Manual Entry

* Go to the left-hand column and select Warehouse.
* In the drop-down, click Manual Entry.
{% endstep %}

{% step %}
### Add an entry

* In the top left corner, select Add Entry.
*   The following form opens, which you need to fill in as follows:<br>

    <div align="left"><figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure></div>

    * **Qty:** The quantity you want to add.
    * **Search Product:** When you select it, a list of all the products with stock control opens.
* Click Add to save your changes.
{% endstep %}
{% endstepper %}

Once the entry is complete, the system immediately shows the new quantities in the inventory.\
Remember to check the list of items to make sure the stock has been updated correctly.
