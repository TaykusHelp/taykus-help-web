# How to cancel a debt

If a debt isn't going to be collected, you can cancel it from **Sales › Debts** so it no longer shows as pending.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Debts

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Debts**. The **Pending Payment** tab opens.
{% endstep %}

{% step %}
### Select the debt

* Tick the box to the left of the debt you want to cancel.
*   Click **Cancel**.<br>

    <figure><img src="../../.gitbook/assets/deudas-anular.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choose the cancel option

*   A drop-down opens. Choose **Cancel debts and refund payments**.<br>

    <figure><img src="../../.gitbook/assets/deudas-anular-opciones.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirm

*   A window opens asking you to confirm:<br>

    <figure><img src="../../.gitbook/assets/deudas-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Click **OK** to cancel it, or **Close** if you don't want to cancel it.
{% endstep %}
{% endstepper %}

> **Important:** if cancelling means refunding a cash or card payment, you need to have a cash register open. If it's a refund of an online payment, you don't. To open a cash register, see [How to open the cash register](../cajas/como-abrir-la-caja.md).
