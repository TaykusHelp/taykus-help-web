# How to send a debts email

From **Sales › Debts** you can send an email to customers with pending payments to remind them. You can send it to one, several or all of them at once.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Debts

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Debts**. The **Pending Payment** tab opens.
{% endstep %}

{% step %}
### Select the debts

* Tick the box to the left of each debt you want to include.
* If you want to send it to everyone, tick the box in the list header: all debts are selected.
*   Click **Send Debts Email**. The emails are sent straight away, with no confirmation window.<br>

    <figure><img src="../../.gitbook/assets/deudas-enviar-email.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Important:** one email is sent for each selected debt. If a customer has several debts and you tick them all, they'll receive one email for each.

The email text is the **Debt notification** template, which you can change from **Communications › Email Templates**. See [Accessing email templates](https://taykus-help-center.gitbook.io/taykushelpcenter/home/comunicaciones/comunicaciones/acceso-a-plantillas-de-emails).

To check whether the emails have gone out, see [Where to see the delivery status of emails](https://taykus-help-center.gitbook.io/taykushelpcenter/home/comunicaciones/comunicaciones/donde-ver-el-estado-de-envio-de-los-correos).
