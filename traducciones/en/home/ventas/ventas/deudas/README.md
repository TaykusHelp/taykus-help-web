# Debts

**Sales › Debts** shows everything customers still have to pay whose due date has already passed, whatever the type of sale (bookings, matches, etc.). Sales with a future date aren't considered debts and don't appear here.

The screen has two tabs:

* **Pending Payment:** debts the club has to collect.
* **Pending Direct Debit:** debts that will be collected by direct debit and are still waiting to be included in a remittance. See [Debts pending direct debit](deudas-pendientes-de-domiciliacion.md).

In both you can filter by any column and download the list with the download button.

From this screen you can:

* [Collect a debt](como-cobrar-una-deuda.md) by opening it in the POS.
* [Send a debts email](como-enviar-un-email-de-deudas.md) to customers.
* [Cancel a debt](como-anular-una-deuda.md).

The articles explain the **Pending Payment** tab. **Pending Direct Debit** works the same way.
