# How to collect a debt

From **Sales › Debts** you can collect what a customer owes: the debt opens in the POS and is charged like any other sale. You can collect a single debt or several at once.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Debts

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Debts**. The **Pending Payment** tab opens.
{% endstep %}

{% step %}
### Select the debt

* Find the debt you want to collect. You can use the filter on each column, for example **Customer**.
* Tick the box to the left of the debt. If you want to collect several at once, tick them all.
*   Click **Open POS**.<br>

    <figure><img src="../../.gitbook/assets/deudas-abrir-tpv.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Charge it in the POS

* The POS opens with the debt loaded.
* If you ticked several debts, the ticket on the right gives you the option to load all the sales, just like when a player pays another player's share.
* Charge the sale as usual.
{% endstep %}
{% endstepper %}

If you have questions about charging in the POS, see [How to make a sale](https://taykus-help-center.gitbook.io/taykushelpcenter/home/tpv/tpv/ventas/como-hacer-una-venta).
