# How to skip a fee

Skipping a fee means that receipt isn't charged: no charge is generated and it isn't included in the remittance. For example, if a student doesn't come one month, instead of setting the fee to €0 you can skip it.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to the fees

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Fees**.
* Click the fee's **Id**.
* Go to the **Calendar** tab.

> You can also do it from the player's profile or from an academy group. To find out how, see this article:
>
> <a href="como-ver-las-cuotas.md" class="button primary">How to view fees</a>
{% endstep %}

{% step %}
### Select the fee

* Tick the circle of the month's fee you want to change, in the player's row.
* You can select several at once: the circle next to a player's name selects all their fees, and the circle next to a month selects every player's fee for that month. The action applies to all the ones you select.
*   Click **Actions**, at the top left.

    <figure><img src="../../.gitbook/assets/cuotas-acciones.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Skip

* In the **Actions** menu, choose **Skip**.
*   Click **OK** to confirm.

    <figure><img src="../../.gitbook/assets/cuotas-omitir.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

The skipped fee stays recorded and appears in grey, both in the fee's calendar and in the player's profile.

> **Important:** you can only skip fees that haven't been issued. If it's already been issued, reset it first. To find out how, see this article:
>
> <a href="como-restablecer-una-cuota.md" class="button primary">How to reset a fee</a>
