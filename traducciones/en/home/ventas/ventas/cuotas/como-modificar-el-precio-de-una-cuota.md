# How to change a fee's price

You can change the amount of a specific fee, for example for a month in which the student pays less. The change only affects the fees you select, and you can only do it if they haven't been issued yet.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to the fees

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Fees**.
* Click the fee's **Id**.
* Go to the **Calendar** tab.

> You can also do it from the player's profile or from an academy group. To find out how, see this article:
>
> <a href="como-ver-las-cuotas.md" class="button primary">How to view fees</a>
{% endstep %}

{% step %}
### Select the fee

* Tick the circle of the month's fee you want to change, in the player's row.
* You can select several at once: the circle next to a player's name selects all their fees, and the circle next to a month selects every player's fee for that month. The action applies to all the ones you select.
*   Click **Actions**, at the top left.

    <figure><img src="../../.gitbook/assets/cuotas-acciones.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Change the price

* In the **Actions** menu, choose **Change Price**.
* In **Price**, enter the new amount. This field is required.
*   Click **OK** to save.

    <figure><img src="../../.gitbook/assets/cuotas-cambiar-precio.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
