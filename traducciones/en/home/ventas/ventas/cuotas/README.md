# Fees

In **Sales › Fees** you manage fees: charges that repeat periodically, for example the monthly fee of an academy group. Until a fee is issued, you can change its price, its due date or skip it.

First of all, the fee has to be created as a product. See [How to create a Fee-type product](../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md).

From this section you can:

* [View fees](como-ver-las-cuotas.md) by fee, by player or from an academy group.
* [Issue a fee](como-emitir-una-cuota.md) so that it becomes pending payment.
* [Pay a fee](como-pagar-una-cuota.md) from the fee calendar.
* [Reset a fee](como-restablecer-una-cuota.md) if you issued it by mistake.
* [Skip a fee](como-omitir-una-cuota.md) so that the charge isn't collected.
* [Change a fee's price](como-modificar-el-precio-de-una-cuota.md).
* [Change a fee's due date](como-cambiar-el-dia-de-vencimiento-de-una-cuota.md).
* [Turn on automatic card payment](como-activar-el-cobro-automatico-con-tarjeta.md).
* [Automate fee issuing](como-automatizar-la-emision-de-cuotas.md).
* [Automate cancellation for non-payment](como-automatizar-la-cancelacion-por-impago.md).
* [Remove a customer from a fee](como-dar-de-baja-a-un-cliente-de-una-cuota.md).

If the fee changes the customer type (for example, from Non-member to Member), it's a membership. See [What a membership is and how it works](que-es-una-membresia-y-como-funciona.md).
