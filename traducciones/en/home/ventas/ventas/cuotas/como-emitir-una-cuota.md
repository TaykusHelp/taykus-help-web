# How to issue a fee

When you issue a fee, the system records the debt: a sales line pending payment is created, and the customer sees it in their Customer Area, under their pending sales, so they can pay it.

> **Important:** if the fee has automatic issuing turned on, it's issued by itself and you don't need to do it by hand. You turn it on in the fee's form, in Settings, with the **Automatic Issue** checkbox, or for each player, with the checkbox in the fee's list of players. To find out how to create the fee, see this article:
>
> <a href="../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md" class="button primary">How to create a Fee product</a>

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to the fees

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Fees**.
* Click the fee's **Id**.
* Go to the **Calendar** tab.

> You can also do it from the player's profile or from an academy group. To find out how, see this article:
>
> <a href="como-ver-las-cuotas.md" class="button primary">How to view fees</a>
{% endstep %}

{% step %}
### Select the fee

* Tick the circle of the month's fee you want to issue, in the player's row.
* You can select several at once: the circle next to a player's name selects all their fees, and the circle next to a month selects every player's fee for that month. The action applies to all the ones you select.
*   Click **Actions**, at the top left.

    <figure><img src="../../.gitbook/assets/cuotas-acciones.png" alt=""><figcaption></figcaption></figure>
* For example, to issue all the fees for a month, tick the circle next to that month:

    <figure><img src="../../.gitbook/assets/cuotas-seleccionar-mes.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Issue

* In the **Actions** menu, choose **Issue**.
*   Click **OK** to confirm.

    <figure><img src="../../.gitbook/assets/cuotas-emitir.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Once issued, the fee can only be paid or reset. If you need to change it, reset it first. To find out how, see this article:

<a href="como-restablecer-una-cuota.md" class="button primary">How to reset a fee</a>
