# How to resend or download an invoice

When you issue an invoice, it's sent automatically to the customer. If they've lost it or haven't received it, you can send it again or download it from **Sales › Invoices**.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Invoices

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Invoices**. The **Issued invoices** tab opens.
{% endstep %}

{% step %}
### Select the invoice

* Find the invoice. You can use the filters in each column, for example **Sale**, **Number** or **Issue date**.
*   Tick the circle on the left of the invoice.

    <figure><img src="../../.gitbook/assets/facturas-reenviar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Resend or download

* Click **Resend** to send it to the customer again.
* Click **Download** to download the invoice as a PDF.
{% endstep %}
{% endstepper %}
