# Invoices

You can issue the invoice for a sale from several **Sales** lists. In every case the same sale window opens, with the **Issue invoice** button. The only difference is where you click:

* **Sales › Lines:** click the line's **ID**. See [How to issue an invoice from Sales > Lines](como-emitir-una-factura-desde-ventas-greater-than-lineas.md).
* **Sales › Payments:** click the number in the **Sale** column. See [How to issue an invoice from Sales > Payments](como-emitir-una-factura-desde-ventas-pagos.md).
* **Sales › Voucher Payments:** as in Payments, click the number in the **Sale** column.
* **Sales › Debts:** as in Lines, click the **ID**.

> **Important:** you can't issue invoices from the POS.

When you save it, the invoice is sent automatically to the customer. To send it again or download it, see [How to resend or download an invoice](como-reenviar-o-descargar-una-factura.md).
