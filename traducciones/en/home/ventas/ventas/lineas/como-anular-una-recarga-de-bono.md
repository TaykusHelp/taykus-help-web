# How to cancel a voucher top-up

If a voucher top-up is made by mistake, you can cancel the operation to reverse both the payment and the balance added for the customer.

Cancelling a top-up works like cancelling a purchase: it corrects the recorded sale and removes from the voucher the balance, amount or sessions that had been added.

In this article we explain how to cancel a voucher top-up correctly.

> **Important note:** You can only cancel a voucher top-up if the balance added is still complete.
>
> If the customer has used part of the balance, sessions or amount added, that top-up can't be refunded, because the system can't remove all of the balance originally added.

{% stepper %}
{% step %}
### Go to Sales

* Go to the left-hand column and select **Sales**.
* A drop-down opens. Select **Lines**.

<div align="left"><figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Find the sales line

* In the list of sales lines, find the payment for the top-up you want to cancel.
* Select the line.
* Then click **Cancel**.
*   Choose the **Cancel debts and refund payments** option.<br>

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>


* Before confirming, the system shows a confirmation warning.\
  ![](<../../.gitbook/assets/image (31).png>)
* Press **OK** to complete the cancellation.
{% endstep %}

{% step %}
### Check

*   After cancelling the sale, you can check it worked by making sure the matching negative transaction has been created in the sales lines.<br>

    <figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>


* You can also check the player's balance, where the balance added by the top-up should no longer be available.
{% endstep %}
{% endstepper %}

Once the top-up is cancelled, the system reverses the purchase and removes the balance added to the customer's voucher.

Remember to check first that the balance added is still complete, because if part of the top-up has been used, it can't be refunded. This way you'll avoid discrepancies between the recorded payment and the player's available balance.
