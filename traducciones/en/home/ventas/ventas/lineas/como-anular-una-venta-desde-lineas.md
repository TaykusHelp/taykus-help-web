# How to cancel a sale from Lines

If a sale was recorded by mistake or its amount needs to be refunded, you can cancel it from **Sales › Lines**. You can cancel a single line or several at once.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Lines

* Go to the left-hand menu and select **Sales**.
* In the drop-down, choose **Lines**.
{% endstep %}

{% step %}
### Select the line

* Find the sale you want to cancel. You can use the filter on each column, for example **Customer**.
* Tick the box to the left of the line. If you want to cancel several, tick them all.
* Click **Cancel**.
{% endstep %}

{% step %}
### Choose the cancel option

*   A drop-down opens. Choose **Cancel debts and refund payments**.<br>

    <figure><img src="../../.gitbook/assets/lineas-anular.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirm

*   A window opens asking you to confirm:<br>

    <figure><img src="../../.gitbook/assets/lineas-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Click **OK** to cancel it, or **Close** if you don't want to cancel it.
{% endstep %}
{% endstepper %}

Once cancelled, you'll see two coloured lines in the list: in light pink, the refund (with a negative amount), and in darker pink, the cancelled sale.

> **Important:** if cancelling means refunding a cash or card payment, you need to have a cash register open. If it's a refund of an online payment, you don't. To open a cash register, see [How to open the cash register](../cajas/como-abrir-la-caja.md).

If what you want to cancel is a voucher top-up, see [How to cancel a voucher top-up](como-anular-una-recarga-de-bono.md).
