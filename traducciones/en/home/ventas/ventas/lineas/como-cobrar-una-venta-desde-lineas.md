# How to collect a sale from Lines

From **Sales › Lines** you can collect any pending sale: it opens in the POS and is charged like a normal sale. You can collect a single line or several at once, even from different customers. For example, when a player comes to pay for themselves and someone else.

Below are the steps to follow:

{% stepper %}
{% step %}
### Go to Lines

* Go to the left-hand menu and select **Sales**.
*   In the drop-down, choose **Lines**.<br>

    <figure><img src="../../.gitbook/assets/lineas-listado.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the lines

* Find the sale you want to collect. You can use the filter on each column, for example **Customer**.
* Tick the box to the left of the line. If you want to collect several at once, tick them all.
* Click **Open POS**.
{% endstep %}

{% step %}
### Charge it in the POS

* The POS opens with the sale loaded.
* If you ticked several lines, you can switch from one ticket to another in the POS, or load all the sales on the ticket on the right to charge them together.
* Charge the sale as usual.
{% endstep %}
{% endstepper %}

> **Important:** you need to have a cash register open to be able to collect. See [How to open the cash register](../cajas/como-abrir-la-caja.md).

If you tick a line that has already been paid, it opens in the POS with the status **Paid** and there's nothing to collect:

<figure><img src="../../.gitbook/assets/lineas-tpv-pagado.png" alt=""><figcaption></figcaption></figure>

If you have questions about charging in the POS, see [How to make a sale](https://taykus-help-center.gitbook.io/taykushelpcenter/home/tpv/tpv/ventas/como-hacer-una-venta).
