# Voucher payments

In **Sales › Voucher Payments** you'll find the list of everything that has been paid with a voucher: bookings, matches and any other sale where the customer used their balance.

> **Important:** the voucher sale itself (the top-up the customer pays for) doesn't appear here. You'll find that sale in **Sales › Lines** or **Sales › Payments**.

It works just like the payments list. From this screen you can:

* **Find a voucher payment** using the filter on each column.
* **View the sale** by clicking on it.
* **Cancel a payment:** it works the same as in **Sales › Payments**. Tick its box, click **Cancel** and confirm. To be able to make the refund, you need to have a cash register open.
* **Download the list** with the download button.

If you need to cancel a top-up, see [How to cancel a voucher top-up](lineas/como-anular-una-recarga-de-bono.md).
