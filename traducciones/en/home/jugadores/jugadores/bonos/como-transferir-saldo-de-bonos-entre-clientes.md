# How to transfer voucher balance between customers

One feature that can improve the user experience is the option to transfer voucher balance to another customer or player of their choice. Although users can't make the transfer themselves, they can contact the club to handle the request and make sure everything is recorded correctly in the system.

The process is simple and is done by following these steps:

{% stepper %}
{% step %}
### Go to Players

* Go to the left-hand column and select Players.
{% endstep %}

{% step %}
### Find the player or customer

*   Use any of the available columns to search for the player by first name, surname, email, ID number, etc. and click their ID.<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
* You can also use the search box in the top left corner: type the player's name and press Enter.\
  ![](<../../.gitbook/assets/image (7).png>)
{% endstep %}

{% step %}
### Go to the vouchers section

* In the player's profile, find the **Billing** block.
*   In the drop-down, select **Vouchers**.<br>

    <figure><img src="../../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Transfer the balance

* Select the ID of the voucher you want to transfer from.
*   In the top right corner, click Transfer.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
### Select the amount to transfer

* A window appears that you need to fill in with the following information:\
  ![](<../../.gitbook/assets/image (102).png>)
  * **Balance:** enter the amount you want to transfer.
  * **Player:** type the name of the player who will receive the balance.
* Click OK to make the transfer.


{% endstep %}
{% endstepper %}
