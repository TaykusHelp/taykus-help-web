# How to top up a voucher

If the club works with vouchers, it's essential to know how to top them up. There are two ways to do it: from the POS or from the player profile. In this article we explain how to do it from **Players**.

Follow these steps:

{% stepper %}
{% step %}
### Go to Players

* Go to the left-hand menu and select **Players**.
{% endstep %}

{% step %}
### Find the player

* Use any of the available columns to search for the player by first name, surname, email, ID number, etc. and click their **ID**.

<figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

* You can also use the search box in the top left corner: type the player's name and press **Enter**.

<div align="left"><figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Go to the Vouchers section

* In the player's profile, find the **Vouchers** block.

<div align="left"><figure><img src="../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Top up the voucher

* In the top right corner of the block, select **Top up**.
* This option takes you straight to the **POS**.
{% endstep %}

{% step %}
### Select the voucher

* A window opens with all the available vouchers.
* Select the voucher you want to top up from the ones you've already set up.

<figure><img src="../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

* If you need to make a specific change for this customer, you can choose the **Customise top-up** option, after first selecting any voucher top-up already created.
{% endstep %}

{% step %}
### Complete the top-up

* Take the payment using the customer's preferred payment method.
* If it's a customised top-up at a price of €0, select **Confirm**.
{% endstep %}
{% endstepper %}
