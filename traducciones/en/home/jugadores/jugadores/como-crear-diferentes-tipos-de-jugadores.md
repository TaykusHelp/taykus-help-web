# How to create different player types

Player types let you classify your customers into categories. If the club has a new category of customer, you can add it to the program in a few steps.

Follow these steps:

{% stepper %}
{% step %}
### Go to Player types

* Click **Players** in the left-hand menu.
* Select **Player types**, just below.

<figure><img src="../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>

* This block shows all the player types you've already created.
{% endstep %}

{% step %}
### Create a new player type

* Click <i class="fa-plus">:plus:</i>.
* Enter the name of the new category.

<div align="left"><figure><img src="../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure></div>

* Save with <i class="fa-floppy-disk">:floppy-disk:</i>.
{% endstep %}
{% endstepper %}

> **Important:** when you create a new customer type, you'll usually want to give it different prices, especially for bookings. To do this, you need to create [custom prices by player type](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/personalizacion-de-precios/personalizar-precios-por-tipo-de-jugador).
