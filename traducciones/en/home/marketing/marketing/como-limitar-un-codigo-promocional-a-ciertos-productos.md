# How to limit a promo code to certain products

You can make a promo code apply only to the products you choose, for example to off-peak bookings or racket hire. First you create the code and then you add the allowed products from the promotion itself.

Follow these steps:

{% stepper %}
{% step %}
### Go to Promo Codes

* Go to the left-hand menu and select **Marketing.**
*   In the drop-down, click **Promo Codes** and you will be taken straight to the **Promotions** tab.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

> **Important:** The promo code must already exist before you can limit it. If you haven't created it yet, see [How to create a promo code](como-hacer-un-codigo-promocional.md).
{% endstep %}

{% step %}
### Open the promotion

* Click the ID of the promotion you want to limit.
*   The promotion details open, showing its promo codes:<br>

    <figure><img src="../.gitbook/assets/detalle-promocion.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Add the allowed products

* Scroll down to the **Allowed Products** section.
*   Click :heavy\_plus\_sign:<br>

    <figure><img src="../.gitbook/assets/productos-permitidos.png" alt=""><figcaption></figcaption></figure>
*   In the **Product** field, search for and select the product the discount will apply to.<br>

    <figure><img src="../.gitbook/assets/anadir-producto-permitido.png" alt=""><figcaption></figcaption></figure>
* Click **Save**.
* Repeat these steps for each product you want to add.
{% endstep %}

{% step %}
### Copy the products from another promotion (optional)

If you already have another promotion with the same allowed products, you can copy them instead of adding them one by one. Above **Allowed Products** there are two buttons:

* **Copy products to…:** use it when you are in the promotion that already has the products and you want to copy them to another one. For example, from an old promotion to a new one.
* **Copy products from…:** use it when you are in the new promotion and want to bring in the products from another one. For example, from an old promotion.
{% endstep %}
{% endstepper %}

> **Important:** If you don't add any products, the code applies to all products.

Once you have added products, the discount only applies to the products on the list. We recommend testing the code with an allowed product and with one that isn't before sharing it with customers.
