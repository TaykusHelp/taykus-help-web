# How to edit a promo code

Promo codes can be changed at any time to adjust discounts, dates or usage limits to suit your campaign. Editing them correctly lets you keep control of your active promotions without having to create new codes.

In this article we explain how to edit a promo code step by step.

{% stepper %}
{% step %}
### Go to Promo Codes

* Go to the left-hand menu and select **Marketing.**
*   In the drop-down, click **Promo Codes** and you will be taken straight to the **Promotions** tab.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Select the promotion

* Click the ID of the code you want to edit.
*   You will be taken to the section shown in the image:<br>

    <figure><img src="../.gitbook/assets/detalle-promocion.png" alt=""><figcaption></figcaption></figure>

    *   At the top, in the **General** section, you can see a summary of the promotion's status:

        * **Name:** name of the promotion. It can be edited at any time.
        * **Uses:** total number of times the code has been used.
        * **Total codes:** number of codes created in the promotion. It matches the **Quantity** entered when it was created, that is, the number of times the code can be used.

        At the bottom you will find the list of **Promo Codes** linked to the promotion.
{% endstep %}

{% step %}
### Edit the promo code

* Click the code's ID.
*   Click <i class="fa-pen" style="color:green;">:pen:</i>

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
* Edit the fields you need and click Save to keep your changes.
{% endstep %}
{% endstepper %}

Editing a promo code lets you adapt active campaigns without creating new promotions. Reviewing their settings regularly helps you keep control of your discounts and avoid mistakes when they are applied.

If you want the discount to apply only to some products, see [How to limit a promo code to certain products](como-limitar-un-codigo-promocional-a-ciertos-productos.md).
