# How to create a promo code

Promo codes let you apply discounts quickly and in a controlled way to bookings, products or services. They are a useful tool for one-off campaigns, customer loyalty or special promotions. In this article you will learn how to create a promo code step by step and set it up correctly for your needs.

{% stepper %}
{% step %}
### Go to Promo Codes

* Go to the left-hand menu and select **Marketing.**
*   In the drop-down, click **Promo Codes** and you will be taken straight to the **Promotions** tab.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create the promo code

* Click :heavy\_plus\_sign:
*   A section opens that you need to fill in as follows:

    <figure><img src="../.gitbook/assets/anadir-promocion.png" alt=""><figcaption></figcaption></figure>

    * **Name:** Internal name of the promotion so you can identify it in the system. We recommend a clear name that makes the code easy to recognise.
    * **Quantity:** Number of times the code can be used, up to a maximum of **1000**. For example, if you enter 50, the system creates the same code 50 times and it can be used 50 times in total.
    * **Discount type:** Defines how the discount is applied. It can be in **money** (fixed amount) or a **percentage** of the price.
    * **Discount:** Value of the discount to apply, according to the selected type.
    * **Start date:** Date from which the code is active. If you leave it empty, the code is active from the moment you save it.
    * **End date:** Last day the code is valid. From that day on it stops working automatically. If you leave it empty, the code never expires.
    * **Starts with:** Prefix for the codes the system generates automatically (for example, `SUM-`).
    * **Exact text:** A fixed code that you choose and that the customer has to enter (for example, `SUMMER10`). This is the text you will share publicly.

    > **Important:** Fill in only one of the two fields: **Starts with** or **Exact text**.
* Click **Save**.
{% endstep %}

{% step %}
### Check that the code works

* Go to the website or app and make a booking.
* When you reach the booking summary, enter the promo code.
*   Click **Apply code**.<br>

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>


* If the code has been created correctly, the discount is applied automatically.
*   If the code has been created or entered incorrectly, an error message appears on screen saying it cannot be applied.<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Creating and checking a promo code correctly ensures that discounts are applied without errors and avoids problems at the till or with online bookings. We always recommend testing the code before sharing it with customers to make sure it works as expected.
