# Manage activity communications

The **Communications** section lets you review and change the message templates the system sends automatically to users during the registration process for an activity.

These communications tell participants the status of their registration, for example when they register successfully or when their registration is cancelled.

The club can edit these messages to match its own style or add extra information for participants.

{% stepper %}
{% step %}
### Go to the Communications section

* Go to the left-hand menu and select **Activities**.
* Select the ID of the **activity** you want to manage.
*   At the top, click the **Communications** tab.<br>

    <figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Review the available templates

This section shows the automatic message templates the system sends to participants during registration.

*   **Registration confirmation:** message the user receives when they register successfully for the activity.<br>

    <figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>
*   **Registration cancellation:** message sent when a registration is cancelled.<br>

    <figure><img src="../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

These communications are sent automatically according to the status of the participant's registration.
{% endstep %}

{% step %}
### Edit a message template

If you want to change any of these messages:

* Select the template you want to edit.
* Make the changes you need to the message.
* Click **Save** to apply the changes.
{% endstep %}
{% endstepper %}

By customising the communications, the club can adapt the system's automatic messages and keep participants informed about the status of their registration.
