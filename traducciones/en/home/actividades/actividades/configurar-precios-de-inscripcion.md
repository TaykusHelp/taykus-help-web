# Set up registration prices

The **Registration Prices** section lets you set the cost of taking part in an activity when there are **several categories or registration options**.

For activities with a single category, the system automatically uses the **price set when the activity was created**, so you don't need to set anything else in this section.

This tool is mainly used when the registration price **varies according to the number of categories or options the participant registers for**.

{% stepper %}
{% step %}
### Go to the Registration Prices section

* Go to the left-hand menu and open **Activities**.
* Select the activity you want to manage.
*   At the top, click the **Registration Prices** tab.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### When to use this section

If the activity has **a single category**, you don't need to add any price in this section.

In that case, the system automatically uses the **price of the product set when the activity was created**.

You only need to set up this section when the activity allows **several categories or registration combinations**.
{% endstep %}

{% step %}
### Before you start

When an activity lets people register for **more than one category**, you need to set the price for each option.

To do this, the following must already exist:

* The **categories created** in the activity.\
  To find out how, see this article:\
  <a href="como-crear-categorias.md" class="button primary">How to create categories</a>
* The **Item products** with the corresponding prices.\
  To find out how to create them, see this article:\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary">How to create an Item product</a>

Once they exist, from this section you can link each price to its registration option.
{% endstep %}

{% step %}
### Link the price to the number of categories

* Click :heavy\_plus\_sign:.
*   A window pops up that you need to fill in as follows:<br>

    <figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>



    * **Number of registrations per category:** Enter how many categories the price you are setting applies to.
    * **Product:** Select the previously created product with the **price for the selected number of categories**. This is the amount the participant will pay when registering for that number of categories.
* Click Save to keep your changes.
* **Important:** You need to create **as many registration prices as category combinations the activity allows**, including the option to register **for a single category**.
{% endstep %}
{% endstepper %}

By setting up **registration prices according to the number of categories** correctly, the system automatically applies the right amount depending on the option the participant chooses when registering.

This way, the club can manage different registration options within the same activity, keeping prices organised and linked to each combination of categories.
