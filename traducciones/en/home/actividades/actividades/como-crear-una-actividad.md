# How to create an activity

**Activities** let you organise one-off events or sessions at the club, such as open classes, social events, informal tournaments or any other activity where you need to manage participants and registrations.

This module makes it easy to manage attendees, prices and registrations, so the club can organise activities in a structured way and easily control the number of participants.

In this article we show you how to set them up.

{% stepper %}
{% step %}
#### Go to Activities

*   Go to the left-hand menu and select **Activities.**<br>

    <figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Create an activity

* Click ➕
* A window pops up that you need to fill in as follows:

![](<../.gitbook/assets/image (1)>)

![](<../.gitbook/assets/image (2)>)

* **Name:** The title of the activity.
* **Poster:** click "browse" to select an image to show on the website.
* **Description:** Space to add extra information.
* **Sport:** a drop-down opens where you select the sport.
* **Product:** Select a previously created product **in the ITEM category.** This is the price that will be assigned to this activity.
  * To create Item products, see this article:\
    <a href="https://taykus-help-center.gitbook.io/taykushelpcenter/configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary">How to create an Item product</a>
* **Comments:** space to add an internal note.
* **Participants:** maximum number of people who can sign up.
* **Start:** Start date of the activity.
* **End:** End date of the activity.
* **Registration from:** Date registration opens.
* **Registration until:** Date registration closes.
* **Maximum Number of Participants:** works the same as **Participants**.
* **Online:** This box only makes the activity visible on the website. Nothing else. It doesn't open registration or change how it's managed.
* **Online registration:** Lets users sign up for the activity from the website. Without this ticked, the activity is only shown and doesn't accept registrations.
* Click Save to keep your changes.
{% endstep %}

{% step %}
#### Activity settings

Once the activity has been created and saved, new sections become available so you can finish setting it up and manage the players' requests.

The following tabs appear at the top:

![](<../.gitbook/assets/image (3)>)

* **Activity:** Lets you review or change the general information of the activity.
* **Participants:** Here you can see and manage the registration requests made by players.
* **Categories:** Lets you organise participants into categories or levels.
* **Registration Prices:** Sets the prices for registering or booking a place.
* **Customise Registration:** Lets you set up the fields that users will fill in on the registration form.
* **Communications:** Where you set up the messages or notifications related to the activity.
* **Fees:** Lets you set the fees or payments linked to the activity.
* **Sales:** Shows the information about payments or sales generated by registrations.

Once these sections are set up, the activity is ready to receive requests from players through the website or to be managed directly from the club's system.
{% endstep %}
{% endstepper %}
