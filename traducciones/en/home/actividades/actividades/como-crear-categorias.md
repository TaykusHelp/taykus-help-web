# How to create categories

**Categories** let you organise participants in an activity according to different criteria, such as format, level or type of competition.

This is especially useful for activities like tournaments or events where players can register in different categories (for example: men's, women's, mixed or different playing levels).

In this article we explain how to create them.

{% stepper %}
{% step %}
### Go to the Categories section

* Go to the left-hand menu and open **Activities**.
* Click the ID of the activity you want to manage.
*   At the top, click the **Categories** tab.<br>

    <figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create a new category

* Click :heavy\_plus\_sign:.
*   A window opens where you need to fill in the following field:<br>

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Name:** Enter the name of the category (for example: Men's, Women's, Mixed or different playing levels).
* Once you've entered the name, click **Save** to create the category.
{% endstep %}

{% step %}
### Add more categories

You can repeat this process as many times as you need to create all the categories that will be part of the activity.

These categories will later be used to **manage participants' registrations** and to **set registration prices according to the number of categories**.
{% endstep %}
{% endstepper %}

Once the categories have been created, participants can select them when they register and the system automatically manages their registration in the activity.
