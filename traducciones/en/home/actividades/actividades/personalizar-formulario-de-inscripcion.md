# Customise the registration form

The **Customise Registration** section lets you set up the fields users need to fill in when they register for an activity.

From here the club can ask participants for extra information, such as phone number, level, notes or any other details needed to manage the activity properly.

{% stepper %}
{% step %}
### Go to the Customise Registration section

* Go to the left-hand menu and select **Activities**.
* Select the **activity** you want to manage.
*   At the top, click the **Customise Registration** tab.<br>

    <figure><img src="../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Add fields to the form

At the top you'll find different **predefined fields** you can use in the form.

To add one of these fields:

* Select the field you want to use.
* **Drag it to the bottom part of the form.**
* Drop it in the **Left Column** or **Right Column**, depending on how you want to lay out the form.

This lets you arrange the form in **one or two columns**, making it easier for users to read.

<figure><img src="../.gitbook/assets/gift personalizar registro.gif" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Make a field required

Once the field has been added to the form, a **checkbox appears next to it**.

If you tick this box, the field becomes **required**, so the user must fill it in to complete the registration.

If the box isn't ticked, the field is **optional**.<br>

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Create new custom fields

As well as the predefined fields, you can also create new fields.

To do this:

* Click **Add New**.
* The **Add Dynamic Field** window opens.

Fill in the following fields:

**Label:** Name of the field the user will see on the form.\
**Field type:** Sets the type of answer the user can enter.

The options available include:<br>

<figure><img src="../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

* Text
* Yes/No
* List
* Number
* Text area
* Date
* Email
* File upload
* Multiple choice

You can also optionally set:

· **Options:** Values available when the field is a list or selection.\
· **Default value:** Value that appears already selected on the form.

Once the field is set up, click **Save** to add it to the form.
{% endstep %}
{% endstepper %}

Once the form fields are set up, users will need to fill in this information when they register. All the data collected is linked to each participant and can be checked later from the **Participants** section.
