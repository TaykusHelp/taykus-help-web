# How to create a match from the Taykus app

As well as making bookings, the Taykus app lets players create matches so that other users can join and complete the group.

This option is useful when a player wants to organise a match but doesn't have all the players confirmed yet. From the app they can select the club, the date, the time and an available court, and set the details needed to publish the match.
