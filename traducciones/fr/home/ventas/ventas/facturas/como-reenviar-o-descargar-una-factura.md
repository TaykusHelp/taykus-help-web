# Comment renvoyer ou télécharger une facture

Quand vous émettez une facture, elle est envoyée automatiquement au client. S'il l'a perdue ou ne l'a pas reçue, vous pouvez la lui renvoyer ou la télécharger depuis **Ventes › Factures**.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux factures

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Factures**. L'onglet **Factures émises** s'ouvre.
{% endstep %}

{% step %}
### Sélectionner la facture

* Trouvez la facture. Vous pouvez utiliser les filtres de chaque colonne, par exemple **Vente**, **Numéro** ou **Date d'émission**.
*   Cochez le cercle à gauche de la facture.

    <figure><img src="../../.gitbook/assets/facturas-reenviar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Renvoyer ou télécharger

* Cliquez sur **Renvoyer** pour l'envoyer de nouveau au client.
* Cliquez sur **Télécharger** pour télécharger la facture en PDF.
{% endstep %}
{% endstepper %}
