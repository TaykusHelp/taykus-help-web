# Factures

Vous pouvez émettre la facture d'une vente depuis plusieurs listes de **Ventes**. Dans tous les cas, la même fenêtre de la vente s'ouvre, avec le bouton **Émettre une facture**. Seul l'endroit où cliquer change :

* **Ventes › lignes :** cliquez sur l'**ID** de la ligne. Consultez [Comment émettre une facture depuis Ventes > lignes](como-emitir-una-factura-desde-ventas-greater-than-lineas.md).
* **Ventes › Paiements :** cliquez sur le numéro de la colonne **Vente**. Consultez [Comment émettre une facture depuis Ventes > Paiements](como-emitir-una-factura-desde-ventas-pagos.md).
* **Ventes › Paiements par chèque :** comme dans Paiements, cliquez sur le numéro de la colonne **Vente**.
* **Ventes › Dettes :** comme dans lignes, cliquez sur l'**ID**.

> **Important :** il n'est pas possible d'émettre des factures depuis le point de vente.

Quand vous l'enregistrez, la facture est envoyée automatiquement au client. Pour la renvoyer ou la télécharger, consultez [Comment renvoyer ou télécharger une facture](como-reenviar-o-descargar-una-factura.md).
