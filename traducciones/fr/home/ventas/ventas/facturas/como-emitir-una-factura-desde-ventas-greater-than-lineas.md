# Comment émettre une facture depuis Ventes > lignes

L'une des sections les plus utilisées du logiciel est la gestion des ventes et leur facturation. Pour cela, vous devez savoir comment retrouver une vente déjà enregistrée, accéder à son détail et émettre une facture avec les données fiscales correspondantes.

La vidéo suivante montre comment faire :

### Vidéo explicative

{% embed url="https://youtu.be/dW3OHLSIm6s" %}

Dans cet article, nous voyons comment émettre une facture depuis Ventes > lignes et les étapes à suivre :

### Avant de commencer

Avant d'émettre la facture, vérifiez que ces données sont créées dans :

* **Paramètres > Ventes > Entreprises**
* **Paramètres > Ventes > Sociétés clientes**

Pour savoir comment faire, consultez ces articles :

<a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/empresas/como-configurar-los-datos-de-empresa" class="button primary">Comment configurer les données de l'entreprise</a>

<a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/empresas-clientes/como-crear-empresas-cliente-en-el-sistema" class="button primary">Comment créer des sociétés clientes dans le système</a>

{% step %}
### Accès à Ventes - lignes

* Dans le menu latéral, ouvrez **Ventes**.
* Cliquez sur **lignes**.
*   Cherchez la ligne de vente à partir de laquelle vous voulez émettre la facture.<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Comment émettre la facture

* Une fois la ligne trouvée, cliquez sur l'**ID**.
*   Dans la vente, cliquez sur le bouton **Émettre une facture**.<br>

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
* Une fenêtre s'ouvre avec les données de facturation.
{% endstep %}

{% step %}
### Remplir les données de la facture

Dans le bloc **Émetteur** :

* Sélectionnez l'**entreprise émettrice** dans le champ **Entreprise**.
* Le système remplit automatiquement les données associées, par exemple :
  * Nom
  * CIF
  * E-mail
  * Téléphone

<figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

Dans le bloc **Acheteur**, vous pouvez choisir entre deux options :

**Personne physique**

Si la facture est pour un particulier :

* Laissez cochée l'option **Personne physique**.
* Vérifiez ou complétez les données du client :
  * Nom complet
  * DNI
  * E-mail
  * Téléphone
  * Adresse

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

**Entreprise**

Si la facture est pour une entreprise :

* Cochez l'option **Entreprise**.
* Dans le champ **Société cliente**, sélectionnez l'entreprise correspondante.
* Le système complète automatiquement les données fiscales de cette entreprise.

<figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Enregistrer la facture

* Quand toutes les données sont vérifiées, cliquez sur l'icône **enregistrer**.
* Le système génère la facture associée à cette vente.
{% endstep %}
{% endstepper %}

Quand vous l'enregistrez, la facture est envoyée automatiquement au client. Si vous devez la renvoyer ou la télécharger, consultez [Comment renvoyer ou télécharger une facture](como-reenviar-o-descargar-una-factura.md).
