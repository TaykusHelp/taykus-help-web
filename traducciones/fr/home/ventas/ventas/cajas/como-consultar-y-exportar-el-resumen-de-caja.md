# Comment consulter et exporter le résumé de caisse

Dans l'onglet **Résumé** de **Ventes › Tiroirs-caisses**, vous pouvez voir combien a été encaissé entre deux dates, par mode de paiement et par type de produit, et le télécharger en Excel. Cet onglet sert uniquement à consulter : les opérations de caisse se font depuis **Mouvements**.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au résumé

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Tiroirs-caisses**.
* L'onglet **Résumé** s'ouvre directement.
{% endstep %}

{% step %}
### Choisir les dates et les caisses

* Dans **Filtres**, indiquez les dates **de** et **À**. Le jour indiqué dans **À** n'est pas inclus : pour voir une seule journée, mettez ce jour dans **de** et le jour suivant dans **À**. Par exemple, pour voir le 27/10, mettez du 27/10 au 28/10.
*   En dessous, cochez les caisses à inclure. Vous pouvez en cocher une ou plusieurs : celles qui sont cochées ont la coche verte.<br>

    <figure><img src="../../.gitbook/assets/cajas-resumen.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Consulter le résumé

* Le tableau **Résumé** affiche, pour chaque mode de paiement, les **Paiements**, les **Entrées manuelles**, les **Retraits manuels**, les **Retraits de clôture** et la **Fermeture de la boîte de nuit** (les écarts de clôture), avec le total en bas. À droite, le graphique **Revenu** montre la répartition par mode de paiement.
*   Plus bas, le tableau **Summary by product type** affiche ce qui a été encaissé pour chaque type de produit (réservations, cotisations, équipement…) et chaque mode de paiement, avec le graphique **Amount by product types**.<br>

    <figure><img src="../../.gitbook/assets/cajas-resumen-tipo-producto.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Exporter vers Excel

*   Cliquez sur **Exporter le résumé**. Un Excel avec le tableau **Résumé** par mode de paiement est téléchargé.<br>

    <figure><img src="../../.gitbook/assets/cajas-resumen-excel.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
