# Comment faire un comptage de caisse

Le comptage de caisse permet de vérifier l'argent présent dans la caisse à un moment donné, sans clôturer la journée.

C'est utile pour vérifier si les espèces réelles correspondent au montant que le système calcule d'après les mouvements enregistrés. Le club peut ainsi repérer d'éventuels écarts, vérifier l'état de la caisse et garder une trace du comptage avant de continuer à travailler.

{% stepper %}
{% step %}
### Accès aux caisses

* Allez dans la colonne de gauche et sélectionnez Ventes.
* Un menu déroulant s'ouvre. Sélectionnez Tiroirs-caisses.\
  <img src="../../.gitbook/assets/image (2).png" alt="" data-size="original">
*   Le résumé de caisse s'affiche. Cliquez sur l'onglet **Mouvements.**<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Faire le comptage

* Cliquez sur **Compte en espèces**.\
  ![](<../../.gitbook/assets/image (26).png>)
*   Cette procédure ne ferme pas la caisse : elle sert seulement à vérifier les espèces présentes à ce moment-là.<br>

    <figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

    *   **Cash**

        Dans le champ **Cash**, vous pouvez indiquer directement le montant total en espèces présent dans la caisse.

        Sous le champ s'affiche le montant que le système calcule que vous auriez dû avoir, d'après les mouvements enregistrés jusqu'à ce moment.

        Vous pouvez ainsi comparer le montant réellement compté avec celui attendu par le système.
    *   **Compte en espèces**

        Vous pouvez aussi remplir la section **Compte en espèces**, en indiquant la quantité réelle de pièces et de billets présents dans la caisse.

        Pour cela, saisissez le nombre d'unités que vous avez pour chaque valeur : centimes, pièces et billets. Le système calcule automatiquement le total des espèces.

        * Le bouton **Clean** efface les montants saisis dans le comptage pour recommencer.
    *   **Card**

        Dans le champ **Card**, vous pouvez indiquer le montant total encaissé par carte pendant la journée.

        * Sous le champ s'affiche le montant que le système calcule que **vous auriez dû** avoir en paiements par carte, d'après les mouvements enregistrés.
    *   **Observations**

        Le champ **Observations** permet d'ajouter toute précision sur le comptage, surtout s'il y a des écarts entre les montants réels et ceux attendus par le système.
    *   **Confirmer le comptage**

        Après avoir vérifié les données, cliquez sur **OK** pour enregistrer le comptage.

        Si vous ne voulez pas l'enregistrer, vous pouvez cliquer sur **Annuler** ou fermer la fenêtre avec la **X** en haut.
{% endstep %}
{% endstepper %}

Une fois le comptage confirmé, le système enregistre les informations saisies sans fermer la caisse.

Le club peut ainsi consulter l'état réel de la caisse à ce moment-là, vérifier les éventuels écarts entre les espèces comptées et le montant attendu, et garder un meilleur contrôle des mouvements enregistrés pendant la journée.
