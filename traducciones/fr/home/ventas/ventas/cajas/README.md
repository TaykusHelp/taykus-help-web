# Caisses

Dans **Ventes › Tiroirs-caisses**, vous suivez l'argent qui entre et sort du club. L'écran comporte deux onglets :

* **Résumé :** les totaux des encaissements par mode de paiement et par type de produit, avec leurs graphiques, entre les dates de votre choix. Ici, on consulte seulement et on peut exporter vers Excel. Consultez [Comment consulter et exporter le résumé de caisse](como-consultar-y-exportar-el-resumen-de-caja.md).
* **Mouvements :** la liste de toutes les opérations de la caisse (encaissements, entrées, retraits…). C'est ici que se font les opérations de caisse avec les boutons **Compte en espèces**, **Retrait**, **Entrée** et **Fermer**.

<figure><img src="../../.gitbook/assets/cajas-movimientos.png" alt=""><figcaption></figcaption></figure>

Si la caisse est fermée, vous devrez d'abord l'ouvrir. Pour chaque opération, consultez ces articles :

* [Comment ouvrir la caisse](como-abrir-la-caja.md)
* [Comment faire un comptage de caisse](como-hacer-un-recuento-de-caja.md)
* [Comment faire une entrée ou un retrait d'espèces](como-hacer-una-entrada-o-retirada-de-efectivo.md)
* [Comment fermer la caisse](como-cerrar-la-caja.md)
