# Comment voir les cotisations

Vous pouvez consulter les cotisations de trois façons : par cotisation, pour voir toutes les personnes qui l'ont ; par client, pour voir toutes les cotisations d'une personne ; ou depuis un groupe de l'académie.

## Depuis Ventes : toutes les personnes ayant une cotisation

{% stepper %}
{% step %}
### Accès aux cotisations

*   Allez dans le menu latéral gauche, sélectionnez **Ventes** puis, dans le menu déroulant, choisissez **ventes périodiques**. Vous verrez la liste de toutes les cotisations du club.

    <figure><img src="../../.gitbook/assets/cuotas-listado.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir le calendrier de la cotisation

* Cliquez sur l'**ID** de la cotisation.
*   Ouvrez l'onglet **Calendrier**. Vous verrez une ligne par personne ayant cette cotisation et une colonne par mois, avec le montant de chaque échéance.

    <figure><img src="../../.gitbook/assets/cuotas-calendario.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

## Depuis la fiche du client : toutes ses cotisations

{% stepper %}
{% step %}
### Accès à la fiche

* Allez dans le menu latéral gauche et sélectionnez **Clients**.
* Cherchez le client et cliquez sur son **ID**.
{% endstep %}

{% step %}
### Ouvrir ses cotisations

*   Cliquez sur l'onglet **Facturation** puis, dans le menu déroulant, choisissez **ventes périodiques**. Vous verrez toutes les cotisations de ce client, mois par mois.

    <figure><img src="../../.gitbook/assets/cuotas-ficha-jugador.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

## Ce que vous pouvez faire avec une cotisation

Depuis l'un de ces écrans, cochez le cercle de la cotisation d'un mois et cliquez sur **Actions**. Vous pouvez en cocher plusieurs à la fois :

*   Le cercle à côté du nom d'un client coche toutes ses cotisations.

    <figure><img src="../../.gitbook/assets/cuotas-seleccionar-jugador.png" alt=""><figcaption></figcaption></figure>
*   Le cercle à côté d'un mois coche celles de tous les clients pour ce mois.

    <figure><img src="../../.gitbook/assets/cuotas-seleccionar-mes.png" alt=""><figcaption></figcaption></figure>

Selon l'état de la cotisation, vous aurez des actions différentes :

* Si la cotisation **n'est pas émise**, vous pouvez la payer, l'émettre, modifier son prix, la passer ou changer son jour d'échéance.
* Si la cotisation **est déjà émise**, vous pouvez seulement la payer ou la rétablir.

## Ce que signifie chaque couleur

* **Bleu :** non émise.
* **Orange :** émise, en attente de paiement.
* **Vert :** payée.
* **Gris :** passée.
