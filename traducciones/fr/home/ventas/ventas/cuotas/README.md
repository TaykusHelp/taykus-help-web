# Cotisations

Dans **Ventes › ventes périodiques**, vous gérez les cotisations : des encaissements qui se répètent selon une périodicité, par exemple la mensualité d'un groupe de l'académie. Tant qu'une cotisation n'est pas émise, vous pouvez modifier son prix, son jour d'échéance ou la passer.

Avant tout, la cotisation doit être créée comme produit. Consultez [Comment créer un produit de type Cotisation](../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md).

Depuis cette section, vous pouvez :

* [Voir les cotisations](como-ver-las-cuotas.md) par cotisation, par client ou depuis un groupe de l'académie.
* [Émettre une cotisation](como-emitir-una-cuota.md) pour qu'elle soit en attente de paiement.
* [Payer une cotisation](como-pagar-una-cuota.md) depuis le calendrier des cotisations.
* [Rétablir une cotisation](como-restablecer-una-cuota.md) si vous l'avez émise par erreur.
* [Passer une cotisation](como-omitir-una-cuota.md) pour que cette échéance ne soit pas encaissée.
* [Modifier le prix d'une cotisation](como-modificar-el-precio-de-una-cuota.md).
* [Changer le jour d'échéance d'une cotisation](como-cambiar-el-dia-de-vencimiento-de-una-cuota.md).
* [Activer le prélèvement automatique par carte](como-activar-el-cobro-automatico-con-tarjeta.md).
* [Automatiser l'émission des cotisations](como-automatizar-la-emision-de-cuotas.md).
* [Automatiser l'annulation pour impayé](como-automatizar-la-cancelacion-por-impago.md).
* [Désinscrire un client d'une cotisation](como-dar-de-baja-a-un-cliente-de-una-cuota.md).

Si la cotisation change le type de client (par exemple, de Non-membre à Membre), c'est une adhésion. Consultez [Qu'est-ce qu'une adhésion et comment fonctionne-t-elle](que-es-una-membresia-y-como-funciona.md).
