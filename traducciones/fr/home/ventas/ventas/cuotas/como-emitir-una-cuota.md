# Comment émettre une cotisation

Quand vous émettez une cotisation, le logiciel enregistre la dette : une ligne de vente en attente de paiement est créée et le client la voit dans son espace client, parmi ses ventes en attente, pour pouvoir la payer.

> **Important :** si l'émission automatique est activée sur la cotisation, elle s'émet toute seule et il n'est pas nécessaire de le faire à la main. Pour savoir comment l'activer, consultez [Comment automatiser l'émission des cotisations](como-automatizar-la-emision-de-cuotas.md). Pour savoir comment créer la cotisation, consultez cet article :
>
> <a href="../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md" class="button primary">Comment créer un produit de type Cotisation</a>

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux cotisations

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **ventes périodiques**.
* Cliquez sur l'**ID** de la cotisation.
* Ouvrez l'onglet **Calendrier**.

> Vous pouvez aussi le faire depuis la fiche du client ou depuis un groupe de l'académie. Pour savoir comment, consultez cet article :
>
> <a href="como-ver-las-cuotas.md" class="button primary">Comment voir les cotisations</a>
{% endstep %}

{% step %}
### Sélectionner la cotisation

* Cochez le cercle de la cotisation du mois que vous voulez émettre, sur la ligne du client.
* Vous pouvez en cocher plusieurs à la fois : le cercle à côté du nom d'un client coche toutes ses cotisations, et le cercle à côté d'un mois coche celles de tous les clients pour ce mois. L'action s'applique à toutes celles que vous cochez.
*   Cliquez sur **Actions**, en haut à gauche.

    <figure><img src="../../.gitbook/assets/cuotas-acciones.png" alt=""><figcaption></figcaption></figure>
* Par exemple, pour émettre toutes les cotisations d'un mois, cochez le cercle à côté de ce mois :

    <figure><img src="../../.gitbook/assets/cuotas-seleccionar-mes.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Émettre

* Dans le menu **Actions**, choisissez **Emettre**.
*   Cliquez sur **OK** pour confirmer.

    <figure><img src="../../.gitbook/assets/cuotas-emitir.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Une fois émise, la cotisation ne peut plus qu'être payée ou rétablie. Si vous devez la modifier, rétablissez-la d'abord. Pour savoir comment, consultez cet article :

<a href="como-restablecer-una-cuota.md" class="button primary">Comment rétablir une cotisation</a>
