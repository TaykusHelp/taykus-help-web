# Comment désinscrire un client d'une cotisation

Pour désinscrire un client d'une cotisation, ou d'une adhésion, changez sa date de fin dans la cotisation. À partir de cette date, ses échéances ne sont plus émises et, si la cotisation est une adhésion, il passe au type de client de résiliation.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à la cotisation

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
*   Dans le menu déroulant, choisissez **ventes périodiques**.

    <figure><img src="../../.gitbook/assets/cuotas-listado.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur l'**ID** de la cotisation.
* Ouvrez l'onglet **Clients**.
{% endstep %}

{% step %}
### Changer la date de fin

*   Trouvez le client dans la liste.

    <figure><img src="../../.gitbook/assets/cuotas-baja-jugadores.png" alt=""><figcaption></figcaption></figure>
* Modifiez sa date de **Fin** et indiquez le jour où vous voulez qu'il soit désinscrit.
{% endstep %}
{% endstepper %}

> **Important :** seule la date de ce client change. Les autres clients de la cotisation restent identiques.

Pour en savoir plus sur les adhésions, consultez [Qu'est-ce qu'une adhésion et comment fonctionne-t-elle](que-es-una-membresia-y-como-funciona.md).
