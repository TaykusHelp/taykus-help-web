# Comment rétablir une cotisation

Rétablir une cotisation annule l'émission : la cotisation redevient comme avant d'être émise. C'est utile si vous l'avez émise par erreur ou si vous devez changer son prix, son jour d'échéance ou la passer, car une cotisation émise ne peut être que payée ou rétablie.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux cotisations

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **ventes périodiques**.
* Cliquez sur l'**ID** de la cotisation.
* Ouvrez l'onglet **Calendrier**.

> Vous pouvez aussi le faire depuis la fiche du client ou depuis un groupe de l'académie. Pour savoir comment, consultez cet article :
>
> <a href="como-ver-las-cuotas.md" class="button primary">Comment voir les cotisations</a>
{% endstep %}

{% step %}
### Sélectionner la cotisation

* Cochez le cercle de la cotisation du mois que vous voulez rétablir, sur la ligne du client.
* Vous pouvez en cocher plusieurs à la fois : le cercle à côté du nom d'un client coche toutes ses cotisations, et le cercle à côté d'un mois coche celles de tous les clients pour ce mois. L'action s'applique à toutes celles que vous cochez.
*   Cliquez sur **Actions**, en haut à gauche.

    <figure><img src="../../.gitbook/assets/cuotas-acciones-emitida.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Rétablir

* Dans le menu **Actions**, choisissez **Restaurer**.
*   Cliquez sur **OK** pour confirmer.

    <figure><img src="../../.gitbook/assets/cuotas-restablecer.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

La ligne de vente en attente disparaît, aussi bien de Ventes › lignes que de l'espace client du client. À partir de là, la cotisation a de nouveau toutes les actions disponibles : payer, émettre, modifier le prix, passer ou changer le jour d'échéance.
