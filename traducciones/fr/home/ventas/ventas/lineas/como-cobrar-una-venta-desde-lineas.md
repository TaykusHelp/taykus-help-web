# Comment encaisser une vente depuis lignes

Depuis **Ventes › lignes**, vous pouvez encaisser n'importe quelle vente en attente : elle s'ouvre au point de vente et s'encaisse comme une vente normale. Vous pouvez encaisser une seule ligne ou plusieurs à la fois, même de clients différents. Par exemple, quand un client vient payer sa part et celle d'un autre.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à lignes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
*   Dans le menu déroulant, choisissez **lignes**.<br>

    <figure><img src="../../.gitbook/assets/lineas-listado.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélectionner les lignes

* Trouvez la vente à encaisser. Vous pouvez utiliser les filtres de chaque colonne, par exemple **Acheteur**.
* Cochez la case à gauche de la ligne. Si vous voulez en encaisser plusieurs à la fois, cochez-les toutes.
* Cliquez sur **Ouvrir point de vente**.
{% endstep %}

{% step %}
### Encaisser au point de vente

* Le point de vente s'ouvre avec la vente chargée.
* Si vous avez coché plusieurs lignes, vous pouvez passer d'un ticket à l'autre depuis le point de vente, ou charger toutes les ventes dans le ticket de droite pour les encaisser ensemble.
* Encaissez la vente comme d'habitude.
{% endstep %}
{% endstepper %}

> **Important :** vous devez avoir une caisse ouverte pour pouvoir encaisser. Consultez [Comment ouvrir la caisse](../cajas/como-abrir-la-caja.md).

Si vous cochez une ligne déjà payée, elle s'ouvre au point de vente avec l'état **Payé** et il n'y aura rien à encaisser :

<figure><img src="../../.gitbook/assets/lineas-tpv-pagado.png" alt=""><figcaption></figcaption></figure>

Si vous avez des doutes sur l'encaissement au point de vente, consultez [Comment faire une vente](https://taykus-help-center.gitbook.io/taykushelpcenter/home/tpv/tpv/ventas/como-hacer-una-venta).
