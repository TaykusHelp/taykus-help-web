# Comment annuler une vente depuis lignes

Si une vente a été enregistrée par erreur ou si son montant doit être remboursé, vous pouvez l'annuler depuis **Ventes › lignes**. Vous pouvez annuler une seule ligne ou plusieurs à la fois.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à lignes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **lignes**.
{% endstep %}

{% step %}
### Sélectionner la ligne

* Trouvez la vente à annuler. Vous pouvez utiliser les filtres de chaque colonne, par exemple **Acheteur**.
* Cochez la case à gauche de la ligne. Si vous voulez en annuler plusieurs, cochez-les toutes.
* Cliquez sur **Annuler**.
{% endstep %}

{% step %}
### Choisir l'option d'annulation

*   Un menu déroulant s'ouvre. Choisissez **Annuler les dettes et restituer les paiements**.<br>

    <figure><img src="../../.gitbook/assets/lineas-anular.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirmer

*   Une fenêtre s'ouvre pour vous demander de confirmer :<br>

    <figure><img src="../../.gitbook/assets/lineas-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **OK** pour l'annuler, ou sur **Fermer** si vous ne voulez pas l'annuler.
{% endstep %}
{% endstepper %}

Une fois la vente annulée, vous verrez deux lignes de couleur dans la liste : en rose clair le remboursement (avec le montant en négatif) et en rose plus foncé la vente annulée.

> **Important :** si l'annulation implique de rembourser un paiement en espèces ou par carte, vous devez avoir une caisse ouverte. S'il s'agit du remboursement d'un paiement en ligne, ce n'est pas nécessaire. Pour ouvrir une caisse, consultez [Comment ouvrir la caisse](../cajas/como-abrir-la-caja.md).

Vous pouvez aussi annuler une vente depuis la fiche du client. Consultez [Comment annuler une vente depuis la fiche du client](../../../jugadores/jugadores/fichas-de-jugador/como-anular-una-venta-desde-la-ficha-del-jugador.md).

Si vous voulez annuler une recharge de bon, consultez [Comment annuler une recharge de bon](como-anular-una-recarga-de-bono.md).
