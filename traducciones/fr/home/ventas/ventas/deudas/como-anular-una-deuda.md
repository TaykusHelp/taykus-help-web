# Comment annuler une dette

Si une dette ne sera pas encaissée, vous pouvez l'annuler depuis **Ventes › Dettes** pour qu'elle n'apparaisse plus comme en attente.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux dettes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Dettes**. L'onglet **Paiement en attente** s'ouvre.
{% endstep %}

{% step %}
### Sélectionner la dette

* Cochez la case à gauche de la dette que vous voulez annuler.
*   Cliquez sur **Annuler**.<br>

    <figure><img src="../../.gitbook/assets/deudas-anular.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choisir l'option d'annulation

*   Un menu déroulant s'ouvre. Choisissez **Annuler les dettes et restituer les paiements**.<br>

    <figure><img src="../../.gitbook/assets/deudas-anular-opciones.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirmer

*   Une fenêtre s'ouvre pour vous demander de confirmer :<br>

    <figure><img src="../../.gitbook/assets/deudas-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **OK** pour l'annuler, ou sur **Fermer** si vous ne voulez pas l'annuler.
{% endstep %}
{% endstepper %}

> **Important :** si l'annulation implique de rembourser un paiement en espèces ou par carte, vous devez avoir une caisse ouverte. S'il s'agit du remboursement d'un paiement en ligne, ce n'est pas nécessaire. Pour ouvrir une caisse, consultez [Comment ouvrir la caisse](../cajas/como-abrir-la-caja.md).
