# Comment encaisser une dette

Depuis **Ventes › Dettes**, vous pouvez encaisser ce qu'un client doit encore : la dette s'ouvre au point de vente et s'encaisse comme n'importe quelle autre vente. Vous pouvez encaisser une seule dette ou plusieurs à la fois.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux dettes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Dettes**. L'onglet **Paiement en attente** s'ouvre.
{% endstep %}

{% step %}
### Sélectionner la dette

* Trouvez la dette à encaisser. Vous pouvez utiliser les filtres de chaque colonne, par exemple **Acheteur**.
* Cochez la case à gauche de la dette. Si vous voulez en encaisser plusieurs à la fois, cochez-les toutes.
*   Cliquez sur **Ouvrir point de vente**.<br>

    <figure><img src="../../.gitbook/assets/deudas-abrir-tpv.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Encaisser au point de vente

* Le point de vente s'ouvre avec la dette chargée.
* Si vous avez coché plusieurs dettes, l'option pour charger toutes les ventes apparaît dans le ticket à droite, comme quand un client paie la part d'un autre.
* Encaissez la vente comme d'habitude.
{% endstep %}
{% endstepper %}

Si vous avez des doutes sur l'encaissement au point de vente, consultez [Comment faire une vente](https://taykus-help-center.gitbook.io/taykushelpcenter/home/tpv/tpv/ventas/como-hacer-una-venta).
