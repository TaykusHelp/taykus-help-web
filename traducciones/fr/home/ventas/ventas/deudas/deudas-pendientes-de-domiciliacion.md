# Dettes en attente de prélèvement bancaire

Dans **Ventes › Dettes**, l'onglet **En attente bancaire** affiche les dettes qui seront encaissées par prélèvement bancaire et qui n'ont pas encore été incluses dans une remise. Il fonctionne comme l'onglet **Paiement en attente** : vous pouvez les encaisser, les annuler ou prévenir le client que l'échéance va être prélevée sur son compte.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux dettes en attente de prélèvement

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Dettes**.
*   Ouvrez l'onglet **En attente bancaire**.<br>

    <figure><img src="../../.gitbook/assets/deudas-pendiente-domiciliacion.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choisir quoi faire

Cochez la case à gauche des dettes voulues et cliquez sur le bouton dont vous avez besoin :

* **Ouvrir point de vente :** pour les encaisser. Consultez [Comment encaisser une dette](como-cobrar-una-deuda.md).
* **Annuler :** pour les annuler. Consultez [Comment annuler une dette](como-anular-una-deuda.md).
* **Envoyer l'e-mail de notification :** pour prévenir le client que l'échéance sera prélevée sur son compte dans les prochains jours, afin qu'il ait suffisamment de fonds. Un e-mail est envoyé pour chaque dette sélectionnée, comme dans [Comment envoyer un e-mail de dettes](como-enviar-un-email-de-deudas.md).
{% endstep %}
{% endstepper %}

> **Important :** l'e-mail de prélèvement n'est pas un rappel de dette, mais un avis du prochain prélèvement bancaire. Si vous voulez réclamer un paiement en attente, utilisez l'onglet **Paiement en attente** et le bouton **Envoyer l'e-mail des dettes**.

Si vous voulez passer une dette de **Paiement en attente** à cet onglet, ou l'inverse, consultez [Comment passer une dette de Paiement en attente à En attente bancaire (et inversement)](como-pasar-una-deuda-a-pendiente-domiciliacion.md).

Pour inclure ces dettes dans une remise, consultez [Génération du Q19 (prélèvement des échéances bancaires)](../q19/generacion-del-q19-domiciliacion-de-recibos-bancarios.md).

Le texte de cet e-mail est le modèle **Notification de prélèvement bancaire**, que vous pouvez modifier depuis **Communications › Modèles d'e-mails**. Consultez [Accès aux modèles d'e-mails](https://taykus-help-center.gitbook.io/taykushelpcenter/home/comunicaciones/comunicaciones/acceso-a-plantillas-de-emails).
