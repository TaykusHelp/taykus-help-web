# Comment passer une dette de Paiement en attente à En attente bancaire (et inversement)

Si une dette qui se trouve dans **Paiement en attente** sera encaissée par prélèvement bancaire, vous pouvez la passer dans **En attente bancaire** pour l'inclure dans la prochaine remise. Vous pouvez aussi faire le changement inverse. Le changement se fait depuis le point de vente.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux dettes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Dettes**.
* Ouvrez l'onglet où se trouve actuellement la dette : **Paiement en attente** ou **En attente bancaire**.
{% endstep %}

{% step %}
### Ouvrir la dette au point de vente

* Cochez la case à gauche de la dette.
*   Cliquez sur **Ouvrir point de vente**.<br>

    <figure><img src="../../.gitbook/assets/deudas-cambiar-desde-pago.png" alt=""><figcaption></figcaption></figure>
*   Depuis l'onglet **En attente bancaire**, cela se fait de la même façon :<br>

    <figure><img src="../../.gitbook/assets/deudas-cambiar-desde-domiciliacion.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Changer l'état

Dans la partie droite du point de vente, sous le total, cliquez sur l'option qui convient :

*   **En attente bancaire**, pour la passer en prélèvement bancaire.<br>

    <figure><img src="../../.gitbook/assets/deudas-cambiar-tpv-a-domiciliacion.png" alt=""><figcaption></figcaption></figure>
*   **Paiement en attente**, pour la remettre en attente de paiement.<br>

    <figure><img src="../../.gitbook/assets/deudas-cambiar-tpv-a-pago.png" alt=""><figcaption></figcaption></figure>
* L'écran clignote un instant : le changement est fait.
* Cliquez sur **Sortir**, en bas à droite, pour quitter le point de vente.
{% endstep %}

{% step %}
### Vérifier le changement

* Revenez à **Ventes › Dettes**.
* La dette apparaît désormais dans l'autre onglet : dans **En attente bancaire** si vous l'avez passée en prélèvement, ou dans **Paiement en attente** si vous l'avez remise.
{% endstep %}
{% endstepper %}

> **Important :** vous pouvez aussi le faire depuis **Ventes › lignes** : cochez la ligne, cliquez sur **Ouvrir point de vente** et suivez l'étape 3.

Pour en savoir plus sur les dettes à prélever, consultez [Dettes en attente de prélèvement bancaire](deudas-pendientes-de-domiciliacion.md).
