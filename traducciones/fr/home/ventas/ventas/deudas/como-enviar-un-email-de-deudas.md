# Comment envoyer un e-mail de dettes

Depuis **Ventes › Dettes**, vous pouvez envoyer un e-mail aux clients qui ont des paiements en attente pour le leur rappeler. Vous pouvez l'envoyer à un client, à plusieurs ou à tous à la fois.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux dettes

* Allez dans le menu latéral gauche et sélectionnez **Ventes**.
* Dans le menu déroulant, choisissez **Dettes**. L'onglet **Paiement en attente** s'ouvre.
{% endstep %}

{% step %}
### Sélectionner les dettes

* Cochez la case à gauche de chaque dette à inclure.
* Si vous voulez l'envoyer à tous, cochez la case dans l'en-tête de la liste : toutes les dettes sont sélectionnées.
*   Cliquez sur **Envoyer l'e-mail des dettes**. Les e-mails partent immédiatement, sans fenêtre de confirmation.<br>

    <figure><img src="../../.gitbook/assets/deudas-enviar-email.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Important :** un e-mail est envoyé pour chaque dette sélectionnée. Si un client a plusieurs dettes et que vous les cochez toutes, il recevra un e-mail pour chacune.

Le texte de l'e-mail est le modèle **Notification de dette**, que vous pouvez modifier depuis **Communications › Modèles d'e-mails**. Consultez [Accès aux modèles d'e-mails](https://taykus-help-center.gitbook.io/taykushelpcenter/home/comunicaciones/comunicaciones/acceso-a-plantillas-de-emails).

Pour vérifier si les e-mails sont partis, consultez [Où voir l'état d'envoi des e-mails](https://taykus-help-center.gitbook.io/taykushelpcenter/home/comunicaciones/comunicaciones/donde-ver-el-estado-de-envio-de-los-correos).
