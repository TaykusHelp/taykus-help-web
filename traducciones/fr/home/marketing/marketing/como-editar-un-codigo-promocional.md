# Comment modifier un code promo

Les codes promo peuvent être modifiés à tout moment pour ajuster les réductions, les dates ou les limites d'utilisation selon les besoins de la campagne. Bien les modifier permet de garder le contrôle des promotions actives sans avoir à créer de nouveaux codes.

Dans cet article, nous vous expliquons comment modifier un code promo étape par étape.

{% stepper %}
{% step %}
### Accès à Codes promo

* Allez dans le menu latéral gauche et sélectionnez **Marketing.**
*   Dans le menu déroulant, cliquez sur **Codes promo** : l'onglet **Promotions** s'ouvre directement.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection de la promotion

* Cliquez sur l'id du code à modifier.
*   Cette section s'ouvre, comme sur l'image :<br>

    <figure><img src="../.gitbook/assets/detalle-promocion.png" alt=""><figcaption></figcaption></figure>

    *   En haut, dans la section **Général**, se trouve un résumé de l'état de la promotion :

        * **Nom :** nom de la promotion. Il peut être modifié à tout moment.
        * **Utilisations :** nombre total de fois où le code a été utilisé.
        * **Codes au total :** quantité de codes créés dans la promotion. Elle correspond à la **Quantité** indiquée à la création, c'est-à-dire au nombre de fois où le code peut être utilisé.

        En dessous apparaît la liste des **Codes promo** associés à la promotion.
{% endstep %}

{% step %}
### Modifier le code promo

* Cliquez sur l'id du code.
*   Cliquez sur <i class="fa-pen" style="color:green;">:pen:</i>

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
* Modifiez les champs nécessaires et cliquez sur Sauvegarder pour enregistrer les changements.
{% endstep %}
{% endstepper %}

Modifier un code promo permet d'adapter les campagnes actives sans créer de nouvelles promotions. Vérifier régulièrement ses paramètres aide à garder le contrôle des réductions et à éviter les erreurs d'application.
