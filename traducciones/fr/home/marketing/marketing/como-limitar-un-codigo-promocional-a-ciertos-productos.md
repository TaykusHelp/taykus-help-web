# Comment limiter un code promo à certains produits

Vous pouvez faire en sorte qu'un code promo ne s'applique qu'aux produits de votre choix, par exemple aux réservations en heure creuse ou à la location de raquette. On crée d'abord le code, puis on ajoute les produits autorisés depuis la promotion elle-même.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Codes promo

* Allez dans le menu latéral gauche et sélectionnez **Marketing.**
*   Dans le menu déroulant, cliquez sur **Codes promo** : l'onglet **Promotions** s'ouvre directement.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

> **Important :** le code promo doit être créé avant de le limiter. Si ce n'est pas encore fait, consultez cet article :
>
> <a href="como-hacer-un-codigo-promocional.md" class="button primary">Comment créer un code promo</a>
{% endstep %}

{% step %}
### Ouvrir la promotion

* Cliquez sur l'id de la promotion à limiter.
*   Le détail de la promotion s'ouvre avec ses codes promo :<br>

    <figure><img src="../.gitbook/assets/detalle-promocion.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ajouter les produits autorisés

* Faites défiler jusqu'à la section **Produits autorisés**.
*   Cliquez sur :heavy\_plus\_sign:<br>

    <figure><img src="../.gitbook/assets/productos-permitidos.png" alt=""><figcaption></figcaption></figure>
*   Dans le champ **Produit**, cherchez et sélectionnez le produit auquel s'appliquera la réduction.<br>

    <figure><img src="../.gitbook/assets/anadir-producto-permitido.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Sauvegarder**.
* Répétez ces étapes pour chaque produit à ajouter.
{% endstep %}

{% step %}
### Copier les produits d'une autre promotion (facultatif)

Si vous avez déjà une autre promotion avec les mêmes produits autorisés, vous pouvez les copier au lieu de les ajouter un par un. Au-dessus de **Produits autorisés**, il y a deux boutons :

* **Copy products to... :** utilisez-le quand vous êtes dans la promotion qui a déjà les produits et que vous voulez les copier vers une autre. Par exemple, d'une ancienne promotion vers une nouvelle.
* **Copy products from... :** utilisez-le quand vous êtes dans la nouvelle promotion et que vous voulez récupérer les produits d'une autre. Par exemple, d'une ancienne promotion.
{% endstep %}
{% endstepper %}

> **Important :** si vous n'ajoutez aucun produit, le code s'applique à tous les produits.

Une fois les produits ajoutés, la réduction ne s'appliquera qu'aux produits de la liste. Nous conseillons de tester le code avec un produit autorisé et un produit non autorisé avant de le partager avec les clients.
