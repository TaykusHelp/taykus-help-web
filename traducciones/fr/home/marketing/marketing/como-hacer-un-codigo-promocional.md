# Comment créer un code promo

Les codes promo permettent d'appliquer des réductions de façon rapide et maîtrisée sur des réservations, des produits ou des services. C'est un outil utile pour des campagnes ponctuelles, la fidélisation des clients ou des promotions spéciales. Dans cet article, vous apprendrez à créer un code promo étape par étape et à bien le configurer selon vos besoins.

{% stepper %}
{% step %}
### Accès à Codes promo

* Allez dans le menu latéral gauche et sélectionnez **Marketing.**
*   Dans le menu déroulant, cliquez sur **Codes promo** : l'onglet **Promotions** s'ouvre directement.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le code promo

* Cliquez sur :heavy\_plus\_sign:
*   Une section s'ouvre, à remplir ainsi :

    <figure><img src="../.gitbook/assets/anadir-promocion.png" alt=""><figcaption></figcaption></figure>

    * **Nom :** nom interne de la promotion pour l'identifier dans le système. Un nom clair qui permet de reconnaître facilement le code est conseillé.
    * **Quantité :** nombre de fois où le code pourra être utilisé, avec un maximum de **1000**. Par exemple, si vous écrivez 50, le système crée le même code 50 fois et il pourra être utilisé 50 fois au total.
    * **Type de réduction :** définit comment la réduction s'appliquera. Elle peut être en **argent** (montant fixe) ou en **pourcentage** sur le prix.
    * **Réduction :** valeur de la réduction qui s'appliquera selon le type choisi.
    * **Date de début :** date à partir de laquelle le code sera actif. S'il reste vide, le code est actif dès son enregistrement.
    * **Date de fin :** date limite de validité du code. À partir de ce jour, il cessera de fonctionner automatiquement. S'il reste vide, le code n'expire pas.
    * **Commence par :** préfixe par lequel commenceront les codes générés automatiquement par le système (par exemple, `ETE-`).
    * **Texte exact :** code fixe de votre choix que le client devra saisir (par exemple, `ETE10`). C'est le texte qui sera partagé publiquement.

    > **Important :** ne remplissez qu'un des deux champs : **Commence par** ou **Texte exact**.
* Cliquez sur **Sauvegarder**.
{% endstep %}

{% step %}
### Vérifier le fonctionnement du code

* Allez sur le site ou l'application et faites une réservation.
* Une fois au résumé de la réservation, saisissez le code promo.
*   Cliquez sur **Appliquer le code**.<br>

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>


* Si le code a été créé correctement, la réduction s'applique automatiquement.
*   Si le code a été créé ou saisi de façon incorrecte, un message d'erreur s'affiche indiquant qu'il ne peut pas être appliqué.<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Créer et vérifier correctement un code promo garantit que les réductions s'appliquent sans erreur et évite les problèmes en caisse ou dans les réservations en ligne. Nous conseillons de toujours tester le code avant de le partager avec les clients, pour s'assurer qu'il fonctionne comme prévu.
