# Comment faire une entrée manuelle de stock

Dans cet article, nous vous montrons comment faire une entrée manuelle de stock. Il y a deux façons d'ajouter de l'inventaire à vos produits.

La première option consiste à ouvrir la liste des demandes de stock, à entrer dans le bloc des entrées et à ajouter les nouvelles quantités pour chaque article. Cette méthode est idéale pour mettre à jour plusieurs produits à la fois de façon rapide et simple.

Pour savoir comment, consultez cet article :\
<a href="como-crear-una-peticion-de-stock.md" class="button primary">Comment créer une demande de stock</a>

Si en revanche vous devez ajouter du stock à un seul article, mieux vaut choisir la seconde option, pensée pour gérer les entrées individuelles.

Pour cela, il suffit de suivre ces étapes simples :

{% stepper %}
{% step %}
### Accès à Entrée manuelle

* Allez dans la colonne de gauche et sélectionnez Entrepôt.
* Dans le menu déroulant, cliquez sur Entrée manuelle.
{% endstep %}

{% step %}
### Ajouter l'entrée

* Sélectionnez, en haut à gauche, Ajouter une entrée.
*   Le formulaire suivant s'ouvre, à remplir ainsi :<br>

    <div align="left"><figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure></div>

    * **Qté :** c'est la quantité à ajouter.
    * **Chercher un produit :** en le sélectionnant, une liste de tous les produits avec suivi de stock s'ouvre.
* Cliquez sur Ajouter pour enregistrer les changements.
{% endstep %}
{% endstepper %}

Après l'entrée, le système affichera immédiatement les nouvelles quantités dans l'inventaire.\
Pensez à vérifier la liste des articles pour confirmer que le stock a été correctement mis à jour.
