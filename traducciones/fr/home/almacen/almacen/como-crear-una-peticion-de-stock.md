# Comment créer une demande de stock

Dans cet article, nous vous expliquons pas à pas comment utiliser le module entrepôt. Grâce à un système intuitif et efficace, vous pourrez suivre précisément le stock disponible, gérer les entrées et sorties de produits et garder les informations à jour en temps réel. Ce processus optimise l'organisation interne, facilite la prise de décision et évite les ruptures ou les excédents d'inventaire.

Voici comment faire :

{% stepper %}
{% step %}
### Accès à Entrepôt

* Allez dans la colonne de gauche et sélectionnez **Entrepôt**.
* La section qui contient toutes les demandes de stock s'ouvre.
{% endstep %}

{% step %}
### Créer une nouvelle demande de stock

* Cliquez sur :heavy\_plus\_sign: pour en créer une nouvelle.
*   Un court formulaire s'ouvre, à remplir avec les données suivantes :

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Description :** indiquez le nom de la commande/demande. Nous vous conseillons d'y inclure la date.
    * **Commentaires des clients :** espace pour ajouter une description supplémentaire.
    * **Validé :&#x20;**<mark style="background-color:$warning;">**IMPORTANT.**</mark> La commande doit avoir cette case cochée pour pouvoir ajouter du stock à l'étape suivante.
* Cliquez sur Sauvegarder pour enregistrer la demande.
{% endstep %}

{% step %}
### Ajouter des produits

* À l'enregistrement, le logiciel vous amène à la demande.
* Sinon, cliquez sur l'Id de la demande à laquelle vous voulez ajouter des produits.
*   Sur l'écran suivant, cliquez sur Ajouter des produits.

    * _<mark style="background-color:$warning;">(Seuls les produits pour lesquels « A du stock » est coché peuvent être ajoutés, voir l'article : PARAMÈTRES : Ventes / Produits – Suivi du stock)</mark>_

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>


* Cette action ouvre une fenêtre avec les produits marqués avec stock.
* Sélectionnez les produits à ajouter à la demande.
* Cliquez sur Sélectionner, en haut à gauche, pour enregistrer la sélection.
* Une fois les produits ajoutés, l'écran se met à jour et affiche le stock actuel de chaque article.
*   Repérez la colonne Quantité demandée et écrivez le nombre d'articles à demander pour chaque produit.<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Ensuite, vous pouvez exporter la liste vers Excel si besoin et l'envoyer à votre fournisseur, en cliquant sur :arrow\_down:.
{% endstep %}

{% step %}
### Ajouter du stock

* Dans le module Entrepôt, où se trouvent toutes les demandes de stock, cliquez sur l'id de la demande créée.
*   Ouvrez le bloc **Entrées**.

    <figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
*   Allez dans la colonne **Ajouter la quantité livrée**.<br>

    <figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
* Écrivez la quantité d'articles reçus et appuyez sur Entrée.
{% endstep %}
{% endstepper %}

Une fois les quantités livrées saisies, le système mettra automatiquement à jour l'inventaire de chaque produit, en affichant le nouveau stock disponible en temps réel.\
Vous pourrez consulter ou modifier la demande à tout moment depuis le module entrepôt si nécessaire.
