# Comment retirer du stock

Dans ce module, vous pouvez retirer des produits de l'inventaire simplement. Cela se fait depuis **Entrée manuelle** : vous choisissez le produit et indiquez en négatif combien d'unités vous voulez déduire.

Cela aide à garder le stock à jour et évite les erreurs d'inventaire.

Pour cela, il suffit de suivre ces étapes simples :

{% stepper %}
{% step %}
### Accès à Entrée manuelle

* Allez dans la colonne de gauche et sélectionnez **Entrepôt**.
* Dans le menu déroulant, cliquez sur **Entrée manuelle**.
{% endstep %}

{% step %}
### Retirer la quantité

* Sélectionnez, en haut à gauche, **Ajouter une entrée**.
*   Le formulaire suivant s'ouvre, à remplir ainsi :<br>

    <div align="left"><figure><img src="../.gitbook/assets/Captura de pantalla 2026-10-22 123351.png" alt=""><figcaption></figcaption></figure></div>

    * **Qté :** c'est la quantité à retirer, en **NÉGATIF**, en ajoutant le signe moins devant.
    * **Chercher un produit :** en le sélectionnant, une liste de tous les produits avec suivi de stock s'ouvre.
* Cliquez sur Ajouter pour enregistrer les changements.
{% endstep %}
{% endstepper %}

Après avoir enregistré l'entrée manuelle, le système mettra immédiatement à jour le stock du produit.\
L'ajustement restera enregistré dans l'inventaire et pourra être consulté ou corrigé ensuite si nécessaire.
