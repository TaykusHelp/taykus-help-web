# Comment envoyer un e-mail groupé aux clients

Depuis la liste des clients, vous pouvez filtrer vos clients et leur envoyer le même e-mail à tous en une fois. C'est très utile pour annoncer des nouveautés, des avis ou des promotions du club.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Clients

* Allez dans le menu latéral gauche et sélectionnez **Clients**.

<figure><img src="../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Filtrer les clients

* Utilisez les filtres de chaque colonne pour ne garder que les clients à qui vous voulez écrire.

<div align="left"><figure><img src="../.gitbook/assets/image (95).png" alt=""><figcaption></figcaption></figure></div>

> Cette étape est facultative. Si vous voulez écrire à tous les clients, passez-la.
{% endstep %}

{% step %}
### Sélectionner les destinataires

* Cochez la case à côté de **ID**, dans l'en-tête de la liste. Tous les clients de la liste sont sélectionnés.

<figure><img src="../.gitbook/assets/image (96).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir l'envoi d'e-mail

* Cliquez sur l'icône de l'enveloppe et choisissez **Email**.

<figure><img src="../.gitbook/assets/image (97).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Rédiger l'e-mail

La fenêtre **Envoyer un message** s'ouvre :

<div align="left"><figure><img src="../.gitbook/assets/image (98).png" alt=""><figcaption></figcaption></figure></div>

* **EmailRecipient :** tous les clients sélectionnés apparaissent.
* **Modèle :** si vous avez un modèle créé pour ce message, choisissez-le ici et l'objet et le texte se remplissent tout seuls. Pour savoir comment le créer, consultez [Comment créer un modèle](../../comunicaciones/comunicaciones/como-crear-una-plantilla.md).
* **Sujet :** champ obligatoire.
* **Sélectionnez le remplacement à insérer :** sert à personnaliser le message. Par exemple, si vous choisissez **Nom**, `[[Customer.Name]]` est ajouté et remplacé par le nom de chaque client à la réception de l'e-mail.
* **Corps du message :** écrivez le texte. Vous pouvez aussi le coller depuis un autre document ou ajouter des images. Pour savoir comment, consultez [Comment joindre une image à un e-mail](../../comunicaciones/comunicaciones/como-adjuntar-una-imagen-a-un-mail.md).
{% endstep %}

{% step %}
### Envoyer

* Cliquez sur **OK** pour envoyer l'e-mail.
{% endstep %}
{% endstepper %}

Pour vérifier si les e-mails sont partis, consultez [Où voir l'état d'envoi des e-mails](../../comunicaciones/comunicaciones/donde-ver-el-estado-de-envio-de-los-correos.md).
