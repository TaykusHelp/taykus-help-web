# Comment annuler une vente depuis la fiche du client

Vous pouvez annuler une vente d'un client directement depuis sa fiche, sans avoir à la chercher dans **Ventes › lignes**. Depuis la fiche, c'est la ligne de vente entière qui est annulée.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir la fiche du client

*   Allez dans le menu latéral gauche et sélectionnez **Clients**.

    <figure><img src="../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure>
* Cherchez le client avec les filtres du tableau (par exemple, par nom).
* Cliquez sur son **ID** pour ouvrir sa fiche.
{% endstep %}

{% step %}
### Aller à ses achats

*   Cliquez sur l'onglet **Facturation** puis, dans le menu déroulant, choisissez **Achats**.

    <figure><img src="../../.gitbook/assets/ficha-facturacion-compras.png" alt=""><figcaption></figcaption></figure>
* L'onglet **Lignes** s'ouvre, avec toutes les ventes du client.
{% endstep %}

{% step %}
### Sélectionner la vente

*   Cochez le cercle à gauche de la vente à annuler.

    <figure><img src="../../.gitbook/assets/ficha-compras-lineas.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Annuler**.
{% endstep %}

{% step %}
### Choisir l'option d'annulation

*   Un menu déroulant s'ouvre. Choisissez **Annuler les dettes et restituer les paiements**.

    <figure><img src="../../.gitbook/assets/ficha-compras-anular.png" alt=""><figcaption></figcaption></figure>
*   Une fenêtre s'ouvre pour vous demander de confirmer :

    <figure><img src="../../.gitbook/assets/ficha-compras-anular-confirmar.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **OK** pour l'annuler, ou sur **Fermer** si vous ne voulez pas l'annuler.
{% endstep %}
{% endstepper %}

> **Important :** si l'annulation implique de rembourser un paiement en espèces ou par carte, vous devez avoir une caisse ouverte. S'il s'agit du remboursement d'un paiement en ligne, ce n'est pas nécessaire.

Vous pouvez aussi annuler des ventes depuis **Ventes › lignes**. Consultez [Comment annuler une vente depuis lignes](../../../ventas/ventas/lineas/como-anular-una-venta-desde-lineas.md).
