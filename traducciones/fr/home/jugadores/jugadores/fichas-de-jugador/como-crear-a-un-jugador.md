# Comment créer un client

Avoir des clients bien enregistrés vous permet de consulter leurs informations, leur historique et leurs coordonnées, et évite les doublons dans la base de données du club.

Vous pouvez créer un nouveau client de deux façons : depuis **Clients** ou depuis le **Calendrier**, en faisant une réservation. Les deux mènent à la même fiche.

## Depuis Clients

{% stepper %}
{% step %}
### Accès à Clients

* Cliquez sur **Clients** dans le menu de gauche.

<figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le client

* Cliquez sur <i class="fa-plus">:plus:</i>.
* La fiche du client s'ouvre pour remplir ses données.
* Une fois les données remplies, cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

## Depuis le Calendrier

{% stepper %}
{% step %}
### Accès au Calendrier

* Cliquez sur **Calendrier** dans le menu de gauche.
{% endstep %}

{% step %}
### Accès à la réservation

* Cliquez pour créer une nouvelle réservation ou ouvrez une réservation existante. La procédure est la même dans les deux cas.
{% endstep %}

{% step %}
### Créer le client

* Sélectionnez le champ **Client**.
* Cliquez sur **Créer un nouveau**.

<figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>

> Si vous avez déjà des clients créés, l'option **Créer un nouveau** apparaît en bas du menu déroulant avec la liste des clients.
{% endstep %}
{% endstepper %}

## La fiche du client

Les deux options vous amènent à cette fiche :

<figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>

La fiche a beaucoup de champs si vous voulez enregistrer les informations complètes du client, mais ils ne sont pas tous nécessaires.

> **Important :** pour pouvoir enregistrer la fiche, seuls ces champs sont obligatoires :
>
> * **Nom**
> * **Email**
> * **Type de client**
