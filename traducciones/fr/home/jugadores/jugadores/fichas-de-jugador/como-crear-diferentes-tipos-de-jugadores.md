# Comment créer différents types de clients

Les types de client vous permettent de classer vos clients par catégories. Si le club a une nouvelle catégorie de client, vous pouvez l'ajouter au logiciel en quelques étapes.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Types de clients

* Cliquez sur **Clients** dans le menu de gauche.
* Sélectionnez **Types de clients**, juste en dessous.

<figure><img src="../../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>

* Ce bloc affiche tous les types de client déjà créés.
{% endstep %}

{% step %}
### Créer un nouveau type de client

* Cliquez sur <i class="fa-plus">:plus:</i>.
* Écrivez le nom de la nouvelle catégorie.

<div align="left"><figure><img src="../../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure></div>

* Enregistrez avec <i class="fa-floppy-disk">:floppy-disk:</i>.
{% endstep %}
{% endstepper %}

> **Important :** en créant un nouveau type de client, on veut généralement lui appliquer des prix différents, surtout pour les réservations. Pour cela, vous devrez créer des prix personnalisés par type de client. Pour savoir comment, consultez cet article :
