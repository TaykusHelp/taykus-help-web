# Comment retirer du solde d'un bon à un client

L'une des principales utilisations du logiciel sera la gestion des bons des clients. Dans cet article, nous expliquons comment retirer manuellement du solde d'un bon déjà attribué à un client et les étapes à suivre.

### Vidéo explicative

{% embed url="https://youtu.be/9PMRW0Br7v8" %}


{% stepper %}
{% step %}

* Ouvrez le menu latéral gauche.
*   Cliquez sur **Clients**.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
* Cherchez le client dont vous voulez retirer du solde du bon.
* Cliquez sur son id pour ouvrir sa fiche.
{% endstep %}

{% step %}
### Accès au bon du client

*   Dans la fiche du client, ouvrez l'onglet **Bons**.<br>

    <figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
* Dans la section **Bons actifs**, repérez le bon à ajuster.
* Cliquez sur l'id du bon pour ouvrir son détail.
*   Une fois dedans, ouvrez l'onglet **Mouvements**.<br>

    <figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Retirer du solde du bon

*   Dans **Mouvements**, cliquez sur le bouton **+** pour ajouter un nouveau mouvement.<br>

    <figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
* Dans la fenêtre qui s'ouvre :
  * Le champ **Solde** reste vide.
  * Dans le champ **Quantité**, saisissez en **négatif** le montant à déduire du bon.
  * Dans **Observations**, ajoutez une référence pour identifier le motif de l'ajustement.
* Cliquez sur **Sauvegarder**.

> **Important :** pour déduire du solde, la valeur doit être saisie en négatif. Par exemple : `-5`, `-10,50`, etc.
{% endstep %}

{% step %}
### Vérification de l'ajustement

Une fois le mouvement enregistré :

* Vous verrez une nouvelle ligne dans la liste des **Mouvements**.
* Sur cette ligne, vous pourrez vérifier :
  * la **quantité déduite**,
  * la **quantité précédente**,
  * et le **nouveau solde** obtenu.
* Si l'ajustement a été fait correctement, le solde du bon se met à jour automatiquement.

<figure><img src="../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Avec ces étapes, vous pouvez déduire manuellement du solde d'un bon depuis la fiche du client, en gardant à jour son solde et l'historique des mouvements. Cet ajustement vous permet de suivre plus précisément les bons attribués et de consulter facilement toute modification.
