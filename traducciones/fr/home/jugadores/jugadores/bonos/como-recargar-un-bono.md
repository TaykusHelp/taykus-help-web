# Comment recharger un bon

Si le club travaille avec des bons, il est essentiel de savoir comment les recharger. Il y a deux façons de le faire : depuis le point de vente ou depuis la fiche du client. Dans cet article, nous vous expliquons comment le faire depuis **Clients**.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Clients

* Allez dans le menu latéral gauche et sélectionnez **Clients**.
{% endstep %}

{% step %}
### Recherche du client

* Utilisez l'une des colonnes disponibles pour chercher le client par nom, prénom, e-mail, pièce d'identité, etc. et cliquez sur son **ID**.

<figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

* Vous pouvez aussi utiliser la recherche en haut à gauche : écrivez le nom du client et appuyez sur **Entrée**.

<div align="left"><figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Accès à la section des bons

* Dans le profil du client, repérez le bloc **Bons**.

<div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Recharger le bon

* En haut à droite du bloc, sélectionnez **Recharge**.
* Cette option vous amène directement au **point de vente**.
{% endstep %}

{% step %}
### Sélectionner le bon

* Une fenêtre s'ouvre avec tous les bons disponibles.
* Sélectionnez le bon à recharger parmi ceux déjà configurés.

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

* Si vous devez faire une modification spécifique pour ce client, vous pouvez choisir l'option **Personnaliser la recharge**, après avoir sélectionné n'importe quelle recharge de bon déjà créée.
{% endstep %}

{% step %}
### Terminer la recharge

* Encaissez avec le mode de paiement que préfère le client.
* S'il s'agit d'une recharge personnalisée à 0 €, sélectionnez **Confirmer**.
{% endstep %}
{% endstepper %}
