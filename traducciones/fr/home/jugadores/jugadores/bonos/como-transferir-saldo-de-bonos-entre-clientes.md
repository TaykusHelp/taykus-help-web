# Comment transférer du solde de bons entre clients

Une fonction qui peut enrichir l'expérience de l'utilisateur est la possibilité de transférer le solde de ses bons à un autre client de son choix. L'utilisateur ne peut pas faire le transfert lui-même, mais il peut contacter le club pour gérer la demande et s'assurer que tout est correctement enregistré dans le système.

C'est une procédure simple qui se fait en suivant ces étapes :

{% stepper %}
{% step %}
### Accès à Clients

* Allez dans la colonne de gauche et sélectionnez Clients.
{% endstep %}

{% step %}
### Recherche du client

*   Utilisez l'une des colonnes disponibles pour chercher le client par nom, prénom, e-mail, pièce d'identité, etc. et cliquez sur son ID.<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
* Vous pouvez aussi utiliser la recherche en haut à gauche, écrire le nom du client et appuyer sur Entrée.\
  ![](<../../.gitbook/assets/image (7).png>)
{% endstep %}

{% step %}
### Accéder à la section des bons

* Dans le profil du client, repérez le bloc **Facturation.**
*   Dans le menu déroulant, sélectionnez **Bons**.<br>

    <figure><img src="../../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Transfert du solde

* Sélectionnez l'ID du bon à partir duquel vous voulez faire le transfert.
*   En haut à droite, cliquez sur Transférer.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
### Choisir le montant à transférer

* Une fenêtre s'ouvre, à remplir avec ces informations :\
  ![](<../../.gitbook/assets/image (102).png>)
  * **Solde :** saisissez le montant à transférer.
  * **Client :** écrivez le nom du client qui recevra le solde.
* Cliquez sur OK pour faire le transfert.


{% endstep %}
{% endstepper %}
