# Comment modifier un modèle

Vous pouvez modifier n'importe quel modèle d'e-mail, ceux créés par le club comme les modèles automatiques de Taykus (bienvenue, factures, notifications de dette…). Les modifications s'appliquent aux e-mails envoyés à partir de ce moment.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Modèles d'e-mails

* Allez dans le menu latéral gauche et sélectionnez **Communications**.
*   Dans le menu déroulant, choisissez **Modèles d'e-mails**.

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir le modèle

* Cliquez sur l'**ID** du modèle à modifier. Les modèles automatiques ont l'ID **0000**.
* Le modèle s'ouvre, déjà prêt à être modifié.
{% endstep %}

{% step %}
### Modifier le modèle

*   Modifiez ce dont vous avez besoin : le **Sujet**, le **Thème** ou le texte du **Corps du message**.

    <figure><img src="../.gitbook/assets/plantilla-editar.png" alt=""><figcaption></figcaption></figure>
* Pour ajouter une donnée du client, choisissez-la dans **Sélectionnez le remplacement à insérer**.

> **Important :** les mots entre doubles crochets, comme `[[CustomerName]]`, sont remplacés par les données de chaque client à l'envoi de l'e-mail. Si vous les supprimez, cette donnée n'apparaîtra plus.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

Pour créer un nouveau modèle, consultez [Comment créer un modèle](como-crear-una-plantilla.md).
