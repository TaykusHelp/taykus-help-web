# Comment renvoyer un e-mail

Taykus permet de renvoyer n'importe quel e-mail que le système a déjà envoyé à un client (confirmations de réservation, tickets, cotisations…). C'est utile, par exemple, quand le client dit ne pas l'avoir reçu ou l'avoir supprimé.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux e-mails envoyés

* Allez dans le menu latéral gauche et sélectionnez **Communications**.
*   Dans le menu déroulant, choisissez **Emails**. Vous verrez la liste des e-mails envoyés par le système.<br>

    <figure><img src="../.gitbook/assets/reenviar-acceso-emails.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélectionner l'e-mail

* Trouvez l'e-mail à renvoyer. Vous pouvez utiliser les filtres de chaque colonne, par exemple **Acheteur** ou **Sujet**.
* Cochez la case à gauche de l'e-mail. Si vous voulez en renvoyer plusieurs, cochez-les tous.
*   Cliquez sur **Renvoyer**, en haut de la liste.<br>

    <figure><img src="../.gitbook/assets/reenviar-seleccionar-correo.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirmer le renvoi

*   Une fenêtre s'ouvre pour vous demander de confirmer :

    <figure><img src="../.gitbook/assets/reenviar-confirmar.png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **OK** pour le renvoyer, ou sur **Fermer** si vous ne voulez pas le renvoyer.
{% endstep %}

{% step %}
### Vérifier le renvoi

* L'e-mail réapparaît dans la liste avec l'état **Inséré** et **Tentatives** à 0 en attendant de partir.
* Quand il est de nouveau parti, son **Statut d'envoi** passe à **Envoyé**.
{% endstep %}
{% endstepper %}

> **Important :** cet écran ne permet pas de changer l'adresse e-mail. Si le client s'était trompé, corrigez-la d'abord dans sa fiche puis renvoyez l'e-mail : il partira à la nouvelle adresse.

Pour en savoir plus sur les états des e-mails, consultez [Où voir l'état d'envoi des e-mails](donde-ver-el-estado-de-envio-de-los-correos.md).
