# Accès aux paramètres des communications

Depuis la section **Communications**, vous pouvez gérer les paramètres des messages et e-mails envoyés par Taykus.

Dans cet article, nous vous montrons comment accéder à cette section pour revoir ou modifier ses options.

{% stepper %}
{% step %}
### Accès à Communications

* Cliquez sur l'icône ⚙ en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **Communications**<br>

    <figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Une fois ces étapes terminées, vous accéderez à la section **Communications**, d'où vous pourrez consulter et gérer les différentes options de configuration.
