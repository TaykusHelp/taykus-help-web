# Comment configurer le compte e-mail du club

Les e-mails automatiques du club (confirmations, factures, rappels…) sont envoyés depuis le compte e-mail configuré dans Taykus. Ce peut être le compte de Taykus ou un compte propre au club, souscrit auprès d'un fournisseur d'envoi d'e-mails comme Mailjet ou similaire.

Il est conseillé d'utiliser un compte propre : celui de Taykus est partagé par de nombreux clubs et certains fournisseurs, comme Gmail, peuvent envoyer ses e-mails en spam ou les bloquer. Pour en savoir plus, consultez [Utilisation du compte e-mail de Taykus](uso-de-la-cuenta-de-correo-taykus.md).

> **Important :** en général, ce paramétrage est fait par l'équipe de Taykus. Si vous voulez le modifier et avez des doutes, contactez l'assistance.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Communications

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **Communications**. L'onglet **Emails** s'ouvre.

    <figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Modifier le compte

*   Cliquez sur l'icône <i class="fa-pen">:pen:</i>.

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Données du compte

Saisissez les données fournies par votre fournisseur de messagerie :

* **HOST**, **Port**, **Nom d'utilisateur** et **Mot de passe :** les données de connexion au serveur du fournisseur.
* **Ssl** et **Tls :** le type de connexion sécurisée indiqué par le fournisseur.
* **Adresse de l'expéditeur** et **Nom de l'expéditeur :** l'adresse et le nom que verra le client en recevant un e-mail du club. Utilisez des données reconnaissables, par exemple le nom du club et une adresse professionnelle, pour que le client sache que c'est un e-mail officiel.

> **Important :** saisissez les données exactement comme le fournisseur vous les donne. Si l'une d'elles est incorrecte, les e-mails pourraient ne pas être envoyés ou être rejetés.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

À partir de ce moment, Taykus enverra les e-mails automatiques du club depuis ce compte.
