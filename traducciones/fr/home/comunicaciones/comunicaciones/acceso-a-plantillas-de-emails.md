# Accès aux modèles d'e-mails

Dans **Modèles d'e-mails** se trouvent les modèles des e-mails automatiques que Taykus envoie aux clients du club.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux modèles

* Allez dans le menu latéral gauche et sélectionnez **Communications**.
*   Dans le menu déroulant, choisissez **Modèles d'e-mails**.<br>

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Pour savoir ce que contient cet écran, consultez [Modèles d'e-mails](plantillas-de-emails.md).
