# Comment créer un modèle

Les modèles d'e-mails servent à enregistrer les e-mails que vous envoyez souvent, pour ne pas avoir à les réécrire à chaque fois. Quand vous envoyez un e-mail à vos clients, vous choisissez le modèle et l'objet et le texte se remplissent tout seuls.

### Vidéo explicative

{% embed url="https://youtu.be/CQdKu3j7PsA" %}

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Modèles d'e-mails

* Allez dans le menu latéral gauche et sélectionnez **Communications**.
*   Dans le menu déroulant, choisissez **Modèles d'e-mails**.

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le modèle

*   Cliquez sur :heavy\_plus\_sign:. La fenêtre **Ajouter un modèle d'e-mail** s'ouvre.

    <figure><img src="../.gitbook/assets/plantilla-nueva-boton.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sujet et thème

*   Dans le bloc **Général**, remplissez ces champs :

    <figure><img src="../.gitbook/assets/plantilla-nueva-asunto-tema.png" alt=""><figcaption></figcaption></figure>

    * **Sujet :** l'objet de l'e-mail, ce que verra le client en le recevant. Par exemple, _Bienvenue au club_.
    * **Thème :** le nom du modèle. Écrivez-en un qui l'identifie : c'est celui que vous verrez dans la liste en choisissant le modèle pour envoyer un e-mail. Champ obligatoire.
{% endstep %}

{% step %}
### Texte de l'e-mail

* Dans le bloc **Détail**, écrivez le texte dans **Corps du message**. Vous pouvez le mettre en forme avec la barre d'outils (gras, listes, couleurs, images…).
*   Pour ajouter une donnée du client, comme son nom, placez le curseur là où elle doit apparaître et choisissez-la dans le menu déroulant **Sélectionnez le remplacement à insérer**.

    <figure><img src="../.gitbook/assets/plantilla-nueva-reemplazos.png" alt=""><figcaption></figcaption></figure>
* Un mot entre doubles crochets est ajouté, par exemple `[[Customer.Name]]`. À l'envoi de l'e-mail, il est remplacé par la donnée de chaque client.
{% endstep %}

{% step %}
### Enregistrer

*   Cliquez sur **Sauvegarder**. Le modèle apparaîtra dans la liste des **Modèles d'e-mails**.

    <figure><img src="../.gitbook/assets/plantilla-nueva-guardar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

## Utiliser le modèle pour envoyer un e-mail

Les étapes complètes pour envoyer un e-mail à plusieurs clients sont dans [Comment envoyer un e-mail groupé aux clients](../../jugadores/jugadores/como-enviar-un-correo-masivo-a-clientes.md). En résumé :

* Allez dans le menu latéral gauche, sélectionnez **Clients** et cochez les clients à qui envoyer l'e-mail.
* Cliquez sur l'icône de l'enveloppe et choisissez **Email**.
*   Dans **Modèle**, choisissez le modèle par son thème. L'objet et le texte se remplissent tout seuls.

    <figure><img src="../.gitbook/assets/plantilla-usar-al-enviar.png" alt=""><figcaption></figcaption></figure>
* Vérifiez l'e-mail, modifiez ce qui est nécessaire et cliquez sur **OK** pour l'envoyer.

Pour ajouter une image à l'e-mail, consultez [Comment joindre une image à un e-mail](como-adjuntar-una-imagen-a-un-mail.md).
