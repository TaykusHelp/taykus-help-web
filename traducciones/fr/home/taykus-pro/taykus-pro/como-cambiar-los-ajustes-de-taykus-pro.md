# Comment modifier les réglages de Taykus Pro

Dans **Réglages**, vous pouvez choisir d'afficher l'application en mode clair ou sombre, et vérifier si vous avez activé les notifications avec lesquelles le club vous prévient des changements dans vos cours.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accéder aux Réglages

* Cliquez sur ☰ en haut à gauche et sélectionnez **Réglages**.
{% endstep %}

{% step %}
### Choisir l'apparence

*   Dans **Apparence**, choisissez :

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-ajustes.png" alt="" width="300"><figcaption></figcaption></figure></div>

    * **Système :** l'application suit le mode clair ou sombre de votre téléphone.
    * **Clair :** toujours en mode clair.
    * **Sombre :** toujours en mode sombre.
{% endstep %}

{% step %}
### Activer les notifications

* Dans **Notifications**, vous verrez si elles sont activées ou désactivées.
* Pour le changer, cliquez sur **Modifier dans les réglages du système**. Les réglages de votre téléphone s'ouvriront, et vous pourrez les activer pour Taykus Pro.
{% endstep %}
{% endstepper %}

> **Important :** si les notifications sont désactivées, vous ne recevrez pas les alertes du club quand quelque chose change dans vos cours.
