# Comment se connecter à Taykus Pro

Pour vous connecter à Taykus Pro, vous avez besoin de l'utilisateur et du mot de passe que vous utilisez pour le panneau de Taykus. Si vous travaillez dans plusieurs clubs, ajoutez chacun avec ses propres identifiants.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Télécharger l'application

* Téléchargez **Taykus Pro** sur l'[App Store](https://apps.apple.com/es/app/taykus-pro/id6804599678) (iPhone et iPad) ou sur [Google Play](https://play.google.com/store/apps/details?id=com.taykus.coach) (Android).
{% endstep %}

{% step %}
### Saisir les identifiants

* **Club :** le nom de votre club.
* **Utilisateur :** votre e-mail.
* **Mot de passe :** le même que pour le panneau.
*   Cliquez sur **Se connecter**.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-entrar.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Ajouter un autre club

* Dans **Accueil**, cliquez sur **Ajouter un autre club**. Vous pouvez aussi le faire depuis le menu : cliquez sur ☰ en haut à gauche, allez dans **Compte** et cliquez sur **Ajouter un nouveau club**.
* Saisissez les identifiants de ce club et cliquez sur **Se connecter**.
*   Pour retirer un club de l'application, allez dans **Compte** et cliquez sur l'icône de corbeille à côté.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-cuenta.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

> **Important :** si vous ne pouvez pas vous connecter, demandez au club de vérifier que votre utilisateur a bien été créé et que votre rôle a des autorisations dans **Autorisations Taykus Pro**.
