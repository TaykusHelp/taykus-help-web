# Comment utiliser le chat de Taykus Pro

Avec le chat de Taykus Pro, vous pouvez discuter avec d'autres membres de l'équipe qui ont un utilisateur dans Taykus, en tête-à-tête ou en groupe. Pour l'utiliser, votre rôle doit avoir l'autorisation **Voir le chat**.

Pour parler avec les joueurs d'une réservation, utilisez l'option **Chat** de la réservation. Consultez [Comment utiliser le calendrier dans Taykus Pro](como-usar-el-calendario-en-taykus-pro.md).

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accéder au chat

* Cliquez sur ☰ en haut à gauche et sélectionnez **Chat**.
*   Vous verrez vos conversations du club. Cliquez sur un nom pour ouvrir la conversation avec cette personne.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-chat.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer un groupe

* Cliquez sur :heavy_plus_sign: en haut à droite.
* **Nom du chat :** saisissez le nom du groupe. Par exemple, « Groupe profs ».
* Si vous le souhaitez, cliquez sur l'icône d'appareil photo pour ajouter une photo.
* Dans **Inviter**, cochez les personnes à ajouter.
*   Cliquez sur **Créer**. Vous devenez **Propriétaire** du groupe.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-nuevo-chat.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
