# Comment utiliser le calendrier dans Taykus Pro

Dans **Calendrier**, vous voyez les réservations du club jour par jour, terrain par terrain. Si votre rôle le permet, vous pouvez aussi créer, déplacer, prolonger ou annuler des réservations.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accéder au calendrier

* Cliquez sur ☰ en haut à gauche et sélectionnez **Calendrier**.
{% endstep %}

{% step %}
### Choisir le jour et les ressources

* En haut, utilisez les flèches **‹** et **›** pour changer de jour, ou cliquez sur la date pour la choisir.
* En dessous, chaque bouton est un groupe de ressources du club (par exemple, terrains de padel, courts de tennis ou professeurs). Cliquez sur celui que vous voulez voir.
* Faites glisser sur les côtés pour voir les autres terrains.
*   Si vous travaillez dans plusieurs clubs, cliquez sur le nom du club, en haut, pour changer de club.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-calendario.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer une réservation

* Cliquez sur un créneau libre du calendrier.
* En haut, vous verrez le terrain, le jour et l'heure choisis.
*   Recherchez le type de réservation ou filtrez par catégorie, et cliquez sur celui que vous voulez.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-crear-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Remplir la réservation

*   La fenêtre **Nouvelle réservation** s'ouvre :

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-nueva-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>

    * **Heure :** choisissez la durée (par exemple, **60 min**, **90 min** ou **120 min**). À droite, vous verrez l'heure de début et de fin. Pour changer de terrain, cliquez sur **›**.
    * **Titulaire de la réservation :** cliquez sur **Choisir le titulaire** et choisissez le joueur. Le titulaire compte comme l'un des joueurs.
    * **Joueurs :** cliquez sur **Ajouter un joueur** pour ajouter les autres. Entre parenthèses, vous voyez combien il y en a et combien de places il y a.
    * **Notifier les participants :** laissez-le activé si vous voulez prévenir les joueurs.
* Cliquez sur **Réserver**.
{% endstep %}

{% step %}
### Déplacer ou prolonger une réservation

*   Pour la déplacer, maintenez la réservation appuyée et faites-la glisser vers une autre heure ou un autre terrain.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-mover-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
*   Pour la prolonger ou la raccourcir, cliquez sur le bord inférieur de la réservation et faites-le glisser jusqu'à la nouvelle heure de fin. Vous verrez l'heure en bleu pendant que vous la faites glisser.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-alargar-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
* Quand vous relâchez la réservation, une fenêtre s'ouvre pour confirmer le changement.
{% endstep %}

{% step %}
### Voir une réservation

* Cliquez sur une réservation pour l'ouvrir. Vous verrez l'horaire, le type de réservation, le titulaire, les ressources, les participants avec ce que chacun a payé, et le total payé.
* Pour ajouter un joueur, cliquez sur **Ajouter un joueur** sur une place libre. Pour le retirer, cliquez sur le **X** à côté.
*   Dans **Observations internes**, vous pouvez écrire des notes sur la réservation.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-detalle-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Options de la réservation

*   Dans la réservation, cliquez sur **⋯** en haut à droite :

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-opciones-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>

    * **Mettre à jour le prix :** recalcule le prix si quelque chose a changé dans le type de réservation, pour que le changement s'applique.
    * **Valider :** valide le cours. Elle apparaît dans toutes les réservations, mais ne sert que pour les cours.
    * **Partager :** crée un message avec les détails de la réservation et son lien, pour l'envoyer, par exemple, par WhatsApp.
    * **Copier le lien :** copie uniquement le lien de la réservation.
    * **Copier :** copie la réservation pour la répéter un autre jour, sur un autre terrain ou à une autre heure. Ensuite, cliquez sur le créneau où vous voulez la copie.
    * **Déplacer :** une autre façon de la déplacer. Ensuite, cliquez sur la nouvelle heure ou le nouveau terrain.
    * **Résultats :** ajoute les résultats de la réservation.
    * **Chat :** ouvre le chat de la réservation pour parler avec les joueurs. Voir l'étape suivante.
    * **Contacter :** envoie un e-mail aux participants.
    * **Annuler la réservation :** annule la réservation.
{% endstep %}

{% step %}
### Parler avec les joueurs de la réservation

* Dans la réservation, cliquez sur **⋯** puis sur **Chat**.
*   Un message vous indique que vous entrerez dans le chat de la réservation en tant que club et que les joueurs verront vos messages. Cliquez sur **Entrer**.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-entrar-chat-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
*   Écrivez votre message en bas, dans **Écrire un message**.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-chat-reserva.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
