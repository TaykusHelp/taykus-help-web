# Comment voir votre agenda dans Taykus Pro

Dans **Mon agenda**, vous voyez vos cours de tous vos clubs. Vous pouvez les voir sous forme de liste (Agenda) ou de mois complet (Mois).

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accéder à Mon agenda

* Cliquez sur ☰ en haut à gauche et sélectionnez **Mon agenda**.
*   Vous pouvez aussi y accéder depuis **Accueil**, dans **Voir mon agenda**.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-menu.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vue Agenda

* En haut, sélectionnez **Agenda**.
* Vous verrez vos cours classés par jour, avec le nom du cours, l'horaire et le terrain.
*   La coche verte indique que le cours a déjà été validé ; le cercle gris, qu'il ne l'est pas encore.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-agenda.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vue Mois

* Sélectionnez **Mois**.
* Chaque jour indique combien de cours vous avez, avec un point de la couleur du club.
*   Cliquez sur un jour pour voir ses cours.

    <div align="left"><figure><img src="../.gitbook/assets/taykus-pro-mes.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Changer de mois

* Utilisez les flèches **‹** et **›** pour passer au mois précédent ou suivant, ou cliquez sur le mois pour le choisir.
{% endstep %}

{% step %}
### Choisir les clubs à afficher

* Sous **Agenda** et **Mois**, chaque club a son bouton de sa couleur.
* Cliquez sur un club pour le sélectionner ou le retirer. Vous verrez les cours des clubs sélectionnés.
{% endstep %}
{% endstepper %}
