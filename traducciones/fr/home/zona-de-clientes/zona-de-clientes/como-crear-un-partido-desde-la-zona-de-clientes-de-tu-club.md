# Comment créer un match depuis l'espace client de votre club

Depuis l'espace client de votre club, vous pouvez créer un match pour que d'autres joueurs s'y inscrivent et complètent le groupe, sans utiliser l'application.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Réservations

*   Dans le menu en haut du site du club, cliquez sur **Réservations**.

    <figure><img src="../.gitbook/assets/zona-clientes-menu-reservas.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choisir Match

*   Dans **Booking Types**, repérez **Match** et cliquez sur **Réserver**.

    <figure><img src="../.gitbook/assets/zona-clientes-tipos-reserva-partido.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer votre match

* Cliquez sur **Créez votre match**.
*   Choisissez le jour et l'heure.

    <figure><img src="../.gitbook/assets/zona-clientes-crea-tu-partido.png" alt=""><figcaption></figcaption></figure>

> **Important :** si vous ne cliquez pas sur **Créez votre match** et changez de jour, vous verrez les matchs déjà créés, auxquels vous pouvez vous inscrire.
{% endstep %}

{% step %}
### Données du match

<figure><img src="../.gitbook/assets/zona-clientes-crear-partido-ventana.png" alt=""><figcaption></figcaption></figure>

* **Genre :** **Ouvert**, **Mixte** et celui de votre genre (**Homme** ou **Femme**) apparaissent.
* **Type de match :** **Compétitif** (le résultat change votre niveau) ou **Amical** (il ne le change pas).
* **Niveau :** la barre apparaît avec une plage autour de votre niveau. Déplacez les deux points pour choisir le niveau minimum et maximum des joueurs qui peuvent s'inscrire.
* Cliquez sur **Créer un match**.
{% endstep %}

{% step %}
### Payer votre place

* Le résumé du match s'ouvre, avec les **Détails de la réservation** et les **Joueurs**.
* Dans **Paiement partagé**, vous verrez ce que vous payez : seulement votre part.
*   Cliquez sur **Ajouter au panier** et terminez le paiement.

    <figure><img src="../.gitbook/assets/zona-clientes-partido-pago.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Pour en savoir plus sur chaque option, consultez [Types de match : compétitif, amical et genre](https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/calendario/partidos/tipos-de-partido).
