# Comment recevoir un e-mail quand quelqu'un réserve ou annule

Si vous voulez que le club reçoive un e-mail chaque fois qu'un terrain est réservé ou annulé, vous devez écrire cette adresse dans le champ **E-mail de notification de réservation** du terrain. L'avis arrive pour toute réservation : celles faites par le club et celles faites par les clients depuis le site ou l'application.

> **Important :** l'adresse se saisit terrain par terrain, et chaque terrain n'accepte qu'une seule adresse. Pour recevoir les avis de tous les terrains, vous devrez la saisir sur chacun.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Groupe de ressources

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <figure><img src="../../../.gitbook/assets/aviso-reservas-configuracion.png" alt=""><figcaption></figcaption></figure>
*   Le bloc **Groupes de ressources** s'ouvre directement. Cliquez sur l'**ID** du sport (par exemple, Padel).

    <figure><img src="../../../.gitbook/assets/aviso-reservas-grupos-de-recursos.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir la liste des terrains

*   Ouvrez l'onglet **Ressources**. Vous verrez tous les terrains de ce sport.

    <figure><img src="../../../.gitbook/assets/aviso-reservas-recursos.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ajouter l'adresse

Vous pouvez le faire de deux façons :

**Depuis la liste (la plus rapide)**

* Faites défiler vers la droite jusqu'à la colonne **E-mail de notification de réservation**.
*   Cliquez sur la case du terrain, écrivez l'adresse et appuyez sur **Entrée** pour l'enregistrer.

    <figure><img src="../../../.gitbook/assets/aviso-reservas-columna-email.png" alt=""><figcaption></figcaption></figure>

**Depuis la fiche de chaque terrain**

* Cliquez sur l'**ID** du terrain.
* Faites défiler vers le bas jusqu'au champ **E-mail de notification de réservation** et écrivez l'adresse.
*   Cliquez sur **Sauvegarder**.

    <figure><img src="../../../.gitbook/assets/aviso-reservas-ficha-pista.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

À partir de ce moment, vous recevrez un e-mail chaque fois qu'une réservation est faite ou annulée sur ce terrain.

> Les professeurs peuvent aussi recevoir un avis de leurs réservations sur leur propre adresse. Pour savoir comment, consultez cet article :
