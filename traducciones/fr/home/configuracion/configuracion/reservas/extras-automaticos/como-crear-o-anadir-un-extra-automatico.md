# Comment créer ou ajouter un supplément automatique

Un **supplément automatique** s'ajoute tout seul au prix de la réservation dans certaines conditions. Par exemple, facturer l'éclairage à part à partir d'une certaine heure ou à certaines dates.

> **Avant de commencer :** le supplément doit exister comme produit de type Service. Si vous ne l'avez pas encore créé, consultez cet article :
>
> <a href="../../ventas/productos/como-crear-un-producto-tipo-servicio.md" class="button primary">Comment créer un produit de type Service</a>

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Suppléments de réservation

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Suppléments de réservation**.<br>

    <figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le supplément

* Cliquez sur :heavy\_plus\_sign:.
*   Cette fenêtre s'ouvre :

    <figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

    * **Produit :** cherchez le produit à ajouter comme supplément.
    * **Type de réservation :** le type de réservation auquel il s'applique. Pour l'appliquer à plusieurs types, créez un supplément pour chacun.
    * **Ressource :** les terrains auxquels il s'ajoute. Si vous le laissez vide, il s'applique à tous.
    * **Type de client :** s'il n'est facturé qu'à un type de client (par exemple, membre ou non-membre).
    * **Acheteur :** s'il n'est facturé qu'à une personne. S'il y en a plusieurs, créez un supplément pour chacune.
    * **Date de début :** à partir de quelle date il s'ajoute.
    * **Date de fin :** jusqu'à quelle date. Facultative.
    * **Heure de début :** à partir de quelle heure il s'ajoute.
    * **Heure de fin :** jusqu'à quelle heure. Facultative.
    * **Récurrence annuelle :** cochez-la s'il se répète chaque année.
    * **Jours de la semaine :** les jours où il s'ajoute.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

> **Important :** de même que, pour les produits, on en crée un pour les réservations et un autre pour les matchs, ici aussi vous devez créer un supplément pour chacun. Créez d'abord les deux produits, puis les deux suppléments.
