# Comment créer ou indiquer un motif d'annulation

Quand une réservation est annulée, il y a généralement un motif : la pluie, une blessure, un changement de programme… Si vous enregistrez ces motifs, le club peut voir pourquoi on annule et améliorer la gestion des horaires, des terrains et de la communication avec les clients.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Motifs d'annulation

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fo7gBVkwfX7ziYiTLefsN%252Fimage.png%3Falt%3Dmedia%26token%3D9f9d15bf-ab2d-44e1-b2e8-fd7276f24e60&#x26;width=300&#x26;dpr=4&#x26;quality=100&#x26;sign=3f7de3b8&#x26;sv=2" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Motifs d'annulation**.<br>

    <figure><img src="../../../.gitbook/assets/image (120).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer les motifs

* Cliquez sur :heavy\_plus\_sign:.
*   Écrivez le nom du motif. Par exemple : _pluie_, _maladie_, _entretien du terrain_, _oubli_…<br>

    <figure><img src="../../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Sauvegarder**.
* Répétez la procédure pour créer tous les motifs nécessaires.
{% endstep %}
{% endstepper %}

## Indiquer le motif lors de l'annulation d'une réservation

Quand vous annulez une réservation, cet écran apparaît :

<div align="left"><figure><img src="../../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>

Dans le menu déroulant, vous pouvez choisir l'un des motifs créés. Ce n'est pas obligatoire.

## Voir la liste des annulations avec leur motif

* Cliquez sur **Calendrier** puis, dans le menu déroulant, sélectionnez **Réservations**.  ![](<../../../.gitbook/assets/image (30).png>)
* Cliquez sur **colonnes** et sélectionnez **Motifs d'annulation** pour ajouter cette colonne à la liste.  ![](<../../../.gitbook/assets/image (31).png>)
*   Filtrez par l'état **Annulée**. Vous verrez la liste ainsi :<br>

    <figure><img src="../../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>
* Vous pouvez télécharger la liste et l'exporter vers Excel.
