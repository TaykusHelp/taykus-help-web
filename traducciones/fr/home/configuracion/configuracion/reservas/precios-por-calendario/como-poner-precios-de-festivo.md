# Comment définir les prix des jours fériés

Vous pouvez facturer un prix différent les jours fériés, par exemple s'il y a plus de demande ces jours-là. Les prix des autres jours ne changent pas.

> **Important :** ici, on ne change que les **prix**. L'ouverture et la disponibilité des terrains ne changent pas. Pour cela, consultez cet article :
>
> <a href="../horarios/como-poner-horario-de-festivo.md" class="button primary">Comment définir l'horaire des jours fériés</a>

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Tarifs par calendrier

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Tarifs par calendrier**.<br>

    <figure><img src="../../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le calendrier de prix des jours fériés

Passez cette étape si vous en avez déjà un pour les jours fériés, ou si le jour férié utilisera des prix existants (par exemple, ceux du week-end).

* Cliquez sur :heavy\_plus\_sign:.
*   Cette fenêtre s'ouvre :

    <div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

    * **Nom :** _Férié_.
    * **Priorité :** elle doit être supérieure à celle des autres. Nous vous conseillons _100_.
    * Ne remplissez rien d'autre et cliquez sur **Sauvegarder**.
{% endstep %}

{% step %}
### Ajouter les jours fériés

Ajoutez les jours fériés au calendrier de prix qu'ils doivent utiliser : celui des jours fériés ou un existant, comme celui du week-end.

* Cliquez sur l'**ID** du calendrier de prix.
*   Allez dans le bloc **Exceptions**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>
* Cliquez sur <i class="fa-plus" style="color:purple;">:plus:</i>.
*   Cette fenêtre s'ouvre :

    <div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

    * **jour :** la date du jour férié.
    * **Tous les ans :** cochez-la si le jour férié se répète chaque année à la même date.
    * **Type d'exception :** laissez _Inclure la date_, qui est la valeur par défaut.
* Cliquez sur <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> pour enregistrer.
{% endstep %}
{% endstepper %}
