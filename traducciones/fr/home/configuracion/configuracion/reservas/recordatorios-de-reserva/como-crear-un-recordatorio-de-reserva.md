# Comment créer un rappel de réservation

Les clients reçoivent déjà un e-mail quand ils font, annulent ou modifient une réservation. Il est pourtant facile d'oublier une réservation ou un match. Pour l'éviter, Taykus peut envoyer un **e-mail de rappel** un peu avant.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux rappels de réservation

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fo7gBVkwfX7ziYiTLefsN%252Fimage.png%3Falt%3Dmedia%26token%3D9f9d15bf-ab2d-44e1-b2e8-fd7276f24e60&#x26;width=300&#x26;dpr=4&#x26;quality=100&#x26;sign=3f7de3b8&#x26;sv=2" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Rappelderéservation**.<br>

    <figure><img src="../../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le rappel

* Cliquez sur :heavy\_plus\_sign:.
*   Cette fenêtre s'ouvre :<br>

    <figure><img src="../../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>

    * **Anticipation en minutes :** combien de minutes à l'avance le client est prévenu.
    * **Groupe de ressources :** le sport ou les professeurs auxquels il s'applique. Si vous le laissez vide, il s'applique à tous.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}
