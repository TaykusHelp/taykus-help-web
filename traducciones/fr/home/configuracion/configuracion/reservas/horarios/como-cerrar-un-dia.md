# Comment fermer un jour

Vous pouvez fermer le club une journée entière pour qu'aucune réservation ne soit possible sur aucun terrain. C'est utile les jours fériés, pour des événements internes ou pour toute autre raison.

Pour cela, on utilise un horaire appelé **Fermé**, avec une priorité plus élevée que les autres, auquel on ajoute les dates de fermeture.

> Si vous voulez fermer seulement **un terrain** un jour précis, vous pouvez le faire directement depuis le calendrier. Pour savoir comment, consultez cet article :
>
> <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/calendario/como-cerrar-una-pista" class="button primary">Comment fermer un terrain</a>

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux horaires

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Horaires**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (59).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer l'horaire Fermé

Si vous avez déjà un horaire **Fermé**, passez cette étape.

* Cliquez sur :heavy\_plus\_sign:.
* Cette fenêtre s'ouvre :

<div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

* **Nom :** _Fermé_.
* **Priorité :** elle doit être supérieure à celle des autres horaires. Nous vous conseillons _100_.
* Ne remplissez rien d'autre et cliquez sur **Sauvegarder**.
{% endstep %}

{% step %}
### Ajouter les dates de fermeture

* Cliquez sur l'**ID** de l'horaire **Fermé**.
* Allez dans le bloc **Exceptions**.

<div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>

* Cliquez sur <i class="fa-plus" style="color:purple;">:plus:</i>.
* Cette fenêtre s'ouvre :

<div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

* **jour :** la date de fermeture du club.
* **Tous les ans :** cochez-la seulement si le club ferme à cette date chaque année.
* **Type d'exception :** laissez _Inclure la date_, qui est la valeur par défaut.
* Cliquez sur <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> pour enregistrer.
{% endstep %}
{% endstepper %}

Si vous voulez fermer plusieurs jours de suite, ne mettez pas de dates de début et de fin sur cet horaire : créez-en un à part. Pour savoir comment, consultez cet article :

<a href="como-cerrar-el-club-entre-dos-fechas.md" class="button primary">Comment fermer le club entre deux dates</a>
