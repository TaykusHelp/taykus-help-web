# Comment définir l'horaire des jours fériés

Vous pouvez donner aux jours fériés un horaire différent de l'habituel : une autre heure d'ouverture, d'autres tranches de réservation ou une autre activité de l'académie. La planification des autres jours ne change pas.

> **Important :** ici, on ne change que l'**horaire**. Si les jours fériés ont un autre **prix**, configurez-le à part :
>
> <a href="../precios-por-calendario/como-poner-precios-de-festivo.md" class="button primary">Comment définir les prix des jours fériés</a>

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux horaires

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Horaires**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (57).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer l'horaire des jours fériés

Passez cette étape si vous avez déjà un horaire de jours fériés, ou si le jour férié utilisera un horaire existant (par exemple, celui du week-end).

* Cliquez sur :heavy\_plus\_sign:.
*   Cette fenêtre s'ouvre :

    <div align="left"><figure><img src="../../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure></div>

    * **Nom :** _Férié_.
    * **Priorité :** elle doit être supérieure à celle des autres horaires. Nous vous conseillons _100_.
    * Ne remplissez rien d'autre et cliquez sur **Sauvegarder**.
{% endstep %}

{% step %}
### Ajouter les jours fériés

Ajoutez les jours fériés à l'horaire qu'ils doivent utiliser : celui des jours fériés que vous venez de créer ou un horaire existant, comme celui du week-end.

* Cliquez sur l'**ID** de l'horaire.
*   Allez dans le bloc **Exceptions**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure></div>
* Cliquez sur <i class="fa-plus" style="color:purple;">:plus:</i>.
*   Cette fenêtre s'ouvre :

    <div align="left"><figure><img src="../../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure></div>

    * **jour :** la date du jour férié.
    * **Tous les ans :** cochez-la si le jour férié se répète chaque année à la même date.
    * **Type d'exception :** laissez _Inclure la date_, qui est la valeur par défaut.
* Cliquez sur <i class="fa-floppy-disk" style="color:green;">:floppy-disk:</i> pour enregistrer.
{% endstep %}
{% endstepper %}
