# Comment modifier un horaire par jours

Vous pouvez changer les jours de la semaine auxquels s'applique un horaire sans toucher au reste de sa configuration. C'est utile pour des changements ponctuels, des événements ou des besoins du club.

### Vidéo explicative

{% embed url="https://youtu.be/zTc6DgS2DAo" %}

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux horaires

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **réservations**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure></div>
*   Cliquez sur le bloc **Horaires**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Modifier les jours de l'horaire

*   Cliquez sur l'**ID** de l'horaire à modifier.

    <figure><img src="../../../.gitbook/assets/image (121).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur le bouton de modification <i class="fa-pencil" style="color:blue;">:pencil:</i>.
* Changez le nom de l'horaire pour qu'il indique les jours auxquels il s'applique. Vous éviterez ainsi les confusions.
*   Cochez ou décochez les jours de la semaine.<br>

    <figure><img src="../../../.gitbook/assets/image (122).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Sauvegarder**.
{% endstep %}

{% step %}
### Vérifier les changements

* Allez dans le calendrier et vérifiez que l'horaire s'applique les bons jours.
{% endstep %}
{% endstepper %}

> Vous pouvez créer autant d'horaires que nécessaire, même un différent pour chaque jour de la semaine.
