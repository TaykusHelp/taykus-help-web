# Comment donner des autorisations dans Taykus Pro

Dans **Autorisations Taykus Pro**, vous décidez ce que chaque rôle du club peut voir et faire dans l'application Taykus Pro. Les rôles sont les mêmes que dans **Paramètres › Rôles**.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accéder à Autorisations Taykus Pro

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et allez dans **Paramètres**.
*   Cliquez sur **Autorisations Taykus Pro**.

    <figure><img src="../../.gitbook/assets/permisos-taykus-pro-acceso.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Cocher les autorisations de chaque rôle

* Chaque ligne est une fonctionnalité de l'application et chaque colonne, un rôle du club.
*   Cochez la case du rôle pour chaque fonctionnalité que vous voulez lui donner :

    <figure><img src="../../.gitbook/assets/permisos-taykus-pro.png" alt=""><figcaption></figcaption></figure>

    * **Agenda des professeurs :** **Voir l'agenda des professeurs** (chacun voit son propre agenda de cours), **Valider le cours**, **Faire l'appel**, **Envoyer des communications** et **Ajouter des commentaires**.
    * **Calendrier :** **Voir le calendrier** et **Créer / Modifier / Annuler des réservations**.
    * **Chat :** **Voir le chat**.
* La case de la ligne de chaque bloc (par exemple, **Calendrier**) coche tout le bloc pour ce rôle.
* La case à gauche de chaque fonctionnalité (colonne **Tous les rôles**) la coche pour tous les rôles.
* Ce qu'un rôle n'a pas le droit de faire n'apparaît pas dans le menu de l'application.

> **Important :** pour donner une autorisation comme **Valider le cours** ou **Créer / Modifier / Annuler des réservations**, cochez d'abord l'autorisation de voir de son bloc. Jusque-là, sa case reste grisée.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Enregistrer les modifications**.
{% endstep %}
{% endstepper %}
