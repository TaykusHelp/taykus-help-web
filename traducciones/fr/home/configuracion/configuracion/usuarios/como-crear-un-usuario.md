# Comment créer un utilisateur

Chaque personne du club qui va utiliser Taykus a besoin de son propre utilisateur, avec son e-mail et son mot de passe. Le rôle de l'utilisateur détermine ce qu'il peut voir et faire dans le logiciel.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Utilisateurs

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite.
*   Dans le menu déroulant, cliquez sur **Utilisateurs**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer l'utilisateur

* Cliquez sur :heavy\_plus\_sign:.
*   Ce formulaire s'ouvre :<br>

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

    * **Nom :** le nom de l'utilisateur.
    * **Logo :** facultatif. Une photo de l'utilisateur.
    * **Email :** l'adresse avec laquelle il se connectera à Taykus.
    * **Mot de passe :** son mot de passe d'accès.
    * **Langue préférée :** la langue dans laquelle il verra le logiciel.
    * **Rôle :** les autorisations qu'il aura. Pour savoir comment créer ou modifier un rôle, consultez cet article :

      <a href="../roles/como-crear-editar-o-borra-un-rol.md" class="button primary">Comment créer, modifier ou supprimer un rôle</a>
    * **Page d'accueil :** l'écran qu'il verra en entrant dans le logiciel.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}
