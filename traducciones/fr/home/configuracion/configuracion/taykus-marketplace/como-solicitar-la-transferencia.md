# Comment demander le virement ?

Les paiements en ligne que le club reçoit via Taykus ne sont pas virés automatiquement : c'est vous qui demandez le virement quand vous en avez besoin. Vous gardez ainsi plus de contrôle pour vérifier et rapprocher les paiements.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux paiements

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
*   Cliquez sur **Place du marché Taykus**.<br>

    <figure><img src="../../.gitbook/assets/image (75).png" alt=""><figcaption></figcaption></figure>
*   Ouvrez l'onglet **Paiements**.<br>

    <figure><img src="../../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Demander le virement

* Allez dans le bloc **Confirmé**.
* Cliquez sur **Vente** pour sélectionner toutes les lignes de paiement.
*   Cliquez sur <mark style="color:orange;">**Demande remise**</mark>.<br>

    <figure><img src="../../.gitbook/assets/image (79).png" alt=""><figcaption></figcaption></figure>
* Ce message de confirmation apparaît :

<figure><img src="../../.gitbook/assets/image (84).png" alt=""><figcaption></figcaption></figure>

> Le virement arrive généralement sur votre compte en **deux jours ouvrés** environ.
{% endstep %}
{% endstepper %}

## Les onglets de Paiements

Dans **Paiements**, il y a quatre onglets :

<div align="left"><figure><img src="../../.gitbook/assets/image (81).png" alt=""><figcaption></figcaption></figure></div>

* **Confirmé :** paiements de réservations déjà jouées que vous pouvez demander.
* **Non confirmé :** paiements de réservations qui peuvent encore être annulées ou qui n'ont pas encore été jouées.
* **Déjà remis :** paiements déjà virés.
* **Incomplet :** virements qui n'ont pas pu être faits parce qu'il manque des données.
