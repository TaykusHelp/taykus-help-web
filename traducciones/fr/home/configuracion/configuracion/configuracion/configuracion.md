# Paramètres

Dans le menu des paramètres, la section **Paramètres** contient les données de base du club. C'est aussi ici que l'on importe la base de données.

<figure><img src="../../.gitbook/assets/image (54).png" alt=""><figcaption></figcaption></figure>

Voici les étapes pour modifier les données du club :

{% stepper %}
{% step %}
### Accès au menu des paramètres

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite.
* Un menu déroulant s'ouvre.
* Cliquez de nouveau sur **Paramètres**.
{% endstep %}

{% step %}
### Accès aux données du club

* Dans le menu des paramètres, cliquez sur **Paramètres**.
* Vous verrez un onglet avec les données du club.
* Cliquez sur l'**ID** pour les ouvrir.
{% endstep %}

{% step %}
### Modifier et enregistrer

*   Cliquez sur l'icône du crayon <i class="fa-pen" style="color:blue;">:pen:</i> pour modifier.<br>

    <figure><img src="../../.gitbook/assets/image (55).png" alt=""><figcaption></figcaption></figure>
* Faites les modifications nécessaires.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}
