# Comment accéder au menu des paramètres

Le menu des paramètres est disponible depuis n'importe quel écran de Taykus. Il permet de régler les données du club, les réservations, les ventes, les utilisateurs et les autres options du système.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir le menu déroulant

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite.
* Un menu déroulant s'ouvre.
{% endstep %}

{% step %}
### Ouvrir Paramètres

* Cliquez de nouveau sur **Paramètres** <i class="fa-gear" style="color:blue;">:gear:</i>.

<figure><img src="../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

* Le menu des paramètres s'ouvre :

<figure><img src="../../.gitbook/assets/image (88).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
