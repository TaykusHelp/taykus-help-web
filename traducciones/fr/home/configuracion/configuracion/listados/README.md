# Listes

Presque tous les écrans du panneau Taykus sont des listes : clients, ventes, paiements, dettes, modèles… Elles fonctionnent toutes de la même façon : ce que vous apprenez sur l'une vous sert pour les autres.

Dans n'importe quelle liste, vous pouvez :

* [Filtrer entre deux dates](como-filtrar-entre-dos-fechas.md).
* [Déplacer des colonnes](como-mover-columnas.md).
* [Masquer ou afficher des colonnes](como-ocultar-o-mostrar-columnas.md).
* [Enregistrer une liste en favori](como-guardar-un-listado-como-favorito.md), avec ses filtres et ses colonnes.
* [Exporter une liste](como-exportar-un-listado.md).
