# Comment enregistrer une liste en favori

Si vous consultez souvent une liste avec les mêmes filtres et colonnes, enregistrez-la en favori. Dans le panneau, cela s'appelle **Liste personnalisée** et tout est enregistré : les filtres, les colonnes visibles et leur ordre.

> **Important :** les listes personnalisées peuvent être ouvertes par n'importe quel utilisateur du club, pas seulement par celui qui les crée.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Préparer la liste

* Appliquez les filtres et disposez les colonnes comme vous le souhaitez. Consultez [Comment filtrer entre deux dates](como-filtrar-entre-dos-fechas.md), [Comment déplacer des colonnes](como-mover-columnas.md) et [Comment masquer ou afficher des colonnes](como-ocultar-o-mostrar-columnas.md).
{% endstep %}

{% step %}
### Enregistrer la liste

*   Cliquez sur l'icône de l'étoile, au-dessus de la liste, puis sur **Sauvegarder**.

    <figure><img src="../../.gitbook/assets/listados-favorito-menu.png" alt=""><figcaption></figcaption></figure>
*   Écrivez un nom dans **Nom de la liste personnalisée** et cliquez sur **OK**.

    <figure><img src="../../.gitbook/assets/listados-favorito-guardar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir une liste enregistrée

*   Cliquez sur l'icône de l'étoile. Les listes enregistrées apparaissent sous **Liste personnalisée**.
*   Cliquez sur le nom de la liste pour l'ouvrir.

    <figure><img src="../../.gitbook/assets/listados-favorito-abrir.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Pour supprimer une liste enregistrée, cliquez sur la **X** à côté de son nom.

> **Important :** n'importe quel utilisateur du club peut supprimer une liste enregistrée, pas seulement celui qui l'a créée.
