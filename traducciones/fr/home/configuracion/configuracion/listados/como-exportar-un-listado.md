# Comment exporter une liste

Vous pouvez télécharger n'importe quelle liste pour la travailler en dehors de Taykus ou la conserver. Ce que vous voyez à ce moment-là est exporté : les enregistrements qui correspondent à vos filtres et les colonnes visibles.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Filtrer la liste

* Appliquez les filtres et laissez visibles les colonnes à exporter. Consultez [Comment masquer ou afficher des colonnes](como-ocultar-o-mostrar-columnas.md).
{% endstep %}

{% step %}
### Exporter

* Cliquez sur l'icône de la flèche de téléchargement, au-dessus de la liste.
*   Dans **Télécharger**, choisissez le format : **Excel** ou **CSV**. Le fichier est téléchargé sur votre ordinateur.

    <figure><img src="../../.gitbook/assets/listados-exportar.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
