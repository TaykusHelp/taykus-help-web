# Comment modifier les données d'une société cliente

Si les données d'une société cliente changent (adresse, CIF, contact…), vous pouvez les mettre à jour à tout moment. Les nouvelles données seront utilisées dans les prochaines factures.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux sociétés clientes <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Sociétés clientes**.<br>

    <figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Modifier les données

* Cliquez sur l'**ID** de la société cliente.
*   Sélectionnez <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Modifiez les données nécessaires.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}
