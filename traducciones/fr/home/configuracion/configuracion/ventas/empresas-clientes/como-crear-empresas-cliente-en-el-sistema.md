# Comment créer des sociétés clientes dans le système

Si certains de vos clients sont des entreprises, vous pouvez enregistrer leurs données dans le système. Vous pourrez ainsi les utiliser dans les factures, réservations et démarches sans avoir à les saisir à chaque fois, et éviter les erreurs dans les documents.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux sociétés clientes <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Sociétés clientes**.<br>

    <figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer la société cliente

* Cliquez sur :heavy\_plus\_sign:.
*   Cette fenêtre s'ouvre. Remplissez-la avec les données fournies par le client.

    <figure><img src="../../../.gitbook/assets/image (115).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

La société cliente est enregistrée et vous pourrez la choisir dans les prochaines factures et démarches.
