# Comment créer ou modifier une marque

Les marques sont des étiquettes que vous mettez sur les produits pour les regrouper et les filtrer ensuite, par exemple dans les rapports de ventes. On utilise en général le nom du fabricant (Nike, Head…), mais vous pouvez les appeler comme vous voulez.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux marques

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Marques de produits**.<br>

    <figure><img src="../../.gitbook/assets/image (95).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer une marque

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre. Écrivez le nom de la marque.

    <div align="left"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

## Modifier une marque

* Cliquez sur l'**ID** de la marque à modifier.
* Cliquez sur l'icône de modification <i class="fa-pen" style="color:green;">:pen:</i>.
* Faites les modifications.
* Cliquez sur **Sauvegarder**.
