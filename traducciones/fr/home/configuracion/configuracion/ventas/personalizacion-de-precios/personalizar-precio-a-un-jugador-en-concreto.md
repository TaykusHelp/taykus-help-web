# Personnaliser le prix pour un client précis

Si le club offre des conditions spéciales à certains clients ou entreprises, vous pouvez leur fixer un prix propre sur n'importe quel produit (réservations, cotisations, articles…). Vous n'aurez ainsi pas à changer le prix à la main à chaque encaissement.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux produits

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**. L'onglet **Produits** s'ouvre directement.
{% endstep %}

{% step %}
### Ouvrir le produit

* Cherchez dans la liste le produit auquel appliquer le prix spécial.

> **Important :** choisissez bien le produit. Pour les réservations, il y a généralement un service par tranche horaire (heure de pointe, heure creuse…) : assurez-vous d'ouvrir exactement le service et la tranche auxquels appliquer le prix.

*   Cliquez sur son **ID**. L'onglet **Général** du produit s'ouvre.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure></div>
*   Ouvrez l'onglet **Prix spéciaux**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Créer le prix spécial

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre, dans laquelle il suffit de remplir ces champs :<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure></div>

    * **Clients :** écrivez le nom du client ou de l'entreprise.
    * **Prix brut :** le nouveau prix, en chiffres. Si vous voulez qu'il soit gratuit, mettez 0.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

> Si le prix spécial doit s'appliquer à plusieurs tranches ou à plusieurs produits, répétez la procédure pour chacun. Ainsi, le prix ne s'applique que là où il faut.
