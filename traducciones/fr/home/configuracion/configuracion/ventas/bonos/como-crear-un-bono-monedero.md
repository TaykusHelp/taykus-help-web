# Comment créer un bon monétaire

Le **bon monétaire** charge un solde sur le compte du client, à dépenser en réservations, produits ou services du club. Le solde est déduit automatiquement à chaque achat ou réservation.


Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux bons

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Bons**.<br>

    <figure><img src="../../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer le bon

* Cliquez sur :heavy\_plus\_sign:.
* La fiche du bon s'ouvre :

{% step %}
### Données générales

* **Logo :** image pour reconnaître le bon dans le système et dans la vente en ligne.
* **Nom :** le nom que verront les clients et le personnel du club. Utilisez un nom clair, par exemple : _Porte-monnaie Club_ ou _Bon Solde 50 €_.
* **Prix brut :** prix final du bon, taxes comprises. C'est ce que paie le client.
* **Prix net :** prix hors taxes. Il est calculé automatiquement selon le type de taxe.
* **Type de taxe :** la taxe qui s'applique à la vente du bon.
* **Détail :** texte facultatif pour expliquer les conditions du bon.
{% endstep %}

{% step %}
### Où il est vendu

* **Vente en ligne :** cochez-la pour que le bon puisse être acheté sur le site du club.
* **Tendance :** met en avant le bon dans la vente en ligne comme option recommandée.
* **Populaire :** marque le bon comme option populaire.
* **Vente au point de vente :** cochez-la pour pouvoir le vendre depuis le point de vente.
* **Accès rapide au point de vente :** le bon apparaît dans les accès rapides du point de vente.
{% endstep %}

{% step %}
### Type et quantité

* **Type de bon :** sélectionnez **Bon monétaire**, qui fonctionne comme un porte-monnaie avec un solde.
* **Description :** texte interne facultatif.
* **Type de montant :** sélectionnez **Argent**.
* **Montant à remplir :** le solde chargé sur le bon quand vous le vendez ou l'attribuez.
{% endstep %}

{% step %}
### Validité

* **Jours avant expiration :** nombre de jours avant l'expiration du bon, à compter de l'achat ou de l'activation.
* **Jours de validité d'utilisation :** nombre de jours pendant lesquels le bon peut être utilisé une fois activé.
* **Date de début de validité :** date à partir de laquelle le bon peut être utilisé.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

> **Important :** pour pouvoir enregistrer le bon, ces champs sont obligatoires : **Nom**, **Prix brut**, **Type de taxe**, **Type de bon**, **Type de montant** et **Montant à remplir**.

Une fois enregistré, le bon peut être vendu ou attribué aux clients depuis le point de vente ou depuis leur fiche, et le solde sera déduit à chaque achat ou réservation.
