# Comment créer ou modifier une taxe

Les taxes (TVA) s'appliquent à chaque produit pour calculer son prix net. Les configurer correctement est nécessaire pour que les prix, les factures et les rapports soient justes.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux taxes

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Taxes**.

    <figure><img src="../../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer une taxe

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre :<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (50).png" alt=""><figcaption></figcaption></figure></div>

    * **Nom :** le nom de la taxe. Nous vous conseillons d'utiliser le pourcentage lui-même, par exemple _21 %_ ou _TVA 21 %_.
    * **Pourcentage :** le pourcentage de la taxe.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

## Modifier une taxe

* Cliquez sur l'**ID** de la taxe à modifier.
*   Cliquez sur l'icône de modification <i class="fa-pen" style="color:green;">:pen:</i>.<br>

    <figure><img src="../../.gitbook/assets/image (48).png" alt=""><figcaption></figcaption></figure>
* Faites les modifications.
* Cliquez sur **Sauvegarder**.
