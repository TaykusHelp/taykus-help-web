# Comment créer un type de produit

Les types de produits servent à regrouper les produits du club par familles. Il est ainsi plus facile de les trouver puis de les analyser dans les rapports de ventes et les statistiques.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux types de produits

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Types de produits**.<br>

    <figure><img src="../../.gitbook/assets/image (93).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer un type de produit

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre. Écrivez le nom de la nouvelle famille ou sous-famille.

    <div align="left"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

## Modifier un type de produit <a href="#modificar-un-tipo-de-producto" id="modificar-un-tipo-de-producto"></a>

* Cliquez sur l'**ID** du type de produit à modifier.
* Cliquez sur l'icône de modification <i class="fa-pen" style="color:green;">:pen:</i>.
* Faites les modifications.
* Cliquez sur **Sauvegarder**.
