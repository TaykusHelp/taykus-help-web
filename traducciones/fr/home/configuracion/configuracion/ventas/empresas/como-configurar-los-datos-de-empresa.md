# Comment configurer les données de l'entreprise

C'est ici que sont enregistrées les données fiscales du club. Elles sont utilisées automatiquement dans l'autofacture générée quand le club demande un virement, et apparaissent dans tous les documents comptables émis par le système.

On ne peut enregistrer **qu'une seule entreprise ou raison sociale**. En général, ces données sont configurées au démarrage avec Taykus, mais vous pouvez les vérifier et les modifier quand vous le souhaitez.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux entreprises

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Entreprises**.<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer les données de l'entreprise

*   Cliquez sur :heavy\_plus\_sign:.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Remplissez les données fiscales de l'entreprise. Le seul champ obligatoire est l'**Email**.

> **Important :** <mark style="background-color:$danger;">ne modifiez pas le champ **Invoice Number Format**.</mark>
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
* Désormais, ces données apparaîtront sur chaque autofacture générée lors d'une demande de virement.
{% endstep %}
{% endstepper %}
