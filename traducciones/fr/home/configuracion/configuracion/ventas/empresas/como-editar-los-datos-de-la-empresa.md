# Comment modifier les données de l'entreprise

Si les données fiscales du club changent, vous pouvez les mettre à jour à tout moment. Les nouvelles données seront utilisées dans les prochaines autofactures.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux entreprises <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Entreprises**.

    <figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fs9ED1QQXJQhiuEk3Y7el%252Fimage.png%3Falt%3Dmedia%26token%3Dbabad01e-4c52-45a5-8290-6cc9696c7b71&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=828913b3&#x26;sv=2" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Modifier les données

* Cliquez sur l'**ID** de l'entreprise.
*   Sélectionnez <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Modifiez les données fiscales nécessaires.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

> **Important :** <mark style="background-color:$danger;">ne modifiez pas le champ **Invoice Number Format**.</mark>

<figure><img src="../../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}
