# Comment modifier le prix d'un produit de type article

Vous pouvez changer le prix de n'importe quel article (tubes de balles, grips ou autres produits) depuis la liste des produits ou depuis sa fiche. Quand vous changez le **Prix brut**, le système recalcule le **Prix net** selon la taxe du produit.

### Vidéo explicative

{% embed url="https://youtu.be/dnUlgHbHzDk" %}

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux produits

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**. L'onglet **Produits** s'ouvre directement.
{% endstep %}

{% step %}
### Chercher l'article

* Dans la colonne **Catégorie**, sélectionnez **Article**.
* Dans la colonne **Nom**, écrivez le nom ou une partie du nom du produit. Par exemple : `tube`.
* La liste n'affiche que les produits correspondants.
{% endstep %}

{% step %}
### Option 1 : changer le prix depuis la liste

* Dans la colonne **Prix brut**, cliquez sur le prix actuel.
* Écrivez le nouveau montant.
* Cliquez en dehors du champ pour appliquer le changement.
* Vérifiez dans la liste que le prix a été mis à jour.
{% endstep %}

{% step %}
### Option 2 : changer le prix depuis la fiche

* Cliquez sur l'**ID** du produit.
* Ouvrez l'onglet **Général**.
* Cliquez sur l'icône de modification.
* Changez le **Prix brut**.
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

> **Important :** avant d'enregistrer, vérifiez que vous avez choisi le bon produit (surtout s'il y en a plusieurs aux noms proches) et contrôlez son **Type de taxe**, car le prix net est calculé à partir de celui-ci.
