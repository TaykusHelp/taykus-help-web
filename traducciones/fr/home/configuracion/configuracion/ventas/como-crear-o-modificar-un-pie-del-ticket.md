# Comment créer ou modifier le pied de page du ticket

Le pied de page du ticket est un texte qui apparaît à la fin de tous les tickets d'achat. Il sert à ajouter des informations comme des conditions, des promotions, un remerciement ou les coordonnées du club.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à Billet

* Cliquez sur l'icône <i class="fa-gear" style="color:blue;">:gear:</i> en haut à droite et ouvrez **Paramètres**.
* Cliquez sur **Ventes**.
*   Ouvrez l'onglet **Billet**.<br>

    <figure><img src="../../.gitbook/assets/image (46).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Écrire le pied de page

* Cliquez sur <i class="fa-pencil" style="color:green;">:pencil:</i>.
*   Écrivez le texte que vous voulez voir apparaître en bas du ticket.<br>

    <figure><img src="../../.gitbook/assets/image (47).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

> **Important :** il ne peut y avoir qu'un seul pied de page. Pour le changer, modifiez celui qui existe.
