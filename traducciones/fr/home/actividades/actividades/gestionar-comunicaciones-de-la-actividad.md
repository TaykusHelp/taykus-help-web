# Gérer les communications de l'activité

La section **Communications** permet de revoir et de modifier les modèles de messages que le système envoie automatiquement aux utilisateurs lors de l'inscription à une activité.

Ces communications informent le participant de l'état de son inscription, par exemple quand il s'inscrit correctement ou quand son inscription est annulée.

Le club peut modifier ces messages pour les adapter à son style de communication ou ajouter des informations pour les participants.

{% stepper %}
{% step %}
### Accéder à la section Communications

* Allez dans le menu de gauche et sélectionnez **Activités**.
* Sélectionnez l'id de l'**activité** à gérer.
*   En haut, cliquez sur l'onglet **Communications**.<br>

    <figure><img src="../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Revoir les modèles disponibles

Cette section affiche les modèles de communication automatique que le système envoie aux participants lors de l'inscription.

*   **Confirmation d'inscription :** message reçu par l'utilisateur quand il s'inscrit correctement à l'activité.<br>

    <figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>
*   **Annulation d'inscription :** message envoyé quand une inscription est annulée.<br>

    <figure><img src="../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

Ces communications sont envoyées automatiquement selon l'état de l'inscription du participant.
{% endstep %}

{% step %}
### Modifier un modèle de communication

Si vous voulez modifier l'un de ces messages :

* Sélectionnez le modèle à modifier.
* Faites les modifications nécessaires dans le contenu du message.
* Cliquez sur **Sauvegarder** pour appliquer les changements.
{% endstep %}
{% endstepper %}

En personnalisant les communications, le club peut adapter les messages automatiques du système et tenir les participants informés de l'état de leur inscription.
