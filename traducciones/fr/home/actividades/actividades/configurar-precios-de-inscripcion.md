# Configurer les prix d'inscription

La section **Prix d'inscription** permet de définir le coût de participation à une activité quand il existe **plusieurs catégories ou modalités d'inscription**.

Pour les activités avec une seule catégorie, le système utilise automatiquement le **prix défini lors de la création de l'activité** : il n'y a donc rien d'autre à configurer dans cette section.

Cet outil s'utilise surtout quand le prix de l'inscription **varie selon le nombre de catégories ou de modalités auxquelles s'inscrit le participant**.

{% stepper %}
{% step %}
### Accéder à la section Prix d'inscription

* Allez dans le menu de gauche et ouvrez **Activités**.
* Sélectionnez l'activité à gérer.
*   En haut, cliquez sur l'onglet **Prix d'inscription**.<br>

    <figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Quand utiliser cette section

Si l'activité n'a **qu'une seule catégorie**, inutile d'ajouter un prix dans cette section.

Dans ce cas, le système utilise automatiquement le **prix du produit configuré lors de la création de l'activité**.

Il ne faut configurer cette section que quand l'activité permet **plusieurs catégories ou combinaisons d'inscription**.
{% endstep %}

{% step %}
### Conditions préalables

Quand une activité permet de s'inscrire à **plus d'une catégorie**, il faut définir les prix pour chaque option.

Pour cela, ces éléments doivent déjà exister :

* Les **catégories créées** dans l'activité. \
  Pour savoir comment, consultez cet article :\
  <a href="como-crear-categorias.md" class="button primary">Comment créer des catégories</a>
* Les **produits de type article** avec les prix correspondants.\
  Pour savoir comment les créer, consultez cet article :\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary">Comment créer un produit de type Article</a>

Une fois créés, cette section vous permettra d'associer chaque prix à son option d'inscription.
{% endstep %}

{% step %}
### Associer le prix au nombre de catégories

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre, à remplir ainsi :<br>

    <figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>



    * **Nombre d'inscriptions par catégories :** indiquez à combien de catégories s'applique le prix que vous configurez.
    * **Produit :** sélectionnez le produit créé au préalable qui contient le **prix correspondant au nombre de catégories choisi**. C'est le montant que paiera le participant en s'inscrivant à ce nombre de catégories.
* Cliquez sur Sauvegarder pour enregistrer les changements.
* **Important :** vous devrez créer **autant de prix d'inscription que de combinaisons de catégories autorisées par l'activité**, y compris l'option de s'inscrire **à une seule catégorie**.
{% endstep %}
{% endstepper %}

En configurant correctement les **prix d'inscription selon le nombre de catégories**, le système appliquera automatiquement le montant correspondant à l'option choisie par le participant lors de l'inscription.

Le club peut ainsi gérer différentes modalités d'inscription dans une même activité, avec des prix organisés et associés à chaque combinaison de catégories.
