# Comment créer des catégories

Les **catégories** permettent d'organiser les participants d'une activité selon différents critères, comme la modalité, le niveau ou le type de compétition.

C'est particulièrement utile pour des activités comme les tournois ou les événements où les joueurs peuvent s'inscrire à différentes catégories (par exemple : masculin, féminin, mixte ou différents niveaux de jeu).

Dans cet article, nous vous expliquons comment les créer.

{% stepper %}
{% step %}
### Accéder à la section Catégories

* Allez dans le menu de gauche et ouvrez **Activités**.
* Sélectionnez l'id de l'activité à gérer.
*   En haut, cliquez sur l'onglet **Catégories**.<br>

    <figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer une nouvelle catégorie

* Cliquez sur :heavy\_plus\_sign:.
*   Une fenêtre s'ouvre, dans laquelle vous devez remplir le champ suivant :<br>

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Nom :** indiquez le nom de la catégorie (par exemple : Masculin, Féminin, Mixte ou différents niveaux de jeu).
* Une fois le nom indiqué, cliquez sur **Sauvegarder** pour créer la catégorie.
{% endstep %}

{% step %}
### Ajouter d'autres catégories

Vous pouvez répéter cette procédure autant de fois que nécessaire pour créer toutes les catégories de l'activité.

Ces catégories serviront ensuite à **gérer les inscriptions des participants** et à **configurer les prix d'inscription selon le nombre de catégories**.
{% endstep %}
{% endstepper %}

Une fois les catégories créées, les participants pourront les choisir lors de l'inscription et le système gérera automatiquement leur enregistrement dans l'activité.
