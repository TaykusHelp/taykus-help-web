# Comment voir les informations de votre profil dans l'application Taykus

Depuis l'application Taykus, les joueurs peuvent consulter simplement les informations associées à leur profil d'utilisateur.

Dans cette section, vous pourrez revoir vos données personnelles, vérifier les informations liées à votre compte et accéder aux options disponibles pour gérer votre profil dans l'application.
