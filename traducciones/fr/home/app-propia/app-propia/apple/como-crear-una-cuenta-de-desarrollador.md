# Comment créer un compte développeur

Pour pouvoir publier et gérer une application dans l'environnement Apple, il faut un compte dans l'**Apple Developer Program**.\
Ce compte permet à l'entreprise de s'identifier officiellement auprès d'Apple et de réaliser les démarches nécessaires pour travailler avec des applications iOS.

Voici comment créer et enregistrer le compte.

{% stepper %}
{% step %}
### Accéder au portail Apple Developer

*   La première étape consiste à accéder au portail officiel d'Apple Developer depuis le lien suivant :\
    <a href="https://developer.apple.com/" class="button primary">Accès à Apple Developer</a><br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure></div>
*   Connectez-vous avec votre compte Apple. Si vous n'en avez pas encore, créez-le.

    > **Important :** le compte Apple doit être créé avec des données personnelles, pas directement avec les données de l'entreprise. Plus tard, lors de l'inscription à l'Apple Developer Program, les informations légales de l'organisation seront demandées.
{% endstep %}

{% step %}
### Demander l'accès à l'Apple Developer Program

* Une fois le compte Apple créé, vous devrez demander l'inscription à l'**Apple Developer Program**.
*   Ce processus n'est pas immédiat. Apple examinera d'abord les informations du compte et fera une vérification initiale, qui peut prendre quelques jours.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Choisir le type d'entité

* Après l'approbation initiale, Apple vous demandera d'indiquer le type d'entité avec lequel vous voulez enregistrer le compte.
*   Dans ce cas, choisissez l'option : **Entreprise ou organisation**<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Informations nécessaires sur l'entreprise

* En choisissant l'option entreprise ou organisation, Apple affichera une liste des informations nécessaires pour continuer.
* Parmi les données qui peuvent être demandées :
  * Numéro **D-U-N-S** de l'entreprise.
  * Raison sociale complète de l'entreprise.
  * Adresse et données fiscales.
  * Nom et fonction de la personne autorisée à agir au nom de l'entreprise.
  * Site web de l'entreprise.
  *   Téléphone de contact.<br>

      <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>

#### Numéro D-U-N-S

* Le numéro **D-U-N-S** est un identifiant unique de l'entreprise qu'Apple peut demander pour vérifier l'organisation.
* Si l'entreprise ou l'entité n'a pas encore ce numéro, il faut le demander avant de poursuivre la configuration du compte, en cliquant sur le bouton suivant :\
  <a href="https://cloud.email.informa.es/numero-duns" class="button primary">Demander le numéro D-U-N-S</a>
* Deux options sont disponibles :
  * **Demande prioritaire :** vous obtiendrez le numéro immédiatement moyennant 9 € HT.
  * **Demande gratuite :** sans frais, mais le numéro sera émis sous 10 à 14 jours.

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Saisir la raison sociale et le numéro D-U-N-S

* Une fois le numéro D-U-N-S obtenu, Apple demandera deux données principales :
  * **Raison sociale complète de l'entreprise**, exactement comme elle figure dans les registres officiels.
  *   **Numéro D-U-N-S**, associé à cette même entreprise.<br>

      <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
* Avant de continuer, vérifiez que les deux données correspondent.
* Si la raison sociale saisie ne correspond pas à celle associée au numéro D-U-N-S, Apple peut refuser ou retarder la vérification.
{% endstep %}

{% step %}
### Compléter les informations supplémentaires

*   Après avoir saisi la raison sociale et le numéro D-U-N-S, vous devrez compléter le reste du formulaire avec des informations supplémentaires sur l'entreprise.

    Apple peut demander des données comme :

    * Site web officiel de l'entreprise.
    * Numéro de téléphone de contact.
    * Confirmation que la personne qui fait l'inscription a l'autorité légale pour signer des accords au nom de l'organisation.
    *   Vérification de l'e-mail associé au compte.<br>

        <div align="left"><figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vérifier et confirmer les informations

* Avant d'envoyer la demande, vérifiez toutes les données saisies.
* Vérifiez en particulier :
  * Raison sociale de l'entreprise.
  * Numéro D-U-N-S.
  * Adresse et données fiscales.
  * Site web.
  * Téléphone de contact.
  *   E-mail associé au compte.<br>

      <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>
* Une fois la demande envoyée, toute erreur peut retarder l'approbation de l'inscription.
{% endstep %}

{% step %}
### Attendre la vérification d'Apple

*   Après l'envoi de la demande, Apple examinera toutes les informations fournies.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
* Ce processus peut prendre plusieurs jours ouvrés, car Apple vérifie à la fois les données de l'entreprise et l'identité du demandeur.
* À la fin de la vérification, Apple enverra un e-mail au contact principal du compte avec les instructions pour terminer la dernière étape de l'inscription.
{% endstep %}

{% step %}
### Signer l'accord juridique et effectuer le paiement

* Quand Apple approuve la demande, vous recevrez un e-mail avec les instructions pour accéder au portail développeur.<br>

<div align="left"><figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure></div>

* Vous devrez alors :
  1. Lire et signer l'accord juridique d'Apple.
  2. Effectuer le paiement de l'adhésion annuelle à l'Apple Developer Program.
* Le coût de l'adhésion est de **99 USD par an**.
* Une fois cette étape terminée, le compte sera inscrit à l'Apple Developer Program.<br>
{% endstep %}
{% endstepper %}

À la fin du processus, l'entreprise disposera d'un compte développeur actif pour travailler avec des applications dans l'environnement Apple.
