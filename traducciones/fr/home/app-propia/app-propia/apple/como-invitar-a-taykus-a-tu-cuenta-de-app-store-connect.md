# Comment inviter Taykus sur votre compte App Store Connect

Pour que nous puissions vous aider à configurer ou gérer votre application iOS, vous devez inviter un membre de l'équipe de Taykus sur votre compte **App Store Connect**.

Depuis cette plateforme, Apple permet de gérer les utilisateurs, les autorisations et les accès liés aux applications publiées ou en cours de publication.

***

#### Télécharger le guide d'invitation

Vous pouvez télécharger le guide avec les captures d'écran depuis le lien suivant :

{% file src="../../.gitbook/assets/Guía de invitación a App Store Connect.pdf" %}

> **Important :** pour des raisons de sécurité, le fichier peut être protégé par un mot de passe.\
> Si vous n'avez pas le mot de passe, demandez-le à l'équipe de Taykus.

***

Une fois l'invitation envoyée, l'équipe de Taykus pourra accepter l'accès et poursuivre la gestion ou la configuration nécessaire.
