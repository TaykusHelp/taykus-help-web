# Comment appliquer une réduction en %

Appliquer des réductions depuis le point de vente permet d'ajuster le montant d'une vente de façon rapide et maîtrisée, pour des promotions, des incidents ou un geste commercial. Voici comment appliquer une réduction étape par étape.

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**, ou cliquez sur la réservation et sélectionnez **Payer Réservation**. Les deux options vous amènent au point de vente.
{% endstep %}

{% step %}
### Recherche du client

*   Si vous ne payez pas une réservation et n'avez pas encore sélectionné le client, utilisez la recherche en haut à droite pour le trouver.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   S'il s'agit d'une vente ponctuelle sans enregistrement de données, sélectionnez **Client anonyme**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le produit

* Si ce n'est pas une réservation, choisissez le produit à vendre dans la liste disponible.
{% endstep %}

{% step %}
### Appliquer la réduction

*   Saisissez sur le clavier du point de vente le pourcentage de réduction à appliquer et appuyez sur le symbole **%** pour qu'il s'applique automatiquement.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vérifier et encaisser

*   Vérifiez que la réduction apparaît correctement sur le ticket et procédez à l'encaissement avec le mode de paiement choisi par le client.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

Une fois la réduction appliquée, la vente continue normalement. Bien utiliser cette fonction garantit que les ajustements de prix sont enregistrés et évite les erreurs à la clôture de caisse.
