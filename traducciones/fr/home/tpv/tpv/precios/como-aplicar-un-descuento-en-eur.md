# Comment appliquer une réduction en €

Depuis le point de vente, vous pouvez appliquer une réduction directe en euros sur une vente avant l'encaissement. Cette option est utile quand le club doit ajuster le montant final pour une promotion, un geste commercial, une correction ponctuelle ou toute autre situation où il faut déduire une somme précise.

Voici comment appliquer une réduction en euros étape par étape.

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**, ou cliquez sur la réservation et sélectionnez **Payer Réservation**. Les deux options vous amènent au point de vente.
{% endstep %}

{% step %}
### Recherche du client

*   Si vous ne payez pas une réservation et n'avez pas encore sélectionné le client, utilisez la recherche en haut à droite pour le trouver.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   S'il s'agit d'une vente ponctuelle sans enregistrement de données, sélectionnez **Client anonyme**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le produit

* Si ce n'est pas une réservation, choisissez le produit à vendre dans la liste disponible.
{% endstep %}

{% step %}
### Appliquer la réduction

* Saisissez sur le clavier du point de vente le montant en euros à déduire et appuyez sur le symbole **€** pour appliquer la réduction automatiquement.
* Par exemple, pour déduire **5 €**, saisissez `5` sur le clavier du point de vente et appuyez sur **€**.\
  ![](<../../.gitbook/assets/image (36).png>)
* La réduction s'applique directement au montant du ticket.
{% endstep %}

{% step %}
### Vérifier et encaisser

* Vérifiez que la réduction apparaît correctement sur le ticket et procédez à l'encaissement avec le mode de paiement choisi par le client.\
  ![](<../../.gitbook/assets/image (37).png>)
{% endstep %}
{% endstepper %}

Une fois la réduction appliquée et l'encaissement fait, la vente est enregistrée avec le montant final correspondant. Bien utiliser cette option permet d'ajuster les prix de façon ponctuelle et maîtrisée, tout en gardant le ticket et la clôture de caisse corrects dans le système.
