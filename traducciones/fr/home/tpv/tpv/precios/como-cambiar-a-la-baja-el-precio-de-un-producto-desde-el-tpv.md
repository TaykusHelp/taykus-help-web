# Comment baisser le prix d'un produit depuis le point de vente

Baisser le prix d'un produit depuis le point de vente permet d'ajuster une vente ponctuelle sans modifier le prix général de l'article dans le système. Cette option est utile pour des ajustements commerciaux ou pour résoudre un incident lors de l'encaissement. Voici comment faire étape par étape.

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**, ou cliquez sur la réservation et sélectionnez **Payer Réservation**. Les deux options vous amènent au point de vente.
{% endstep %}

{% step %}
### Recherche du client

*   Si vous ne payez pas une réservation et n'avez pas encore sélectionné le client, utilisez la recherche en haut à droite pour le trouver.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   S'il s'agit d'une vente ponctuelle sans enregistrement de données, sélectionnez **Client anonyme**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le produit

* Si ce n'est pas une réservation, choisissez le produit à vendre dans la liste disponible.
{% endstep %}

{% step %}
### Changer le prix

* Cliquez sur le nom du produit dans le ticket.
*   La ligne passe en vert et vous pouvez saisir le nouveau prix.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vérifier et encaisser

*   Vérifiez que le nouveau prix apparaît correctement sur le ticket et procédez à l'encaissement avec le mode de paiement choisi par le client.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure></div>
* Le nouveau prix apparaît sur le ticket comme une réduction appliquée au montant d'origine.
{% endstep %}
{% endstepper %}

Une fois le prix modifié, vous pouvez continuer la vente normalement. L'ajustement est enregistré sur le ticket comme réduction, ce qui garantit que le mouvement apparaît correctement en caisse.
