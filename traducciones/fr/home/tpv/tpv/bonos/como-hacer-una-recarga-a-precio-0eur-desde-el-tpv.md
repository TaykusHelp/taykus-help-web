# Comment faire une recharge à 0 € depuis le point de vente

Personnaliser une recharge à 0 € permet d'ajouter du solde à un bon monétaire sans générer d'encaissement, par exemple en cas de geste commercial, de compensation ou d'ajustement interne. L'opération est enregistrée dans le système et garde l'historique du bon à jour.&#x20;

Voici comment le faire étape par étape.&#x20;

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**.
{% endstep %}

{% step %}
### Recherche du client

*   Utilisez la recherche en haut à droite pour trouver le client.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélection du bon

*   Cliquez sur l'option Bons, sous les accès rapides.

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Personnalisation de la recharge

* Une fenêtre s'ouvre avec tous les bons disponibles.
* Sélectionnez **n'importe lequel des bons** configurés au préalable.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Cliquez sur Personnaliser la recharge.
*   Un menu s'ouvre avec les caractéristiques du bon sélectionné, que vous pourrez modifier.

    <figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>
* **Personnaliser la recharge :**
  * **Prix :** écrivez zéro en chiffres.
  * **Type de bon :** sélectionnez dans le menu déroulant le type de bon correspondant.
  * **Type de montant :** choisissez dans le menu déroulant le type de solde à recharger.
  * **Montant à remplir :** saisissez la quantité à ajouter (par exemple, 100 € ou 10 unités).
  * **Description :** commentaire facultatif pour indiquer le motif de la recharge personnalisée.
* **Personnaliser les restrictions :**
  * Cette section n'est pas obligatoire, mais vous pouvez personnaliser les restrictions du bon.
* Cliquez sur OK pour enregistrer la personnalisation.
{% endstep %}

{% step %}
### Terminer la recharge

* Cette étape est indispensable. Même si le prix est de 0 €, la recharge n'est pas enregistrée si l'opération n'est pas confirmée.
*   Cliquez sur **Confirmer.**<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure></div>
* Le ticket passe à l'état **Payé**, ce qui confirme que la recharge a bien été faite.\
  ![](<../../.gitbook/assets/image (10).png>)
{% endstep %}
{% endstepper %}

Une fois la recharge à 0 € confirmée, le solde est disponible immédiatement sans générer de mouvement d'encaissement. Enregistrer correctement ces opérations garantit traçabilité et contrôle dans l'historique du bon.
