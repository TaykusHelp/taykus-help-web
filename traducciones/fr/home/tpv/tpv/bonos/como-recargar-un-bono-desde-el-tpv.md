# Comment recharger un bon depuis le point de vente

Recharger un bon monétaire depuis le point de vente permet d'ajouter du solde immédiatement pour que le client puisse l'utiliser lors de ses prochains achats ou réservations. L'opération est enregistrée automatiquement dans le système et facilite la gestion des paiements anticipés.&#x20;


{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**.
{% endstep %}

{% step %}
### Recherche du client

*   Utilisez la recherche en haut à droite pour trouver le client.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélection du bon

*   Cliquez sur l'option Bons, sous les accès rapides.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection du bon voulu

* Une fenêtre s'ouvre avec tous les bons disponibles.
* Sélectionnez le bon à recharger parmi ceux configurés au préalable.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Si vous devez faire une modification spécifique pour ce client, vous pouvez utiliser **Personnaliser la recharge** ; pour savoir comment, consultez cet article :\
  <a href="como-hacer-una-recarga-personalizada-de-un-bono-monedero-desde-el-tpv.md" class="button primary">Comment faire une recharge personnalisée d'un bon monétaire depuis le point de vente</a><br>
{% endstep %}

{% step %}

* Procédez à l'encaissement, avec le mode de paiement que préfère le client.
* Si la recharge du bon reste en attente de paiement ou de prélèvement, le solde n'est pas chargé au client tant qu'elle n'est pas payée.
{% endstep %}
{% endstepper %}

Une fois la recharge faite, le solde est disponible immédiatement. Enregistrer correctement ces opérations garantit un suivi précis du porte-monnaie et des mouvements de caisse.
