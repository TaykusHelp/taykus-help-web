# Comment envoyer un ticket depuis le point de vente

L'option **Envoyer un ticket** du point de vente permet d'envoyer le justificatif de vente à l'e-mail du client rapidement et simplement. Après une vente, le système l'envoie automatiquement à l'adresse enregistrée dans sa fiche. Cette fonction permet aussi de le renvoyer manuellement depuis le point de vente et de changer l'adresse de destination si le client veut le recevoir ailleurs.

Dans cet article, nous vous montrons comment utiliser cette option étape par étape.

{% stepper %}
{% step %}
### Trouvez la vente

* Vous pouvez trouver la vente depuis le point de vente, depuis le calendrier ou depuis **Ventes › lignes**.
* Une fois trouvée, ouvrez-la au point de vente.
{% endstep %}

{% step %}
### Envoyer le ticket

*   Cliquez sur **Envoyer un ticket**.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
*   Le système affiche une fenêtre avec les données de la fiche du client.

    <div align="left"><figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure></div>
* Vous pouvez y modifier l'adresse e-mail à laquelle le ticket sera envoyé.
* Cliquez sur **OK** pour terminer l'envoi.
{% endstep %}

{% step %}
### Vérification

* Allez dans le menu latéral gauche et sélectionnez Communications / E-mails.

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

* Cette section affiche la liste des e-mails envoyés par le système.
*   Repérez l'e-mail correspondant et vérifiez que la colonne **Statut d'envoi** indique **Envoyé**.<br>

    <figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Renvoyer le ticket depuis le point de vente permet de s'assurer que le client reçoit bien son justificatif, même s'il faut changer l'adresse e-mail. Vérifier l'état de l'envoi depuis **Communications → E-mails** confirme que le message est bien parti du système et garantit le suivi de l'opération.
