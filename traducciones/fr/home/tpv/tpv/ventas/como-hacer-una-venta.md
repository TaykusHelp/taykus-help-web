# Comment faire une vente

Le point de vente permet d'enregistrer des ventes de produits et de services de façon rapide et sûre, en garantissant que tous les mouvements apparaissent correctement en caisse. Même si la procédure est simple, il est important de suivre les bonnes étapes pour éviter les erreurs d'encaissement ou les écarts de caisse.

Dans cet article, nous expliquons comment faire une vente depuis le point de vente étape par étape.



{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**.
{% endstep %}

{% step %}
### Recherche du client

*   Utilisez la recherche en haut à droite pour trouver le client à qui faire la vente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   S'il s'agit d'une vente ponctuelle sans enregistrement de données, sélectionnez **Client anonyme**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le produit

* Sélectionnez le produit à vendre dans la liste disponible.
*   Les articles marqués comme **Vente rapide** apparaissent directement sur cet écran, à l'endroit indiqué sur l'image.

    <figure><img src="../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>
*   Vous pouvez aussi les trouver en sélectionnant le **type de produit** associé. En cliquant sur le nom du type, tous les articles liés à cette catégorie s'affichent.

    <figure><img src="../../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>


*   Une autre option est d'utiliser la **recherche de produits**. Cliquez sur la recherche et écrivez le nom du produit ou le numéro du code-barres s'il a été enregistré.

    <figure><img src="../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Vérifier et encaisser

* Vérifiez que tous les articles voulus apparaissent correctement sur le ticket.
*   Une fois confirmé, sélectionnez le mode de paiement choisi par le client et terminez la vente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

Bien faire une vente depuis le point de vente garantit que les encaissements sont enregistrés avec précision et évite les écarts de caisse. Avant de terminer toute opération, vérifiez toujours le ticket pour vous assurer que les articles et le montant sont corrects.
