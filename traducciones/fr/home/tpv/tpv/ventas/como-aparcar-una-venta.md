# Comment mettre une vente en attente

La fonction de mise en attente d'une vente au point de vente permet de mettre en pause une transaction en cours pour servir un autre client, puis de la reprendre plus tard sans perdre les informations. C'est un outil utile dans les moments de forte affluence en caisse. Voici comment l'utiliser étape par étape.

### Comment mettre une vente en attente ?

Si le point de vente est déjà ouvert avec un produit, depuis une réservation (en ouvrant le point de vente depuis le calendrier) ou une vente directe, suivez ces étapes :

{% stepper %}
{% step %}
### **Mettre la vente en attente**

*   En haut de l'écran du point de vente, cliquez sur **Vente préenregistrée**.<br>

    <figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### **Confirmation**

* La vente est mise en attente automatiquement.
*   Le ticket passe du vert au blanc, ce qui indique que le point de vente est de nouveau disponible pour une autre opération.<br>

    <figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>


{% endstep %}
{% endstepper %}

Une fois mise en attente, la vente reste enregistrée dans le système jusqu'à ce que vous décidiez de la reprendre. Cette fonction permet de libérer le point de vente sans perdre la transaction en cours et facilite la gestion de plusieurs clients aux moments de forte activité.
