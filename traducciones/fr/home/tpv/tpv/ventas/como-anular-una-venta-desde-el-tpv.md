# Comment annuler une vente depuis le point de vente

L'option **Annuler la vente** du point de vente permet d'annuler des opérations enregistrées par erreur et de garder un bon suivi de la caisse. Elle est particulièrement utile quand un mauvais montant a été encaissé, qu'un mauvais produit a été choisi ou qu'il faut annuler une vente avant la clôture. Annuler depuis le point de vente garantit que le mouvement est enregistré proprement dans le système et évite les écarts par la suite.

Dans cet article, nous vous montrons comment faire étape par étape.

{% stepper %}
{% step %}
### Trouvez la vente

* Vous pouvez trouver la vente depuis le point de vente, depuis le calendrier ou depuis **Ventes › lignes**.
* Une fois trouvée, ouvrez-la au point de vente.
{% endstep %}

{% step %}
### Annuler la vente

*   Cliquez sur **Annuler la vente**.

    <figure><img src="../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
*   Avant de confirmer, le système affiche un message de vérification.

    <figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Oui** pour terminer l'annulation.
{% endstep %}

{% step %}
### Vérification

*   Après l'annulation, vous pouvez vérifier que tout s'est bien passé en contrôlant que le ticket apparaît à **0 €** et barré.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>


*   En quittant le point de vente, le système vous amène automatiquement à **Ventes › lignes**, où l'opération apparaît en **rouge**, ce qui indique qu'elle a été enregistrée comme annulée.<br>

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Cette vérification rapide confirme que le mouvement a bien été enregistré dans le système.
