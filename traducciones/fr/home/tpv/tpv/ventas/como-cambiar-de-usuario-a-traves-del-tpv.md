# Comment changer d'utilisateur depuis le point de vente

**Changer d'utilisateur** au point de vente permet de passer rapidement d'un employé à l'autre quand un même terminal est utilisé par plusieurs personnes. Cette fonction garantit que chaque opération est enregistrée avec le bon utilisateur, ce qui facilite le suivi des ventes et de l'activité de caisse sans avoir à se déconnecter ni à interrompre le travail.

Dans cet article, nous vous montrons comment utiliser cette option étape par étape.

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente.**
{% endstep %}

{% step %}
### Changement d'utilisateur

*   Cliquez sur le bouton **Changer d'utilisateur.**

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection de l'utilisateur

*   Une fenêtre s'ouvre avec tous les utilisateurs disponibles.<br>

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur l'utilisateur voulu.
* Une autre fenêtre s'ouvre pour saisir le mot de passe.

<div align="left"><figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure></div>

* Cliquez sur OK pour changer d'utilisateur.
{% endstep %}
{% endstepper %}

Bien utiliser la fonction **Changer d'utilisateur** aide à garder un suivi ordonné de l'activité au point de vente et garantit que chaque opération est associée à la bonne personne. En faire une habitude améliore le contrôle de la caisse et évite les confusions entre les équipes.
