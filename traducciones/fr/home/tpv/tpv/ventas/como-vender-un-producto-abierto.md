# Comment vendre un produit ouvert

Disposer au point de vente d'un outil pour vendre des produits non enregistrés dans le système est très utile, surtout pour des produits ponctuels qui ne seront pas disponibles régulièrement.&#x20;

Voici comment faire une vente avec un produit ouvert :

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**, ou cliquez sur la réservation et sélectionnez **Payer Réservation**. Les deux options vous amènent au point de vente.
{% endstep %}

{% step %}
### Recherche du client

*   Si vous ne payez pas une réservation et n'avez pas encore sélectionné le client, utilisez la recherche en haut à droite pour le trouver.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   S'il s'agit d'une vente ponctuelle sans enregistrement de données, sélectionnez **Client anonyme**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le produit

* Si ce n'est pas une réservation, choisissez le produit à vendre dans la liste disponible.
{% endstep %}

{% step %}
### Ajouter un produit ouvert

*   Cliquez sur **Prix ouvert.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
*   Cette fenêtre s'ouvre, à remplir ainsi :<br>

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    * **Description :** saisissez le nom que vous voulez donner à ce produit ou à cette vente.
    * **Prix :** fixez le prix à attribuer à ce produit ou à cette vente.
    * **Type de produit :** sélectionnez dans le menu déroulant une catégorie si vous voulez classer ce produit ouvert. Ce champ est facultatif.
    * **Taxes :** sélectionnez le type de taxe à appliquer à ce produit ouvert.
* Cliquez sur **OK** pour ajouter ce montant au ticket.
{% endstep %}

{% step %}
### Vérifier et encaisser

* Assurez-vous que le produit ouvert a bien été ajouté au ticket.
* Procédez à l'encaissement avec le mode de paiement que préfère le client.<br>
{% endstep %}
{% endstepper %}

Une fois le produit ouvert ajouté, vous pouvez continuer la vente et encaisser normalement. Cette fonction permet d'enregistrer des montants personnalisés sans modifier le catalogue des produits, tout en gardant le contrôle du ticket et de la caisse.
