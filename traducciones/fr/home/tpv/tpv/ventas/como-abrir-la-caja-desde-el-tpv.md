# Comment ouvrir la caisse depuis le point de vente

Ouvrir la caisse depuis le point de vente permet d'enregistrer le montant initial de la journée et de garantir un bon suivi des mouvements d'espèces. Faire cette étape en début de journée aide à éviter les écarts et garde le suivi de caisse organisé. Dans cet article, nous vous montrons comment faire étape par étape.

{% stepper %}
{% step %}
### **Accédez au point de vente**

* Allez dans le menu latéral gauche et sélectionnez **Point de vente.**
{% endstep %}

{% step %}
### Sélection de la caisse

* Si la caisse est fermée, une fenêtre avec les caisses disponibles s'affiche automatiquement en ouvrant le point de vente.
*   Cliquez sur la caisse à ouvrir.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Ouvrir la caisse

* Après avoir sélectionné la caisse, le système vous amène à la page de résumé de caisse.
*   Sélectionnez **Mouvements.**<br>

    <figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur **Ouvrir**.
{% endstep %}

{% step %}
### Indiquer le fonds de caisse

* Une fenêtre s'ouvre pour indiquer les espèces avec lesquelles vous commencez la journée.\
  ![](<../../.gitbook/assets/image (18).png>)
* Si vous ne voulez pas enregistrer d'espèces initiales, laissez le champ vide.
{% endstep %}

{% step %}
### Confirmer l'ouverture

* Cliquez sur <mark style="color:$tint;">**OK**</mark> pour ouvrir la caisse
{% endstep %}
{% endstepper %}

Une fois la caisse ouverte, vous pouvez commencer à enregistrer les ventes et les mouvements normalement. Pensez à toujours ouvrir la caisse en début de journée pour garder un bon suivi des espèces et éviter les écarts à la clôture.
