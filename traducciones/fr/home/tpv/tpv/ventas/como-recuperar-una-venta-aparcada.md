# Comment reprendre une vente en attente

Reprendre une vente en attente permet de continuer une transaction en pause sans perdre les informations déjà enregistrées. C'est utile pour poursuivre l'encaissement quand un client revient ou qu'une opération en caisse a été interrompue. Voici comment reprendre une vente en attente étape par étape.

{% stepper %}
{% step %}
### Accès au point de vente

* Allez dans le menu latéral gauche et sélectionnez **Point de vente**.
{% endstep %}

{% step %}
### Ouvrir les ventes en attente

*   En haut de l'écran, cliquez sur **Ventes préenregistrées**.<br>

    <figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélectionner la vente

* Une fenêtre s'ouvre avec toutes les ventes en attente.
*   Choisissez la vente à reprendre.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Terminer la vente

* Poursuivez l'encaissement avec le mode de paiement que préfère le client.
{% endstep %}
{% endstepper %}

Une fois la vente reprise, vous pouvez terminer l'encaissement normalement. Bien utiliser les ventes en attente aide à garder de l'ordre au point de vente et évite de perdre des informations pendant la journée.
