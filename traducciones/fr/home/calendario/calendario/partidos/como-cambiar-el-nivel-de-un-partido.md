# Comment changer le niveau d'un match

Une fois le match créé, le club peut changer le niveau minimum et maximum des joueurs qui peuvent s'inscrire. Les joueurs ne peuvent le changer ni depuis l'app ni depuis la zone client.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir le match

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
* Cliquez sur le match.
*   Dans le menu de droite, cliquez sur **Détails**.

    <figure><img src="../../.gitbook/assets/partido-detalles.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Changer le niveau

* L'onglet **Général** de la réservation s'ouvre.
* Faites défiler vers le bas jusqu'à **Restrictions**.
*   Changez le **Min. Niveau** et le **Max. Niveau**.

    <figure><img src="../../.gitbook/assets/partido-restricciones-nivel.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur **Sauvegarder**.
{% endstep %}
{% endstepper %}

Pour en savoir plus, consultez [Types de match : compétitif, amical et genre](tipos-de-partido.md).
