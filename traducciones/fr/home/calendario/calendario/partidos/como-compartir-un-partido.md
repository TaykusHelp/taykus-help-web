# Comment partager un match

Partager un match est le moyen le plus rapide pour que davantage de joueurs s'inscrivent et qu'il soit complet plus tôt.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir les options de partage

* Cliquez sur le match.
* Allez dans le menu de droite.
*   Vous verrez deux façons de le partager, selon ce dont vous avez besoin.

    <figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1 : Partager (message prêt à envoyer)

En cliquant sur **Partager**, le système crée un message mis en forme qui contient :

* Le nom du club
* Le niveau du match
* La date et la durée
* Le lieu
* L'état des places
* Le lien direct d'inscription

C'est la meilleure option pour l'envoyer sur WhatsApp, car elle présente toutes les informations du match clairement.

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 2 : Copier le lien

En cliquant sur **Copier le lien**, le système copie seulement le lien direct vers le match.

C'est utile si :

* Vous voulez écrire votre propre message.
* Vous allez l'inclure dans une campagne ou une newsletter.
* Vous n'avez besoin que du lien.
{% endstep %}
{% endstepper %}
