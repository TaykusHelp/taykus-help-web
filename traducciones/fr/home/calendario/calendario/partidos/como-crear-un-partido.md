# Comment créer un match

Avec les matchs, le club peut ouvrir des places sur un terrain pour que les joueurs s'inscrivent. C'est un moyen simple de remplir les créneaux libres du calendrier.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

<figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choix du type de réservation

* Cliquez sur le terrain et l'heure où vous voulez créer le match.
* Le menu des types de réservation s'ouvre.
*   Choisissez le type de réservation des matchs. Son nom est choisi par chaque club : sur l'image, c'est **Partido**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (103).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Informations du match

*   La fiche du match s'ouvre :<br>

    <figure><img src="../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>

    * **Niveau minimum et maximum :** le niveau autorisé dans le match. C'est facultatif : si vous ne le remplissez pas, le niveau sera fixé par le premier joueur qui s'inscrit.
    * **Modifier les niveaux :** cochée par défaut, le match est alors **compétitif** (le résultat change le niveau des joueurs). Décochez-la si vous voulez qu'il soit **amical** (le résultat ne change pas le niveau).
    * **Genre :** en cliquant, un menu déroulant s'ouvre avec ces options :
      * **Ouvert :** tout le monde peut s'inscrire.
      * **Homme :** seules les personnes identifiées avec le genre masculin peuvent s'inscrire.
      * **Femme :** seules les personnes identifiées avec le genre féminin peuvent s'inscrire.
      * **Mixte :** 2 hommes et 2 femmes. Si vous voulez une autre combinaison, choisissez **Ouvert**.
{% endstep %}

{% step %}
### Ajouter des joueurs (facultatif)

* Cliquez sur le bloc **Participants**.
* Sélectionnez **Recherche**.
*   Écrivez le nom du joueur.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (105).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Enregistrer le match

* Cliquez sur **Sauvegarder** pour confirmer.
* Le match apparaît dans le calendrier et les joueurs peuvent s'inscrire.
{% endstep %}
{% endstepper %}
