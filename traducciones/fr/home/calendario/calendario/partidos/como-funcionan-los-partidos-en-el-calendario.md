# Comment fonctionnent les matchs dans le calendrier

Quand vous créez un match ouvert, il n'occupe pas de terrain réel tant qu'il n'est pas complet. Ainsi, le club ne perd pas de disponibilité à cause de matchs qui n'ont pas encore tous leurs joueurs.

## Le terrain virtuel « Matches »

<figure><img src="../../.gitbook/assets/image (36).png" alt=""><figcaption></figcaption></figure>

Quand vous créez un match ouvert, il est d'abord placé sur un terrain virtuel appelé **Matches**. Ce n'est pas un terrain physique du club : c'est un espace temporaire où le match attend pendant que les joueurs s'inscrivent.

## Quand le match est complet

Dès que le match a tous ses joueurs, le système le déplace automatiquement sur un terrain réel libre sur ce créneau horaire.

## Si les terrains réels se remplissent avant

Si tous les terrains réels de ce créneau sont occupés et que le match est toujours incomplet, le système l'annule automatiquement. On évite ainsi les chevauchements dans le calendrier.

Grâce à ce fonctionnement, le club peut encourager la création de matchs sans compromettre la disponibilité réelle de ses terrains.
