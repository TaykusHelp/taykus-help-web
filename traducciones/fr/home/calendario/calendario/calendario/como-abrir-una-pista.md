# Comment ouvrir un terrain

Si vous avez fermé un terrain avec **Fermer toute la journée**, vous pouvez le rouvrir. Comme le terrain fermé disparaît du calendrier ce jour-là, il faut le faire depuis un jour où il apparaît, en choisissant une période qui inclut le jour fermé.

Par exemple, si le terrain est fermé le 17, allez sur le calendrier du 16 et choisissez la période du 16 au 18.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
*   Allez à la veille du jour où le terrain est fermé. Vous pouvez choisir le jour dans le calendrier en haut.

    <figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir les horaires du terrain

* Cliquez sur le nom du terrain. La fenêtre **Heures d'ouverture** de ce terrain s'ouvre.
{% endstep %}

{% step %}
### Choisir la période

*   Dans **Périodicité**, laissez **Aujourd'hui** décoché et remplissez les dates :

    <figure><img src="../../.gitbook/assets/abrir-pista-restaurar.png" alt=""><figcaption></figcaption></figure>

    * **De :** la veille du jour fermé.
    * **À :** le lendemain du jour fermé.
{% endstep %}

{% step %}
### Rétablir l'horaire

* Cliquez sur **Rétablir par défaut**.
* Le terrain retrouve son horaire normal et réapparaît dans le calendrier.

> **Important :** **Rétablir par défaut** s'applique à tous les jours de la période. Si la veille ou le lendemain avaient un horaire spécial, ils reviennent eux aussi à leur horaire normal. Vérifiez-les ensuite et, si besoin, remettez leur horaire.
{% endstep %}
{% endstepper %}

> **Important :** seul le terrain sélectionné est ouvert. Si vous avez fermé plusieurs terrains ce jour-là, répétez l'opération pour chacun d'eux.

Pour savoir comment fermer un terrain, consultez [Comment fermer un terrain](como-cerrar-una-pista.md).
