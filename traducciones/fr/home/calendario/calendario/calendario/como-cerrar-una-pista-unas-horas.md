# Comment fermer un terrain quelques heures

Si vous avez seulement besoin de fermer un terrain quelques heures (par exemple le matin, l'après-midi ou un moment en milieu de journée), il n'est pas nécessaire de le fermer toute la journée. Il y a deux façons de le faire depuis le calendrier :

* **Changer ses heures d'ouverture** pour ce jour ou ces jours.
* **Bloquer ces heures avec une réservation** sans joueurs.

> **Important :** cela se fait terrain par terrain. Si vous devez fermer plusieurs terrains, répétez l'opération pour chacun.

## Option 1 : changer les heures d'ouverture

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
*   Allez au jour que vous voulez changer. Vous pouvez le choisir dans le calendrier en haut.

    <figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ouvrir les horaires du terrain

* Cliquez sur le nom du terrain. La fenêtre **Heures d'ouverture** de ce terrain s'ouvre.
{% endstep %}

{% step %}
### Changer les heures

*   Changez le **Début** et la **Fin** pour ne laisser ouvertes que les heures que vous voulez.

    <figure><img src="../../.gitbook/assets/cerrar-horas-apertura.png" alt=""><figcaption></figcaption></figure>

    * **Fermer l'après-midi :** ne laisse que le matin. Par exemple, de 09:00 à 14:00.
    * **Fermer le matin :** ne laisse que l'après-midi. Par exemple, de 16:00 à 22:30.
    * **Fermer un moment en milieu de journée :** créez deux tranches avec **+**. Par exemple, une de 09:00 à 14:00 et une autre de 16:00 à 22:30, pour fermer de 14:00 à 16:00.
{% endstep %}

{% step %}
### Choisir les jours et enregistrer

* Dans **Périodicité**, cochez **Aujourd'hui** si c'est seulement pour ce jour, ou remplissez **De** et **À** s'il s'agit de plusieurs jours de suite.
* Cliquez sur **Enregistrer les modifications**.
{% endstep %}
{% endstepper %}

Pour revenir à l'horaire normal, consultez [Comment ouvrir un terrain](como-abrir-una-pista.md).

## Option 2 : bloquer les heures avec une réservation

Vous pouvez aussi créer une réservation sur ce terrain **sans ajouter de joueur** et l'ajuster aux heures que vous voulez fermer. Ainsi, personne ne peut réserver sur ce créneau. Pour savoir comment créer une réservation, consultez [Comment créer une réservation](../reservas/como-crear-una-reserva.md).

> Si la fermeture concerne de nombreux jours ou tout le club, il vaut mieux changer l'horaire depuis Paramètres. Consultez [Comment fermer le club entre deux dates](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/reservas/horarios/como-cerrar-el-club-entre-dos-fechas).
