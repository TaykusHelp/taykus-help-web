# Comment fermer un terrain

Fermer un terrain permet de le bloquer pendant une journée entière pour qu'aucune réservation ne puisse y être faite. Cette option est particulièrement utile les jours fériés, pour les événements internes du club, l'entretien ou tout autre motif opérationnel.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
{% endstep %}

{% step %}
### Choix de la date

* Sélectionnez le jour que vous voulez fermer.

<figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

* En cliquant sur le jour, le calendrier vous emmène directement à cette date.
{% endstep %}

{% step %}
### Fermeture du terrain

* Cliquez sur le nom du terrain.
* Le menu suivant s'ouvre :

<div align="left"><figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure></div>

* Sélectionnez **Fermer toute la journée**.
{% endstep %}
{% endstepper %}

> **Important :** la fermeture s'applique seulement au terrain sélectionné. Si vous devez fermer d'autres terrains le même jour, répétez l'opération pour chacun d'eux.

Pour le rouvrir, consultez [Comment ouvrir un terrain](como-abrir-una-pista.md). Si vous voulez seulement le fermer quelques heures, consultez [Comment fermer un terrain quelques heures](como-cerrar-una-pista-unas-horas.md).
