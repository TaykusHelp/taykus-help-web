# Display

Le display est l'écran que vous pouvez installer dans le club pour montrer aux joueurs et aux visiteurs les matchs du jour : horaires, joueurs et numéro de terrain. En plus d'être très pratique, il donne au club une image plus moderne et professionnelle.

## Comment ouvrir le display

{% stepper %}
{% step %}
### Accès au display

* Cliquez sur **Calendrier** dans le menu de gauche. Un menu déroulant s'ouvre avec deux options :
  * **Display : 1 colonne**
  * **Display : 2 colonnes**

<div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Choisir le format

* Sélectionnez l'option que vous préférez selon la façon dont vous voulez que l'écran s'affiche.
* Le display s'ouvre dans un nouvel onglet du navigateur. C'est cet onglet que vous devrez afficher sur l'écran du club.
{% endstep %}
{% endstepper %}

## Comment afficher seulement les initiales des joueurs

Si vous préférez que le nom complet des participants n'apparaisse pas à l'écran, vous pouvez configurer le display pour qu'il n'affiche que leurs initiales.

{% stepper %}
{% step %}
### Accès aux paramètres des réservations

* Cliquez sur l'icône <i class="fa-gear">:gear:</i> en haut à droite.
* Cliquez à nouveau sur **Paramètres**.
* Sélectionnez **Réservations**.

<div align="left"><figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Sélectionner le sport

* Dans la colonne **Groupe de ressources**, cliquez sur l'ID du sport que vous voulez afficher à l'écran.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Activer les initiales

* La configuration générale de ce sport s'ouvre.
* Cochez la case **Afficher les initiales des participants**.

<div align="left"><figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}
