# Comment annuler les réservations futures d'une réservation multiple

Si une réservation multiple a déjà commencé, vous pouvez annuler seulement les réservations qui restent à jouer et garder celles qui sont passées. C'est utile quand un joueur arrête de venir, change un planning fixe ou quand le club doit libérer les prochaines dates sans toucher à l'historique.

### Vidéo explicative

{% embed url="https://youtu.be/ehAQhAR0FKU" %}

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à la liste Réservations multiples

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
*   Dans le menu déroulant, cliquez sur **Réservations multiples**.<br>

    <figure><img src="../../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Filtrer les réservations futures

* Trouvez la réservation multiple dans la liste et cliquez sur son **ID**.
* Vous verrez toutes les réservations qui en font partie.
* Allez dans la colonne de la **date de début**.
*   Sélectionnez **Plus grand que** et saisissez la date à partir de laquelle vous voulez annuler.<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection des réservations

* Vérifiez que le filtre est bien appliqué.
*   Cliquez sur **ID** dans l'en-tête pour sélectionner toutes les réservations filtrées.

    <figure><img src="../../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Type d'annulation

* Une fois les réservations sélectionnées, cliquez sur le bouton **Annuler**.
*   Deux options apparaissent :

    <div align="left"><figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>

    * **Annuler la réservation et les dettes :** supprime la réservation et aussi la dette.
    * **Annuler la réservation en maintenant les dettes :** supprime la réservation mais conserve le paiement du terrain en attente. C'est utile quand un joueur annule hors délai et que vous voulez libérer le terrain sans perdre la dette.
* Cliquez sur l'option dont vous avez besoin.
* Un message de confirmation apparaît selon l'option choisie.\
  ![](<../../../.gitbook/assets/image (9).png>)![](<../../../.gitbook/assets/image (10).png>)
{% endstep %}

{% step %}
### Confirmation

* Confirmez pour annuler les réservations sélectionnées.

> **Important :** avant de confirmer, vérifiez que le filtre ne contient que des réservations futures. Ainsi, vous n'annulerez pas (et ne rembourserez pas) des réservations que vous ne voulez pas toucher.
{% endstep %}

{% step %}
### Résultat

*   Les réservations passent du statut **Réservée** à **Annulée**.<br>

    <figure><img src="../../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Important :** les réservations **ne sont pas supprimées du système** : elles passent seulement au statut **Annulée** et continuent d'apparaître dans les listes. Pour éviter toute confusion, nous vous conseillons de renommer la réservation multiple en **ANNULÉE**.
