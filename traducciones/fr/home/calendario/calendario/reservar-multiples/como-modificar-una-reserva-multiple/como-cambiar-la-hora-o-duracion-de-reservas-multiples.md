# Comment changer l'heure ou la durée des réservations multiples

Vous pouvez changer l'heure de début ou la durée de nombreuses réservations en une fois, par exemple à cause d'un changement d'horaires du club ou de disponibilité des terrains. Le changement peut s'appliquer à toute la réservation multiple ou seulement à une période.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à la réservation multiple

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
*   Cliquez sur **Réservations multiples**.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Trouvez la réservation multiple que vous voulez modifier et cliquez sur son **ID**.
* Vous verrez la liste de toutes les réservations qui en font partie.

<figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection des réservations

* **Pour changer toutes les réservations :** cliquez sur **ID** dans l'en-tête pour toutes les sélectionner.
* **Pour changer seulement une date ou une période :** filtrez d'abord par la colonne **Début** :
  * Cliquez sur les trois lignes horizontales de la colonne.
  *   Choisissez **Plus grand que** pour changer les réservations à partir d'une date.

      <figure><img src="../../../.gitbook/assets/image (114).png" alt=""><figcaption></figcaption></figure>
  * Ou choisissez **Dans la plage** pour changer les réservations entre deux dates.
  * Ensuite, sélectionnez les réservations filtrées.
{% endstep %}

{% step %}
### Changer l'heure ou la durée

* Une fois les réservations sélectionnées, cliquez sur **Actions**.
*   Sélectionnez **Changer Heure/Durée**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (115).png" alt=""><figcaption></figcaption></figure></div>
*   Dans la fenêtre qui s'ouvre, changez :<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (116).png" alt=""><figcaption></figcaption></figure></div>

    * L'**heure de début**.
    * La **durée** de la réservation.
* Cochez **Prix de mise à jour** pour ajuster le montant à la nouvelle heure ou durée.
* Si vous voulez prévenir les joueurs, cochez **Notifier les participants**.
* Cliquez sur **OK**.
{% endstep %}
{% endstepper %}

Le système vérifie la disponibilité avant d'appliquer les changements. Si une réservation ne peut pas être modifiée parce que le terrain n'est pas libre à la nouvelle heure ou durée, une fenêtre affiche les erreurs :

<div align="left"><figure><img src="../../../.gitbook/assets/image (117).png" alt=""><figcaption></figcaption></figure></div>

Dans ce cas, vous pouvez :

* Enregistrer les modifications valides.
* Écarter les réservations en erreur.

Une fois confirmé, l'heure ou la durée est mise à jour dans les réservations sélectionnées.
