# Comment créer une réservation multiple

La **réservation multiple** crée plusieurs réservations à la fois. Elle est très utile quand un joueur veut un terrain fixe pendant une période (par exemple, tous les mardis) ou quand le club doit bloquer plusieurs terrains pour des tournois, des cours ou des événements.

Dans une même réservation multiple, vous pouvez choisir plusieurs **ressources**, **dates**, **jours** et **horaires**.

### Vidéo explicative

{% embed url="https://youtu.be/Wf7-vtLXeM0" %}

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès à l'onglet Multiple

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
* Cliquez sur le **jour**, le **terrain** et l'**heure** où vous voulez commencer la réservation.
*   Choisissez le **type de réservation**.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
* Ouvrez l'onglet **Multiple**.

<div align="left"><figure><img src="../../.gitbook/assets/image (57).png" alt="" width="274"><figcaption></figcaption></figure></div>

Dans cet onglet, vous configurerez les ressources, la durée et les horaires de la réservation multiple.

<figure><img src="../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélectionner les ressources

* Cliquez sur le bouton :heavy\_plus\_sign:\
  ![](<../../.gitbook/assets/image (1).png>)
* Une fenêtre s'ouvre pour choisir les terrains ou installations que vous voulez réserver.

<figure><img src="../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

* Cochez les ressources et cliquez sur **OK**.
{% endstep %}

{% step %}
### Indiquer les dates et la description

* **Date de début :** jour où commence la réservation multiple.
* **Date de fin :** dernier jour où la réservation se répète.
* **Description :** un nom pour reconnaître la réservation multiple.

<figure><img src="../../.gitbook/assets/image (61).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélectionner les jours et les horaires

* Choisissez l'**heure** de la réservation.
* Cliquez sur le bouton **+** pour ajouter ce créneau horaire.
*   Cochez les **jours de la semaine** où elle se répétera.<br>

    <figure><img src="../../.gitbook/assets/image (62).png" alt=""><figcaption></figcaption></figure>
* Répétez l'opération si vous avez besoin d'autres jours ou horaires.

> **Important :** après avoir choisi l'heure, vous devez cliquer sur le bouton **+**. Si vous n'ajoutez pas le créneau avec ce bouton, même si vous cochez les jours, le système ne vous laissera pas enregistrer la réservation multiple.
{% endstep %}

{% step %}
### Vérifier la disponibilité

*   Avant d'enregistrer, cliquez pour vérifier la disponibilité.<br>

    <figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
* Vous verrez ainsi si les ressources sont libres aux dates et horaires choisis.
* Celles qui ne sont pas disponibles apparaissent en rouge.\
  ![](<../../.gitbook/assets/image (3).png>)
{% endstep %}

{% step %}
### Enregistrer la réservation multiple

* Après avoir vérifié la disponibilité, enregistrez la réservation multiple.
* Le système crée toutes les réservations selon les ressources, les jours et les horaires configurés.
* Si certaines ne peuvent pas être créées par manque de disponibilité, vérifiez les ressources marquées en rouge et changez la sélection.
{% endstep %}
{% endstepper %}

Une fois enregistrée, vous verrez toutes les réservations dans le calendrier et vous pourrez les consulter et les gérer quand vous en aurez besoin.
