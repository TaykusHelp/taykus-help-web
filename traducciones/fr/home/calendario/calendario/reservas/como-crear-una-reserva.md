# Comment créer une réservation

Les réservations se créent directement depuis le calendrier : vous choisissez le terrain et l'heure, le type de réservation, vous complétez les informations et vous enregistrez.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

<figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choix du terrain, de l'heure et du type de réservation

* Cliquez sur le terrain et l'heure où vous voulez faire la réservation.
* Une fenêtre s'ouvre pour choisir le type de réservation.\
  ![](<../../.gitbook/assets/image (66).png>)
* Cliquez sur le type de réservation dont vous avez besoin.
{% endstep %}

{% step %}
### Informations de la réservation

* La fiche de la réservation s'ouvre :

<figure><img src="../../.gitbook/assets/image (67).png" alt=""><figcaption></figcaption></figure>

* **Player :** recherchez le titulaire de la réservation. C'est facultatif.
* **Terrain :** il est déjà sélectionné, mais vous pouvez le changer ici si vous vous êtes trompé.
* **Durée :** choisissez à droite l'une des durées configurées.
* **Observations et commentaires :** pour laisser une note sur la réservation.
* **Envoyer des communications :** cochée par défaut, elle prévient les participants de toute modification.
{% endstep %}

{% step %}
### Enregistrer la réservation

Choisissez comment vous voulez l'enregistrer :

* **Sauvegarder & Payer :** enregistre la réservation et vous emmène directement au point de vente pour l'encaisser.
* **Sauvegarder & Nouveau :** enregistre la réservation et en ouvre une nouvelle à l'heure disponible suivante.
* **Sauvegarder** <i class="fa-floppy-disk" style="color:blue;">:floppy-disk:</i> : enregistre la réservation et vous revenez au calendrier.
{% endstep %}
{% endstepper %}

La réservation apparaît dans le calendrier sur le terrain et à l'heure que vous avez choisis.\
![](<../../.gitbook/assets/image (100).png>)
