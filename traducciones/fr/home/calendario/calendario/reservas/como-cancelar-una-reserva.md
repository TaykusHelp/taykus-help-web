# Comment annuler une réservation

Il faut parfois annuler une réservation à cause de la météo, de l'entretien des terrains ou parce que les joueurs ne peuvent pas venir. En l'annulant, vous pouvez choisir de supprimer aussi la dette ou de la conserver.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier <a href="#acceso-a-calendario" id="acceso-a-calendario"></a>

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

<figure><img src="../../.gitbook/assets/image (71).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choix de la réservation

* Cliquez sur la réservation que vous voulez annuler.
* Un menu avec plusieurs options s'ouvre.
* Passez la souris sur l'icône d'annulation.

<figure><img src="../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Type d'annulation

* Deux options apparaissent :
  * **Annuler la réservation et les dettes :** supprime la réservation et aussi la dette.
  * **Annuler la réservation en maintenant les dettes :** supprime la réservation mais conserve le paiement du terrain en attente. C'est utile quand un joueur annule hors délai et que vous voulez libérer le terrain sans perdre la dette.
* Cliquez sur l'option dont vous avez besoin.
* Un message de confirmation apparaît selon l'option choisie.
{% endstep %}

{% step %}
### Confirmation

<div align="left"><figure><img src="../../.gitbook/assets/image (75).png" alt=""><figcaption></figcaption></figure></div>

<div align="left"><figure><img src="../../.gitbook/assets/image (76).png" alt=""><figcaption></figcaption></figure></div>

* Si vous l'avez configuré, vous pouvez indiquer le **motif de l'annulation**. C'est facultatif, mais cela vous aide à suivre les causes les plus fréquentes.
* Cliquez sur **OK** pour confirmer. La réservation est annulée.
{% endstep %}
{% endstepper %}
