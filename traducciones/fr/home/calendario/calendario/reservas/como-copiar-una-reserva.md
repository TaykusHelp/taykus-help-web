# Comment copier une réservation

Copier une réservation vous permet de la répéter un autre jour, sur un autre terrain ou à une autre heure sans devoir la créer de zéro.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.<br>

    <figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Copier la réservation

* Cliquez sur la réservation que vous voulez copier.
*   Dans le menu qui s'ouvre, sélectionnez **Copie**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Coller la copie

* La fenêtre se ferme.
* Cliquez sur le jour, le terrain et l'heure où vous voulez créer la copie.
{% endstep %}
{% endstepper %}

> **Important :** avant de confirmer, vérifiez la date, le terrain et les joueurs de la nouvelle réservation pour éviter les erreurs dans le calendrier.
