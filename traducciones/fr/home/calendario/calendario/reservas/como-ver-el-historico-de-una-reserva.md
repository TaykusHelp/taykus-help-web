# Comment voir l'historique d'une réservation

L'historique d'une réservation montre tout ce qui s'est passé et qui l'a fait : qui l'a créée, qui l'a modifiée, qui s'est inscrit, qui est sorti ou a été retiré et qui l'a annulée.

> Les paiements de la réservation n'apparaissent pas dans l'historique.

Vous pouvez accéder à l'historique depuis le calendrier ou depuis la liste des réservations.

## Depuis le calendrier

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir la réservation

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
* Cliquez sur la réservation.
*   Dans le menu de droite, cliquez sur **Détails**.

    <figure><img src="../../.gitbook/assets/partido-detalles.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Voir l'historique

*   Ouvrez l'onglet **Histoire**.

    <figure><img src="../../.gitbook/assets/reserva-historico.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

## Depuis la liste des réservations

Cette méthode fonctionne aussi pour les réservations annulées, qui n'apparaissent plus dans le calendrier.

{% stepper %}
{% step %}
### Trouver la réservation

* Allez dans le menu latéral gauche, sélectionnez **Calendrier** puis, dans le menu déroulant, choisissez **Réservations**.
* Trouvez la réservation dans la liste. Vous pouvez utiliser les filtres de chaque colonne.
{% endstep %}

{% step %}
### Voir l'historique

* Cliquez sur l'**ID** de la réservation.
* Ouvrez l'onglet **Histoire**.
{% endstep %}
{% endstepper %}

Pour voir seulement les réservations annulées, consultez [Comment voir les réservations annulées](como-ver-las-reservas-canceladas.md).
