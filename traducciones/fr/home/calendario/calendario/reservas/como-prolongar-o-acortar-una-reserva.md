# Comment prolonger ou raccourcir une réservation

Vous pouvez changer la durée d'une réservation directement dans le calendrier, pour allonger ou réduire le temps de jeu ou pour bloquer un terrain plus ou moins longtemps.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.<br>

    <figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Changer la durée

* Cliquez sur la réservation et placez-vous sur le bord supérieur (pour changer l'heure de début) ou sur le bord inférieur (pour changer l'heure de fin).
*   Une double flèche apparaît, comme sur l'image. Maintenez le bouton enfoncé et faites glisser vers le haut ou vers le bas jusqu'à la nouvelle durée.<br>

    <figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirmer le changement

*   Quand vous relâchez, une fenêtre de confirmation s'ouvre :

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>

    * **Prix de mise à jour :** recommandé. Ajuste le montant à la nouvelle durée ou au nouveau créneau horaire.
    * **Notifier les participants :** envoie un e-mail aux joueurs pour les prévenir du changement.
* Cliquez sur **OK** pour enregistrer les modifications.
{% endstep %}
{% endstepper %}

> **Important :** vérifiez la nouvelle heure de début et de fin avant de confirmer pour éviter les chevauchements avec d'autres réservations.
