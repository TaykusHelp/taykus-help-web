# Comment voir les réservations annulées

Les réservations annulées n'apparaissent plus dans le calendrier, mais vous pouvez les voir dans la liste des réservations en filtrant par statut.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès aux Réservations

* Allez dans le menu latéral gauche et sélectionnez **Calendrier**.
* Dans le menu déroulant, choisissez **Réservations**. La liste **Ressources réservées** s'ouvre.
{% endstep %}

{% step %}
### Filtrer les annulées

* Faites défiler vers la droite jusqu'à la colonne **Statut**.
*   Dans le filtre de cette colonne, choisissez **Annulé**.

    <figure><img src="../../.gitbook/assets/reservas-canceladas.png" alt=""><figcaption></figcaption></figure>
* La liste n'affiche que les réservations annulées.
{% endstep %}
{% endstepper %}

Pour savoir qui a annulé une réservation, cliquez sur son **ID** et ouvrez l'onglet **Histoire**. Consultez [Comment voir l'historique d'une réservation](como-ver-el-historico-de-una-reserva.md).

Pour ne pas avoir à mettre le filtre à chaque fois, vous pouvez enregistrer la liste en favori. Consultez [Comment enregistrer une liste en favori](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/listados/como-guardar-un-listado-como-favorito).
