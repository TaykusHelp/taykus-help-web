# Comment encaisser une réservation

Encaisser les réservations depuis le calendrier enregistre chaque paiement dans le système et évite les écarts de caisse.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.<br>

    <figure><img src="../../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Choix de la réservation

* Cliquez sur la réservation que vous voulez encaisser.
* Sélectionnez le ou les joueurs qui vont payer.
*   Dans le menu qui s'ouvre, choisissez **Payer Réservation**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (84).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Encaissement au point de vente

* Le système vous emmène automatiquement au point de vente.
* Sélectionnez le mode de paiement : espèces, carte ou bon monétaire (si le joueur en a un).

<figure><img src="../../.gitbook/assets/image (102).png" alt=""><figcaption></figcaption></figure>

*   Une fois l'encaissement terminé, le ticket passe à l'état **Payé**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (86).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

> **Important :** vérifiez le montant et le mode de paiement avant de terminer l'encaissement pour que la caisse soit juste à la clôture de la journée.
