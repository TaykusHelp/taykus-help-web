# Comment déplacer une réservation

Vous pouvez changer le terrain, l'heure ou le jour d'une réservation pour un tournoi, un événement, de l'entretien ou à la demande des joueurs. Il y a deux façons de le faire : en la faisant glisser ou depuis son menu.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Accès au Calendrier

*   Allez dans le menu latéral gauche et sélectionnez **Calendrier**.<br>

    <figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1 : déplacer la réservation en la faisant glisser

* Cliquez sur la réservation et maintenez le bouton enfoncé.
*   Faites-la glisser jusqu'au nouveau terrain ou à la nouvelle heure.<br>

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 2 : déplacer la réservation depuis le menu

* Cliquez sur la réservation.
*   Dans le menu qui s'ouvre à droite, sélectionnez :scissors: **Déplacer**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure></div>
* Le menu se ferme. Cliquez sur la nouvelle date (si vous changez de jour), la nouvelle heure ou le nouveau terrain.
*   Une fenêtre de confirmation s'ouvre :<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>

    * **Prix de mise à jour :** recommandé. Ajuste le montant si le nouveau créneau a un autre prix.
    * **Notifier les participants :** prévient les joueurs du changement.
* Cliquez sur **OK** pour confirmer.
{% endstep %}
{% endstepper %}

> **Important :** avant de confirmer, vérifiez la date, le terrain et le prix pour vous assurer que le changement est correct.
