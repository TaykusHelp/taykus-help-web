# Comment partager une réservation

Vous pouvez partager n'importe quelle réservation avec les joueurs, par exemple sur WhatsApp, pour qu'ils aient sous la main toutes les informations et le lien direct.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Ouvrir les options de partage

* Cliquez sur la réservation.
* Allez dans le menu de droite.
*   Vous verrez deux façons de la partager, selon ce dont vous avez besoin.

    <figure><img src="../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Option 1 : Partager (message prêt à envoyer)

En cliquant sur **Partager**, le système crée un message mis en forme qui contient :

* Le nom du club
* Le niveau du match
* La date et la durée
* Le lieu
* L'état des places
* Le lien direct d'inscription

<div align="left"><figure><img src="../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure></div>

C'est la meilleure option pour l'envoyer sur WhatsApp, car elle présente toutes les informations clairement.
{% endstep %}

{% step %}
### Option 2 : Copier le lien

En cliquant sur **Copier le lien**, le système copie seulement le lien direct vers la réservation.

C'est utile si :

* Vous voulez écrire votre propre message.
* Vous allez l'inclure dans une campagne ou une newsletter.
* Vous n'avez besoin que du lien.
{% endstep %}
{% endstepper %}
