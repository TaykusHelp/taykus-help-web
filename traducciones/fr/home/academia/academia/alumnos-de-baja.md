# Élèves inactifs

La section **Élèves inactifs** affiche dans une seule liste tous les clients qui ne sont plus actifs à l'académie. En plus de consulter leur historique sans vérifier groupe par groupe, elle permet de repérer facilement ceux qui pourraient revenir ou recevoir une promotion. C'est un outil rapide pour récupérer des élèves et garder le contact.

Pour accéder à cette section, il suffit de suivre ces étapes :

{% stepper %}
{% step %}
### Accès à Académie

* Allez dans le menu de gauche et cliquez sur Académie.
{% endstep %}

{% step %}
### Accès à Élèves inactifs

* Dans le menu déroulant qui s'ouvre, cliquez sur **Élèves inactifs.**\
  ![](<../.gitbook/assets/image (20).png>)
* Une fois dedans, vous pouvez voir toutes les informations dans une seule liste de tous les élèves.
{% endstep %}
{% endstepper %}
