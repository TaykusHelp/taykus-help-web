# Comment se connecter à Taykus Coach

Pour vous connecter à Taykus Coach, vous avez besoin des identifiants fournis par votre club : ce sont les mêmes que pour l'adresse web des professeurs. Si vous enseignez dans plusieurs clubs, ajoutez chacun avec ses propres identifiants.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Télécharger l'application

* Téléchargez **Taykus Coach** sur l'[App Store](https://apps.apple.com/es/app/taykus-coach/id6804599678) (iPhone et iPad) ou sur [Google Play](https://play.google.com/store/apps/details?id=com.taykus.coach) (Android).
{% endstep %}

{% step %}
### Saisir les identifiants

* **Club :** le nom de votre club.
* **Utilisateur :** votre e-mail.
* **Mot de passe :** celui que vous a donné le club.
*   Cliquez sur **Se connecter**.

    <div align="left"><figure><img src="../../.gitbook/assets/taykus-coach-entrar.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Ajouter un autre club

* En bas, cliquez sur **Compte**.
* Dans **Mes clubs**, cliquez sur **Ajouter un nouveau club**.
* Saisissez les identifiants de ce club et cliquez sur **Se connecter**.
*   Pour retirer un club de l'application, cliquez sur l'icône de corbeille à côté.

    <div align="left"><figure><img src="../../.gitbook/assets/taykus-coach-cuenta.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

> **Important :** si vous ne pouvez pas vous connecter, demandez au club de vérifier que votre utilisateur et votre ressource de professeur sont créés et reliés dans Paramètres › Académies.
