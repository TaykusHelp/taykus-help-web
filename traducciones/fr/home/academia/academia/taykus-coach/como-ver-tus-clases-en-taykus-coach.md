# Comment voir vos cours dans Taykus Coach

En vous connectant à Taykus Coach, vous voyez votre calendrier avec les cours de tous vos clubs. Vous pouvez l'afficher sous forme de liste (Agenda) ou de mois complet (Mois), comme dans le calendrier du téléphone.

Voici les étapes à suivre :

{% stepper %}
{% step %}
### Vue Agenda

* En bas, cliquez sur **Accueil**.
* En haut, sélectionnez **Agenda**.
*   Vous verrez vos cours classés par jour, avec le nom du cours, l'horaire et le terrain.

    <div align="left"><figure><img src="../../.gitbook/assets/taykus-coach-agenda.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Vue Mois

* Sélectionnez **Mois**.
* Chaque jour indique combien de cours vous avez, avec un point de la couleur du club.
*   Cliquez sur un jour pour voir ses cours.

    <div align="left"><figure><img src="../../.gitbook/assets/taykus-coach-mes.png" alt="" width="300"><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Changer de mois et actualiser

* Utilisez les flèches **‹** et **›** pour aller au mois précédent ou suivant, ou cliquez sur le mois pour le choisir.
* Cliquez sur l'icône d'actualisation (la flèche circulaire) pour charger les derniers changements du club.
{% endstep %}

{% step %}
### Choisir les clubs à afficher

* Sous Agenda et Mois, chaque club a son bouton avec sa couleur.
* Cliquez sur un club pour le sélectionner ou le retirer. Vous verrez les cours des clubs sélectionnés.
{% endstep %}
{% endstepper %}
