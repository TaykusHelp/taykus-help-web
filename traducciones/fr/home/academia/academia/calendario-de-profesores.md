# Calendrier des professeurs

Le calendrier des professeurs affiche l'agenda mensuel de chaque moniteur. Vous pouvez y voir d'un coup d'œil tous ses cours, réservations et horaires attribués. De plus, le système calcule les heures totales travaillées et la moyenne mensuelle, ce qui aide à contrôler les charges de travail et à mieux organiser la planification de l'équipe.

Pour voir ces données, il faut suivre ces étapes :

{% stepper %}
{% step %}
### Accès à Académie

* Allez dans le menu de gauche et cliquez sur Académie.
{% endstep %}

{% step %}
### Accès à Calendrier des professeurs

*   Dans le menu déroulant, sélectionnez **Calendrier des professeurs.**<br>

    <figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Sélection des professeurs

*   Cliquez dans le cadre central, où il est écrit **Sélectionner les ressources.**<br>

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
* Sélectionnez le nom du ou des professeurs que vous voulez afficher. Vous pouvez en sélectionner plusieurs.
{% endstep %}

{% step %}
### Choix de la vue du calendrier

*   La vue par défaut est la vue **hebdomadaire**.

    <figure><img src="../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
*   Mais la vue **mensuelle** est aussi disponible :

    <figure><img src="../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>
*   Ainsi que le mode **agenda :**

    <figure><img src="../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Indicateurs du calendrier des professeurs

Le calendrier affiche différents indicateurs selon **la vue sélectionnée** (journalière, hebdomadaire ou mensuelle) et **le nombre de professeurs** choisis dans le filtre.

Quand vous sélectionnez un ou plusieurs professeurs, le système calcule automatiquement :

* **Taux d'occupation**
* **Nombre total d'heures attribuées**
* **Participants au total**
* **Heures moyennes par ressource (professeur)**

Les informations s'adaptent toujours au contexte de la vue :

* **Vue journalière** → indicateurs du jour sélectionné.
* **Vue hebdomadaire** → indicateurs de cette semaine.
* **Vue mensuelle** → résumé du mois complet.

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

Si vous sélectionnez **un seul professeur**, les indicateurs ne concerneront que lui. Si vous en sélectionnez **plusieurs**, le système fera le calcul global du groupe filtré.\
<br>
