# Calendrier des élèves

Dans cet article, nous vous expliquons pas à pas comment configurer les autorisations pour que chaque professeur ne voie que son propre calendrier avec les élèves qui lui sont attribués. Cette fonction offre une expérience plus claire, plus sûre et plus personnalisée dans notre logiciel de gestion sportive. En limitant la visibilité aux seuls groupes et horaires correspondants, on évite la surcharge d'informations, on protège la confidentialité des données et on améliore nettement l'organisation interne de l'équipe enseignante.

Pour cela, il faut suivre ces étapes :

{% stepper %}
{% step %}
### Création de la ressource

* Pour savoir comment créer une ressource, consultez le lien suivant :\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/reservas/grupo-de-recursos/como-crear-un-recurso" class="button primary" data-icon="tennis-ball">Comment créer une ressource</a>
{% endstep %}

{% step %}
### Création de l'utilisateur

* Pour savoir comment créer un utilisateur, consultez le lien suivant :\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/usuarios/como-crear-un-usuario" class="button primary" data-icon="user-plus">Comment créer un utilisateur</a>
{% endstep %}

{% step %}
### Indiquer quels utilisateurs sont entraîneurs

* Pour savoir comment indiquer qu'un utilisateur est entraîneur, consultez le lien suivant :\
  <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/academia/como-especificar-que-usuarios-son-entrenadores" class="button primary" data-icon="medal">Comment indiquer quels utilisateurs sont entraîneurs</a>
{% endstep %}
{% endstepper %}

Une fois toutes ces étapes réalisées, nous remettrons au professeur l'URL d'accès suivante, avec laquelle il ne pourra voir que ses cours et faire l'appel de ses élèves :

<mark style="background-color:yellow;">**Nomduclub**</mark>_.taykus.com/teachers/login_

<sub>_**\* Indiquer le nom du club**_</sub>

Voici la vue qu'aura le professeur depuis son utilisateur, où il pourra noter la présence des élèves, voir les jours, heures, terrain, etc.<br>
