# Prix par jour

Les **prix par jour** permettent, dans un même cours, que chaque client choisisse combien de jours par semaine il veut venir. Si le groupe s'entraîne du lundi au vendredi, l'élève peut s'inscrire à un seul jour, deux, trois… ou les cinq. C'est flexible pour le client et pratique pour le club, car le prix s'adapte à la fréquentation réelle de chacun.

Il est important de suivre un ordre lors de la création du groupe. Si vous allez utiliser les **prix par jour**, ils doivent être ajoutés en premier, avant de créer les entraînements et avant d'ajouter les clients. Cela évite les erreurs, garantit que chaque élève voie le bon prix selon les jours choisis et garde toute la configuration du cours cohérente dès le départ.

Pour créer les prix par jour, il faut suivre ces étapes :

{% stepper %}
{% step %}
### Accès au module Académie

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Accès aux prix par jour du groupe

* Si le groupe n'est pas encore créé, consultez le lien suivant pour savoir comment le créer :\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Comment créer un groupe de l'académie</a>
* Si le groupe est déjà créé, cliquez sur son id pour l'ouvrir.
*   Allez dans la section **Prix par jour**.<br>

    <figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer les prix par jour

* Cliquez sur :heavy\_plus\_sign:.
*   Le panneau suivant s'ouvre, à remplir ainsi :

    <figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>

    * **Nombre de jours :** indiquez le nombre de jours auquel attribuer un prix.
    * **Produit :** fixe le prix pour ce nombre de jours. Le produit doit être de catégorie **Periodic sale** (cotisation).
      * _Pour créer des produits de type Cotisation, consultez l'article suivant :_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota" class="button primary" data-icon="box">Comment créer un produit de type Cotisation</a>
    * Cliquez sur Sauvegarder.
{% endstep %}
{% endstepper %}

Il faut créer un produit pour chaque option proposée. Si l'on peut venir un, deux, trois ou quatre jours, il faudra créer le produit de 1 jour, celui de 2 jours, celui de 3 jours et celui de 4 jours, chacun avec son prix. L'élève peut ainsi choisir exactement combien de jours il veut venir.
