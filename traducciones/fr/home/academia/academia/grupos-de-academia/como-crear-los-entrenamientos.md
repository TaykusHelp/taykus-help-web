# Comment créer les entraînements

Les **entraînements** sont les séances hebdomadaires du cours : le jour, l'heure et le terrain où s'entraîne chaque groupe et, si vous le souhaitez, le professeur. En les créant, on peut **relier les réservations au groupe de l'académie**, pour que toutes les présences et places restent liées au cours et non comme des réservations isolées.

Si vous allez utiliser les **prix par jour**, il est indispensable de les créer **avant** d'ajouter les entraînements. C'est la seule façon pour que le système attribue correctement les jours que chaque élève peut choisir et le prix correspondant. Ensuite, vous pouvez configurer les entraînements et laisser le groupe prêt à fonctionner.

* _Pour créer les prix par jour, consultez l'article suivant :_\
  <a href="precios-por-dias.md" class="button primary" data-icon="medal">Prix par jour</a>

Pour créer les entraînements, il faut suivre ces étapes simples :

{% stepper %}
{% step %}
### Accès au module Académie

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Accès aux entraînements du groupe

* Si le groupe n'est pas encore créé, consultez le lien suivant pour savoir comment le créer :\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Comment créer un groupe de l'académie</a>
* Si le groupe est déjà créé, cliquez sur son id pour l'ouvrir.
*   Allez dans la section **Formations**.

    <figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer les entraînements

*   Cliquez sur Calendrier.

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
* Le calendrier du club s'ouvre, mais à l'intérieur du module Académie.
* Faites une **réservation multiple** comme d'habitude, mais il est important de la faire **depuis le module Académie**. C'est la seule façon pour que la réservation soit liée au groupe et que, lors de l'ajout des élèves, le système les amène automatiquement à leurs entraînements. Tout reste ordonné et dans le même cours.
  * _Pour faire une réservation multiple, consultez l'article suivant :_\
    <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/reservar-multiples/como-crear-una-reserva-multiple" class="button primary" data-icon="clock">Comment créer une réservation multiple</a>
* Une fois la réservation multiple créée, les entraînements sont automatiquement attribués à ce groupe. À partir de là, tout le cours fonctionne avec cette configuration.
{% endstep %}
{% endstepper %}
