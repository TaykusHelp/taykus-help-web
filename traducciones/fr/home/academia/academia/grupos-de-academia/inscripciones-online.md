# Inscriptions en ligne

Les inscriptions en ligne permettent à l'élève de s'inscrire au cours de l'académie rapidement et en toute sécurité. Elles évitent la paperasse, réduisent les erreurs et mettent à jour les places en temps réel. Le club gagne en organisation ; l'élève, en confort. Tout le processus d'inscription se fait en une seule étape.

Pour les activer, il suffit de suivre ces étapes simples :

{% stepper %}
{% step %}
### Accès au module Académie :

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Modifier ou créer le groupe de l'académie

* Si le groupe n'est pas encore créé, consultez le lien suivant pour savoir comment le créer :\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Comment créer un groupe de l'académie</a>
* Si le groupe est déjà créé, cliquez sur son id pour l'ouvrir.
*   Une fois dedans, cliquez sur <i class="fa-pen" style="color:purple;">:pen:</i> pour le modifier.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Activer les inscriptions en ligne

* Faites défiler jusqu'à la section **Inscriptions**.
*   Pour activer les inscriptions, remplissez cette section ainsi :<br>

    <figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

    * **Afficher en ligne :** cette case fait seulement apparaître le cours sur le site. Rien de plus. Elle n'active pas les inscriptions et ne change pas leur gestion.&#x20;
    * **Jours d'anticipation pour l'affichage en ligne :** indiquent combien de jours avant le cours doit être visible en ligne. Ils ne contrôlent que la **date de visibilité.**
    * **Autoriser l'inscription en ligne :** permet aux élèves de s'inscrire au cours depuis le site. Sans cette option, le cours est seulement affiché, mais n'accepte pas d'inscriptions.
    * **Date de début des inscriptions :** date à partir de laquelle l'élève peut s'inscrire au cours.
    * **Date de fin des inscriptions :** date limite jusqu'à laquelle l'élève peut s'inscrire.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur Sauvegarder pour enregistrer les changements.
{% endstep %}
{% endstepper %}
