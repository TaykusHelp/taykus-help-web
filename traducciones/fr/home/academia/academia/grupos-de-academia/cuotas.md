# Cotisations

La section **ventes périodiques** vous permet de suivre de façon visuelle et ordonnée tout ce qui concerne les paiements de votre groupe de l'académie. Vous pouvez y voir quelles cotisations sont émises, qui a payé, qui est encore en attente et si leurs montants ont été modifiés. C'est le moyen le plus rapide de vérifier la situation financière du groupe sans vous perdre dans des vérifications manuelles.

Pour y accéder et travailler, il faut suivre ces étapes :

{% stepper %}
{% step %}
### Accès au module Académie

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Accès aux cotisations du groupe

* Cliquez sur l'id du groupe voulu.
*   Allez dans la section **ventes périodiques.**<br>

    <figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
* Cette section affiche tous les types de cotisation activés dans ce groupe.
  * S'il n'y en a qu'un, il apparaîtra dans une seule liste ; si l'option _Prix par jour_ est activée, ils seront séparés comme sur l'image.
{% endstep %}
{% endstepper %}

Pour savoir comment les gérer, consultez cet article :
