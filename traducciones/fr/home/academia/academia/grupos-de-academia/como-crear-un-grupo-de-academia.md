# Comment créer un groupe de l'académie

Dans cet article, nous vous expliquons pas à pas comment créer des groupes d'école dans notre logiciel de gestion sportive. Grâce à un processus intuitif et efficace, vous pourrez organiser les participants au mieux, selon des critères précis qui améliorent l'expérience des utilisateurs et facilitent la gestion des activités.

Lors de la création d'un groupe de l'académie, il est important de suivre les étapes dans l'ordre.

{% stepper %}
{% step %}
### Accès au module Académie :

* Allez dans le menu latéral gauche et sélectionnez Académie.
* La section où sont gérés tous les groupes d'école créés désormais s'ouvre.
{% endstep %}

{% step %}
### Création du nouveau groupe de l'académie

* Cliquez sur :heavy\_plus\_sign: pour créer un nouveau groupe.
*   Un formulaire s'ouvre, à remplir ainsi :<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>



    *   **General data :**

        * **Nom :** indiquez le nom du groupe. Nous vous conseillons une structure claire comme :\
          `Nom du groupe – Catégorie (âge ou niveau) – Jours – Horaire`.
        * **Logo :** si l'école a un logo, vous pouvez l'ajouter ici.
        * **Saison :** indiquez la période de durée du cours.
        * **Fin :** date de fin du cours/de l'école/de l'académie.
        * **Détails :** espace pour ajouter une description supplémentaire.
        * **Produit :** sélectionnez un produit **de catégorie Periodic sale (cotisation)** créé au préalable. C'est le prix qui sera attribué à ce cours.
          * _Pour créer des produits de type Cotisation, consultez l'article suivant :_ \
            <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota" class="button primary" data-icon="box">Comment créer un produit de type Cotisation</a>
        * **Nombre maximum de participants :** définissez le nombre maximum de personnes pouvant en faire partie.
        * **Min. Niveau :** indiquez le niveau minimum de ce groupe.
        * **Max. Niveau :** indiquez le niveau maximum de ce groupe.

        _<mark style="background-color:yellow;">(Avec ces données, notre groupe de l'académie est déjà créé)</mark>_
    * Cliquez sur Sauvegarder pour enregistrer les changements.


{% endstep %}
{% endstepper %}
