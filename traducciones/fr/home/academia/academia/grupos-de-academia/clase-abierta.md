# Cours ouvert

Proposer un cours ouvert sert à combler les places libres d'un groupe quand il manque un élève. Le club complète le cours, et les utilisateurs peuvent s'inscrire rapidement depuis le site. Cela évite de perdre des heures de terrain et des revenus, et garde les groupes toujours actifs.

Il suffit de suivre ces étapes simples :

{% stepper %}
{% step %}
### Accès au module Académie

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Modifier ou créer le groupe

* Si le groupe n'est pas encore créé, consultez le lien suivant pour savoir comment le créer :\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Comment créer un groupe de l'académie</a>
* Si le groupe est déjà créé, cliquez sur son id pour l'ouvrir.
*   Une fois dedans, cliquez sur <i class="fa-pen" style="color:purple;">:pen:</i> pour le modifier.<br>

    <figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Activer le cours ouvert

* Faites défiler jusqu'à la section **Cours ouvert**.
*   Pour activer l'offre de cours à l'unité en ligne, remplissez cette section ainsi :<br>

    <figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

    * **Produit du cours ouvert :** fixe le prix d'une réservation de cours ouvert. Le produit doit être de catégorie **Service**.
      * _Pour créer des produits de type Service, consultez l'article suivant :_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-servicio" class="button primary" data-icon="box">Comment créer un produit de type Service</a>
    * **Autoriser l'inscription en ligne au cours ouvert :** permet aux clients de s'inscrire au cours proposé depuis le site.
    * **Jours d'anticipation pour l'inscription en ligne au cours ouvert :** indiquent combien de jours avant le cours proposé doit apparaître en ligne et permettre l'inscription.
{% endstep %}

{% step %}
### Enregistrer

* Cliquez sur Sauvegarder pour enregistrer les changements.


{% endstep %}
{% endstepper %}
