# Comment ajouter des élèves

Ajouter des élèves est l'étape où chaque client est inscrit officiellement à un cours de l'académie. On décide ici qui fait partie du groupe, et le système les relie à leurs entraînements et au type d'inscription correspondant. C'est le processus qui transforme la configuration du cours en un vrai groupe, avec ses participants déjà enregistrés et prêts à commencer.

Si vous allez utiliser les **prix par jour**, il est indispensable de les créer **avant** d'ajouter les élèves. C'est la seule façon pour que le système attribue correctement les jours que chaque élève peut choisir et le prix correspondant. Ensuite, vous pouvez configurer les élèves et laisser le groupe prêt à fonctionner.

* _Pour créer les prix par jour, consultez l'article suivant :_\
  <a href="precios-por-dias.md" class="button primary" data-icon="medal">Prix par jour</a>

Pour que les élèves soient bien attribués au groupe, les entraînements doivent être créés à l'avance. En suivant cet ordre, le système pourra les relier correctement à leurs séances et le cours sera organisé dès le départ.

* _Pour créer les entraînements, consultez l'article suivant :_\
  <a href="como-crear-los-entrenamientos.md" class="button primary" data-icon="medal">Comment créer les entraînements</a>

Pour ajouter des élèves, il faut suivre ces étapes :

{% stepper %}
{% step %}
### Accès au module Académie

* Allez dans le menu latéral gauche et sélectionnez Académie.
{% endstep %}

{% step %}
### Accès aux élèves du groupe

* Si le groupe n'est pas encore créé, consultez le lien suivant pour savoir comment le créer :\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Comment créer un groupe de l'académie</a>
* Si le groupe est déjà créé, cliquez sur son id pour l'ouvrir.
*   Allez dans la section **Étudiants**.

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Ajouter des élèves

* Cliquez sur :heavy\_plus\_sign:
*   Le panneau suivant s'ouvre, à remplir ainsi :<br>

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

    * **Acheteur :** cherchez le nom de l'élève ou des élèves à ajouter. S'ils ont les mêmes jours, vous pouvez en ajouter plusieurs à la fois.
    * **Début :** sélectionnez la date à laquelle l'élève ou les élèves commenceront le cours.
    * **Fin :** sélectionnez la date à laquelle le ou les élèves terminent le cours. Cette date pourra être modifiée plus tard si l'élève demande à arrêter avant la fin du cours.
    * **Observations&#x20;**_**(Facultatif)**_**:** espace pour écrire un détail ou laisser une note.
    * **Jours :** cochez le ou les jours où l'élève suivra le cours. Les jours de présence de chaque élève sont ainsi ajoutés automatiquement à la réservation.
* Cliquez sur Sauvegarder pour ajouter les élèves au groupe.
{% endstep %}
{% endstepper %}
