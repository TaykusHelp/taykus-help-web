# Personnaliser le formulaire d'inscription

La section **Personnaliser l'inscription** permet de configurer les champs que les élèves devront remplir lors d'une **préinscription à l'école ou à l'académie**.

Le club peut ainsi recueillir des informations supplémentaires sur les élèves avant de les attribuer à un groupe ou à un niveau.

{% stepper %}
{% step %}
### Accéder à la section Personnaliser l'inscription

* Allez dans le menu de gauche et cliquez sur **Académie**.
* Dans le menu déroulant, sélectionnez **Préinscriptions**.
* Sélectionnez la **préinscription** à gérer.
* En haut, cliquez sur l'onglet **Personnaliser l'inscription**.

![](<../../.gitbook/assets/image (3)>)
{% endstep %}

{% step %}
### Ajouter des champs au formulaire

En haut, vous trouverez différents **champs prédéfinis** utilisables dans le formulaire.

Pour ajouter l'un de ces champs :

* Sélectionnez le champ à utiliser.
* **Faites-le glisser vers le bas du formulaire.**
* Déposez-le dans la **Colonne de gauche** ou la **Colonne de droite** selon l'organisation voulue.

Le formulaire peut ainsi être structuré en **une ou deux colonnes**, pour une lecture plus facile.

![](<../../.gitbook/assets/image (4)>)
{% endstep %}

{% step %}
### Définir si un champ est obligatoire

Une fois le champ ajouté au formulaire, une **case apparaît à côté**.

* Si vous cochez cette case, le champ devient **Obligatoire** : l'utilisateur devra le remplir pour terminer l'inscription.
* Si la case n'est pas cochée, le champ sera **facultatif**.

![](<../../.gitbook/assets/image (5)>)
{% endstep %}

{% step %}
### Créer de nouveaux champs personnalisés

En plus des champs prédéfinis, il est possible de créer de nouveaux champs.

Pour cela :

* Cliquez sur **Ajouter nouveau**.
* La fenêtre **Ajouter un domaine du formulaire dynamique** s'ouvre.

Vous devrez remplir les champs suivants :

**Étiquette :** nom du champ que l'utilisateur verra dans le formulaire.\
**Type de champ :** définit le type de réponse que l'utilisateur pourra saisir.

Parmi les options disponibles :

![](<../../.gitbook/assets/image (6)>)

* Texte
* Oui/Non
* Liste
* Nombre
* Zone de texte
* Date
* E-mail
* Téléversement de fichier
* Sélection multiple

Vous pouvez aussi configurer, de façon facultative :

* **Options :** valeurs disponibles quand le champ est de type liste ou sélection.
* **Valeur par défaut :** valeur qui apparaîtra déjà sélectionnée dans le formulaire.

Une fois le champ configuré, cliquez sur **Sauvegarder** pour l'ajouter au formulaire.

Une fois les champs du formulaire configurés, les utilisateurs devront remplir ces informations lors de l'inscription. Toutes les données recueillies resteront associées à chaque participant et pourront être consultées ensuite depuis la section **Participants**.
{% endstep %}
{% endstepper %}

En personnalisant le formulaire de préinscription, le club peut recueillir des informations supplémentaires sur les élèves et mieux organiser les demandes avant de les attribuer aux différents groupes de l'école.
