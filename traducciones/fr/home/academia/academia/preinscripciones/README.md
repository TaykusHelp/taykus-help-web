# Préinscriptions

{% tabs %}
{% tab title="Activité" %}
## Comment créer une préinscription

Les préinscriptions permettent de recueillir l'intérêt de nouveaux élèves avant de les attribuer à un groupe ou à un professeur, pour une gestion ordonnée de la demande. Ce module aide le club à planifier les places, les horaires et les niveaux à l'avance, en évitant la saturation et en gardant les informations structurées dès le départ. Grâce à cette étape préalable, il est plus simple d'examiner les demandes et de confirmer les inscriptions de façon rapide et maîtrisée.

Dans cet article, nous vous montrons comment les configurer.

{% stepper %}
{% step %}
### Accès aux préinscriptions

* Allez dans le menu de gauche et cliquez sur Académie.
*   Dans le menu déroulant, sélectionnez **Préinscriptions.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer une préinscription

* Cliquez sur :heavy\_plus\_sign:
*   Une fenêtre s'ouvre, à remplir ainsi :

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

    * **Nom :** indiquez le titre de la préinscription au groupe de l'académie.
    * **Affiche :** en cliquant sur « parcourir », vous pouvez choisir une image à afficher sur le site.
    * **Description :** espace pour ajouter une explication supplémentaire.
    * **Sport :** un menu déroulant s'ouvre pour choisir le sport.
    * **Produit :** sélectionnez un produit **de catégorie Article** créé au préalable. C'est le prix qui sera attribué à ce cours.
      * _Pour créer des produits de type Article, consultez l'article suivant :_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-articulo" class="button primary" data-icon="box">Comment créer un produit de type Article</a>
    * **Commentaires des clients :** espace pour ajouter une note interne.
    * **Participants :** nombre maximum de personnes pouvant s'inscrire.
    * **Début :** date de début du cours/de l'école/de l'académie.
    * **Fin :** date de fin du cours/de l'école/de l'académie.
    * **Inscription du :** date de début des inscriptions.
    * **Inscription jusqu'au :** date de fin des inscriptions.
    * **Nombre maximum de participants :** sert à la même chose que **Participants**.
    * **En ligne :** cette case fait seulement apparaître le cours sur le site. Rien de plus. Elle n'active pas les inscriptions et ne change pas leur gestion.
    * **Inscription en ligne :** permet aux utilisateurs d'accéder à la préinscription depuis le site. Sans cette option, le cours est seulement affiché, mais n'accepte pas d'inscriptions.
* Cliquez sur Sauvegarder pour enregistrer les changements.
{% endstep %}

{% step %}
### Configuration de la préinscription

Une fois la préinscription créée et enregistrée, de nouvelles sections s'activent pour compléter sa configuration et gérer les demandes des élèves.

En haut apparaissent les onglets suivants :<br>

<figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

* **Activité :** permet de revoir ou de modifier les informations générales de la préinscription créée.
* **Participants :** permet de voir et de gérer les demandes d'inscription faites par les élèves.\
  _Pour savoir comment les gérer, cliquez sur le lien suivant :_\
  <a href="gestionar-participantes-en-preinscripciones.md" class="button primary" data-icon="users">Gérer les participants des préinscriptions</a>
* **Catégories :** permet d'organiser les préinscriptions par catégories ou niveaux au sein de l'académie.\
  _Pour savoir comment les créer, cliquez sur le lien suivant :_\
  <a href="como-crear-categorias.md" class="button primary" data-icon="list">Comment créer des catégories</a>
* **Personnaliser l'inscription :** permet de configurer les champs du formulaire d'inscription que rempliront les utilisateurs.\
  _Pour savoir comment le personnaliser, cliquez sur le lien suivant :_\
  <a href="personalizar-formulario-de-inscripcion.md" class="button primary" data-icon="file-pen">Personnaliser le formulaire d'inscription</a>
* **Communications :** espace destiné à configurer les messages ou notifications liés à la préinscription.\
  _Pour savoir comment le configurer, cliquez sur le bouton suivant :_\
  <a href="gestionar-comunicaciones-de-la-preinscripcion.md" class="button primary" data-icon="envelope-open-text">Gérer les communications de la préinscription</a>
* **ventes périodiques :** permet de définir les cotisations ou paiements associés à l'activité.
* **Ventes :** affiche les informations sur les paiements ou ventes générés par l'inscription.
{% endstep %}
{% endstepper %}

Une fois ces sections configurées, la préinscription est prête à recevoir les demandes des élèves via le site ou à être gérée directement depuis le système du club.
{% endtab %}

{% tab title="Participants" %}
## Gérer les participants des préinscriptions

La section **Participants** permet de consulter et de gérer toutes les personnes inscrites à une préinscription. Vous pouvez y revoir les informations de chaque inscription, ajouter des notes manuelles ou exporter la liste complète des participants.

Le club garde ainsi un suivi clair des participants et dispose des informations recueillies pendant l'inscription.

{% stepper %}
{% step %}
### Accéder à la section Participants

* Allez dans le menu de gauche et ouvrez **Académie**.
* Cliquez sur **Préinscriptions**.
* Sélectionnez l'id de la préinscription à gérer.
* En haut, cliquez sur l'onglet **Participants**.

![](../../.gitbook/assets/image)
{% endstep %}

{% step %}
### Consulter et gérer les participants

Cette section affiche la liste complète des personnes inscrites à l'activité.

Vous pouvez y :

* Revoir les informations de chaque participant.
* Consulter les données recueillies dans le formulaire d'inscription.
* Ajouter des **commentaires ou notes manuelles** si vous devez enregistrer des informations supplémentaires.

Toutes les informations sur les participants restent ainsi organisées en un seul endroit.
{% endstep %}

{% step %}
### Exporter la liste des participants

Si vous devez travailler avec ces informations en dehors du système, vous pouvez exporter la liste des participants.

*   Cliquez sur Id pour sélectionner tous les participants.<br>

    <figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
*   Choisissez exporter et sélectionnez le format de téléchargement.<br>

    <figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>
* Le téléchargement commence alors et vous trouverez le fichier dans votre dossier de téléchargements.
{% endstep %}
{% endstepper %}

Le club peut ainsi consulter et gérer facilement toutes les inscriptions faites dans la préinscription à l'académie. La section des participants centralise les informations recueillies lors de l'inscription et permet aussi de les exporter pour un examen ou un traitement externe si nécessaire.
{% endtab %}

{% tab title="Catégories" %}
## Comment créer des catégories

Les **catégories** permettent d'organiser les élèves d'une préinscription à l'école selon différents critères, comme le niveau, le groupe ou la modalité.

C'est utile pour structurer les demandes d'inscription et faciliter ensuite l'attribution des élèves aux différents groupes ou niveaux de l'académie.

Dans cet article, nous vous expliquons comment les créer.

{% stepper %}
{% step %}
### Accéder à la section Catégories

* Allez dans le menu de gauche et cliquez sur **Académie**.
* Dans le menu déroulant, sélectionnez **Préinscriptions**.
* Sélectionnez l'id de la **préinscription** à gérer.
*   En haut, cliquez sur l'onglet **Catégories**.

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Créer une nouvelle catégorie

* Dans cette section, cliquez sur **+**.
*   Une fenêtre s'ouvre, dans laquelle vous devez remplir le champ suivant :<br>

    <figure><img src="../../.gitbook/assets/Captura de pantalla 2026-03-13 124035.png" alt=""><figcaption></figcaption></figure>



    * **Nom :** indiquez le nom de la catégorie ou du niveau (par exemple : Initiation, Intermédiaire, Avancé ou tout autre niveau de l'école).
* Une fois le nom indiqué, cliquez sur **Sauvegarder** pour créer la catégorie.
{% endstep %}

{% step %}
### Ajouter d'autres catégories

Vous pouvez répéter cette procédure autant de fois que nécessaire pour créer toutes les catégories ou niveaux de la préinscription.

Ces catégories permettront de **classer les élèves selon le niveau ou le groupe auquel ils veulent s'inscrire**, ce qui facilite ensuite l'organisation de l'école.
{% endstep %}
{% endstepper %}

Une fois les catégories créées, les élèves pourront les choisir lors de la préinscription, ce qui permet au club d'organiser et de gérer les demandes de façon plus structurée.
{% endtab %}

{% tab title="Personnaliser l'inscription" %}
## Personnaliser le formulaire d'inscription

La section **Personnaliser l'inscription** permet de configurer les champs que les élèves devront remplir lors d'une **préinscription à l'école ou à l'académie**.

Le club peut ainsi recueillir des informations supplémentaires sur les élèves avant de les attribuer à un groupe ou à un niveau.

{% stepper %}
{% step %}
### Accéder à la section Personnaliser l'inscription

* Allez dans le menu de gauche et cliquez sur **Académie**.
* Dans le menu déroulant, sélectionnez **Préinscriptions**.
* Sélectionnez la **préinscription** à gérer.
* En haut, cliquez sur l'onglet **Personnaliser l'inscription**.

![](<../../.gitbook/assets/image (3)>)
{% endstep %}

{% step %}
### Ajouter des champs au formulaire

En haut, vous trouverez différents **champs prédéfinis** utilisables dans le formulaire.

Pour ajouter l'un de ces champs :

* Sélectionnez le champ à utiliser.
* **Faites-le glisser vers le bas du formulaire.**
* Déposez-le dans la **Colonne de gauche** ou la **Colonne de droite** selon l'organisation voulue.

Le formulaire peut ainsi être structuré en **une ou deux colonnes**, pour une lecture plus facile.

![](<../../.gitbook/assets/image (4)>)
{% endstep %}

{% step %}
### Définir si un champ est obligatoire

Une fois le champ ajouté au formulaire, une **case apparaît à côté**.

* Si vous cochez cette case, le champ devient **Obligatoire** : l'utilisateur devra le remplir pour terminer l'inscription.
* Si la case n'est pas cochée, le champ sera **facultatif**.

![](<../../.gitbook/assets/image (5)>)
{% endstep %}

{% step %}
### Créer de nouveaux champs personnalisés

En plus des champs prédéfinis, il est possible de créer de nouveaux champs.

Pour cela :

* Cliquez sur **Ajouter nouveau**.
* La fenêtre **Ajouter un domaine du formulaire dynamique** s'ouvre.

Vous devrez remplir les champs suivants :

**Étiquette :** nom du champ que l'utilisateur verra dans le formulaire.\
**Type de champ :** définit le type de réponse que l'utilisateur pourra saisir.

Parmi les options disponibles :

![](<../../.gitbook/assets/image (6)>)

* Texte
* Oui/Non
* Liste
* Nombre
* Zone de texte
* Date
* E-mail
* Téléversement de fichier
* Sélection multiple

Vous pouvez aussi configurer, de façon facultative :

* **Options :** valeurs disponibles quand le champ est de type liste ou sélection.
* **Valeur par défaut :** valeur qui apparaîtra déjà sélectionnée dans le formulaire.

Une fois le champ configuré, cliquez sur **Sauvegarder** pour l'ajouter au formulaire.

Une fois les champs du formulaire configurés, les utilisateurs devront remplir ces informations lors de l'inscription. Toutes les données recueillies resteront associées à chaque participant et pourront être consultées ensuite depuis la section **Participants**.
{% endstep %}
{% endstepper %}

En personnalisant le formulaire de préinscription, le club peut recueillir des informations supplémentaires sur les élèves et mieux organiser les demandes avant de les attribuer aux différents groupes de l'école.
{% endtab %}

{% tab title="Communications" %}
## Gérer les communications de la préinscription

La section **Communications** permet de revoir et de modifier les modèles de messages que le système envoie automatiquement aux élèves pendant la préinscription à l'école ou à l'académie.

Ces communications informent l'utilisateur de l'état de sa demande, par exemple quand il s'inscrit correctement ou quand sa préinscription est annulée.

Le club peut modifier ces messages pour les adapter à son style de communication ou ajouter des informations pour les élèves.

{% stepper %}
{% step %}
### Accéder à la section Communications

* Allez dans le menu de gauche et cliquez sur **Académie**.
* Dans le menu déroulant, sélectionnez **Préinscriptions**.
* Sélectionnez l'id de la **préinscription** à gérer.
*   En haut, cliquez sur l'onglet **Communications**.<br>

    <figure><img src="../../.gitbook/assets/image (31).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Revoir les modèles disponibles

Cette section affiche les modèles de communication automatique que le système envoie aux élèves pendant la préinscription.

*   **Confirmation de préinscription :** message reçu par l'élève quand il s'inscrit correctement.

    <figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>
*   **Annulation de préinscription :** message envoyé quand une demande est annulée.

    <figure><img src="../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>



Ces communications sont envoyées automatiquement selon l'état de la demande.
{% endstep %}

{% step %}
### Modifier un modèle de communication

Si vous voulez modifier l'un de ces messages :

* Sélectionnez le modèle à modifier.
* Faites les modifications nécessaires dans le contenu du message.
* Cliquez sur **Sauvegarder** pour appliquer les changements.
{% endstep %}
{% endstepper %}

En personnalisant les communications, le club peut adapter les messages automatiques envoyés aux élèves et les tenir informés pendant la préinscription.
{% endtab %}
