# Élèves actifs

La section **Élèves actifs** affiche dans une seule liste tous les élèves actuellement inscrits aux cours de l'académie. Elle regroupe leurs informations en un seul endroit, sans devoir entrer groupe par groupe pour trouver quelqu'un. C'est le moyen le plus rapide de consulter et gérer tous les clients toujours actifs.

Pour accéder à cette section, il suffit de suivre ces étapes :

{% stepper %}
{% step %}
### Accès à Académie

* Allez dans le menu de gauche et cliquez sur Académie.
{% endstep %}

{% step %}
### Accès à Élèves actifs

*   Dans le menu déroulant qui s'ouvre, cliquez sur **Élèves actifs.**<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Une fois dedans, vous pouvez voir toutes les informations dans une seule liste de tous les élèves.
{% endstep %}
{% endstepper %}
