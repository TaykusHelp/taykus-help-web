# Disponibilité des groupes

La section **Disponibilité des groupes** permet de consulter les groupes de l'académie disponibles selon différents critères de recherche, comme les dates, les jours de la semaine, les ressources ou le niveau.

Cet outil est utile quand le club doit trouver rapidement un groupe actif, vérifier sa disponibilité ou ajouter un élève à un groupe précis sans devoir parcourir à la main tout le calendrier de l'académie.

Depuis cet écran, vous pouvez appliquer des filtres, consulter les groupes correspondant à la recherche et accéder aux actions disponibles sur chacun.

{% stepper %}
{% step %}
### Accès à Disponibilité des groupes

* Ouvrez le menu latéral gauche.
* Accédez à **Académie**.
* Cliquez sur **Disponibilité des groupes**.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FLhYAxVU5CxyabXNEgArt%252Fimage.png%3Falt%3Dmedia%26token%3D2a2bcb2c-1283-4c7d-b471-a326cf7f503f\&width=768\&dpr=3\&quality=100\&sign=45d66402\&sv=2)

Une fois dedans, l'écran de recherche et la liste des groupes disponibles s'affichent.
{% endstep %}

{% step %}
### Paramètres de recherche

En haut de l'écran se trouvent les filtres qui permettent d'affiner la recherche de groupes.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FUshFUAGquodInGbtv5Ki%252Fimage.png%3Falt%3Dmedia%26token%3Dcf213e40-7cb3-4675-a6ed-40315f96ec2b\&width=768\&dpr=3\&quality=100\&sign=55ec3a09\&sv=2)

**Dates**

Vous pouvez indiquer une plage de dates avec les champs :

* **de**
* **À**

Ces champs permettent de chercher les groupes disponibles sur une période précise.

**Jours de la semaine**

Vous pouvez aussi sélectionner un ou plusieurs jours de la semaine :

* Lun
* Mar
* Mie
* Jue
* Vie
* Sab
* Dom

Vous pourrez ainsi trouver les groupes disponibles certains jours précis.

**Ressources**

Le champ **Ressources** permet de filtrer la recherche selon le terrain, l'installation ou la ressource associée au groupe.

**Niveau**

Le champ **Niveau** permet de chercher les groupes selon le niveau attribué, pour trouver facilement des groupes adaptés à un élève précis.
{% endstep %}

{% step %}
### Chercher les groupes disponibles

Une fois les filtres nécessaires appliqués, cliquez sur le bouton **Recherche**.

Le système affichera dans la liste du bas les groupes correspondant aux paramètres indiqués.

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FUL6zF6Duexel6ebun107%252Fimage.png%3Falt%3Dmedia%26token%3Db48d1e8c-b4c4-4f48-88b8-f6b888ac87b0\&width=768\&dpr=3\&quality=100\&sign=87f0898c\&sv=2)

Dans la liste, vous pouvez voir des informations comme :

* **ID**
* **Nom du groupe**
* **Saison**
* **Date de début**
* **Date de fin**
* **Détails**

Cela permet de vérifier rapidement quels groupes sont disponibles et sur quelle période ils sont actifs.
{% endstep %}

{% step %}
### Ajouter un élève à un groupe

![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252FDWLYuM20q5jZ6kvXmHov%252Fimage.png%3Falt%3Dmedia%26token%3D6540d8f4-a11d-483c-8c25-c19bb029d931\&width=768\&dpr=3\&quality=100\&sign=44ac800f\&sv=2)



* Trouvez le groupe auquel vous voulez ajouter l'élève.
* Sélectionnez le groupe dans la liste.
* Cliquez sur **Ajouter un élève au groupe**.
* Une fenêtre s'ouvre avec le nom du groupe sélectionné.
* Dans le champ **Recherche d'élèves**, cherchez et sélectionnez l'élève à ajouter.
* Si besoin, indiquez une **Date de fin** pour fixer jusqu'à quand l'élève restera dans le groupe.
* Sélectionnez les jours où l'élève fréquentera le groupe.
* Cliquez sur **OK** pour confirmer.

Si vous ne voulez pas faire l'action, vous pouvez fermer la fenêtre en cliquant sur **Fermer** ou sur la **X** en haut à droite.

> **Important :** avant de confirmer, vérifiez que le groupe affiché dans la fenêtre est le bon et que les jours sélectionnés correspondent à la fréquentation de l'élève. Vous éviterez ainsi de l'ajouter à un mauvais groupe ou à de mauvais jours.
{% endstep %}
{% endstepper %}

La section **Disponibilité des groupes** permet de trouver rapidement les groupes de l'académie qui répondent à des critères de recherche précis.

Grâce aux filtres de date, de jours, de ressource et de niveau, le club peut consulter les groupes disponibles et ajouter des élèves de façon plus rapide et ordonnée. Avant toute action, il est conseillé de toujours vérifier le groupe sélectionné pour s'assurer qu'il correspond à la disponibilité souhaitée.
